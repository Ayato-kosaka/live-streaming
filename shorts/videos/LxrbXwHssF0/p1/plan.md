## 4. 書き出しの道具（`tools/shorts/render/`）で作れるか

読んだもの: `render.py`・`README.md`・`style.json`、`tools/shorts/plan/build_edit.py`、品質チェックの `tools/shorts/qa/cuts.py`・`reuse.py`。**道具は触っていない。**

| 要るもの | いまの道具 | 作れるか |
| --- | --- | --- |
| 元の声で全編を流す | spec の行の `orig_voice`。カットと同じ秒の元の音を行の声にする。全部が元の声の回は「話している間の RMS」で揃え、**行ごとに揃えるので2人の声の大きさの差も直る**（`orig_voice.py`）。1行にカットを何本も書けば、間を抜いて声もつなげる | **作れる。ただし `build_edit.py --gap 0` が要る**（既定は行と行の間に 0.25秒、声の無い間を入れて最後の画を延ばす。会話のテンポが崩れ、続いた区間なら同じ画が2度出る） |
| 2人が左右に並ぶ帯を中央に | `sources.<名>.crop`（元の画の使う範囲）＋ `fit: blur`（範囲を全部入れて、上下はぼかした同じ画） | **作れる**（帯の位置は縦の真ん中だけ。上に寄せる欄は無い） |
| 話す人の画に寄る | 同じファイルを、1人ぶんの `crop` の別の source として書き、`fit: cover`。`zoom` でゆっくり寄るのもある | **作れる** |
| 上の題の帯（全編） | `title` の `from`/`to` で0コマ目から最後まで（card でない形）。色・位置は様式の差分（`"extends": "style.json"`） | **作れる**。題の中の1語だけ色を変える欄は無い（いまは1色）→ **足りない（小）** |
| 話し手ごとの字幕の色 | 字幕は様式の `caption` 1つ（白に黒縁）。行ごとに変えられるのは強調（`highlight`）の黄だけ | **足りない（大）**。行に話し手（`speaker`）を持たせ、様式の話し手ごとの色で描く欄が要る。代わりの手: 字幕の頭に名前を付ける（参考 8N0 の「ジム『…』」）・強調で1人の言葉を全部黄にする |
| 話している人の名前の札 | 名前を出す部品が無い（`note` は左上に1か所・`title` は1つだけ） | **足りない（中）**。画の決まった位置に札を出す欄（動画全体かカットごと）が要る。代わりの手: 元の画に焼かれた TikTok の札（「ワルテミス」「あやと【アプリ…】」）をそのまま写す（あやとの札は途中で切れている） |
| 字幕の置き場 | 様式の `caption.center_y`（既定 1000＝画面の縦の真ん中）と、顔を避けて下へ動かす `avoid_faces` | **作れる**（様式の差分で帯の下へ。帯の中は2人の顔なので、真ん中のままだと顔避けで毎行動く） |
| 効果音 | 無い（BGM 1本と元の音だけ） | **足りない**（この型では入れない案なので、いまは要らない） |
| BGM なし／声の下にごく小さく | 指示書に `bgm` を書かなければ鳴らない。小さくは `--bgm-db` | **作れる** |
| 最後の札を出さない | 様式の `end_note.enabled: false` | **作れる** |
| 視聴者さんの名前を写さない | 帯だけを `crop` で切り出す（名前の流れる所は帯の外）。帯にかかるギフトの絵は `cuts[].blur` | **作れる** |
| 3秒の決まりの検査（`cut_length`・`similar_run`） | 同じカット 3.0秒以上・似た画の連続 3.0秒以上で落ちる。顔が大きく写る画どうしは「同じ瞬間」のときだけ似た画と数える | 決まりを当てるなら、帯と寄りを2秒台で切り替えれば**通る**。当てないなら、この型だけ線を外す欄が要る（**仕様の答え待ち**） |
| 原稿の検査（`tools/shorts/script/lint.py`・批評役） | 語りの回の4欄の原稿・最後の問い（L-END）などを見る | この型の企画には当てない（F-052）。対談系の企画の形に合う検査は無い |

**まとめ: いまの道具だけで、元の声・帯・寄り・全編の題・札なしまでは作れる。足りないのは「話し手ごとの字幕の色」と「名前の札」の2つ（ほかは小さい）。** 直すのは、あやとが案と仕様（0章の1〜3）を決めてから。
