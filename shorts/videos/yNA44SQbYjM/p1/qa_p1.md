## 窓を1カットずつに分けたこと

取り込み（`bread-yNA44SQbYjM-p1-clips-20261111.json`）は画を選ぶために 5〜8分の窓で頼んだ。品質チェックは「同じ素材のファイル」を同じ場面と数えるので、
d3 では 90秒離れた別の場面どうしも似た見た目・同じ画に数えられた。狭い窓（頭 −2秒・尻 +3秒、`production.md` 1 の素材の段の形）で頼み直す
はずだったが、そのとき Actions の取り込みが GitHub の障害で止まっていて（前の run の fetch が 1時間半 in_progress、後ろにほかの担当の run が待っている。
3本目を push すると待っている run を取り消す）、**取ってある長い窓から同じ区間を1コマ単位で切り出して**、同じ形の `index.json` を作った
（配信の秒は変えていない。切り出した頭のコマが元の窓の同じコマと PSNR 47dB で一致することを確かめた）。
