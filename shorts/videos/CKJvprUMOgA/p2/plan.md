## なぜ書き直したか

### 取り込みについて

- **clips の外は要らない。** 5行目の第一候補（スーツの列 0:35:28）と10行目の第一候補（台座の騎馬像 0:26:38）、7行目の第二候補（騎馬像の引き 0:22:58）は clips の外だったが、clips の中の別の瞬間で埋めた（上の表）。替えの候補も spec の `alt_src` に、clips の中から1つずつ書いた
- カクつきで ✕ が出たのは2か所だけで、どちらも使わない: 夕日 0:04:58.5–0:04:59.0（空から顔へカメラを切り替える所で、0.5秒同じ絵が止まる。68%）・牛 1:08:58（63%）。牛 1:12:09（60%）も避けた
- 夕日の回で顔が写るのは 0:04:59.5–0:05:04.5（うつむいた顔）と 0:05:05–0:05:06（正面の顔）だけ。正面の顔は使っていない
- 1回目の clips（3本）は、毎晩の文字起こしが Cookie を60分握ったままで取れず、全部失敗した

### 書き出しの段で要ること（声ができてから）

- **3本の clips の `index.json` を `--clips` で3回渡す。** `build_edit.py` は spec の時刻を1つの時間軸として読むが、3本の窓は時刻が重ならない（夕日 0:00:00–0:05:40・銅像 0:11:50–0:42:20・牛 0:49:20–1:16:55）ので、素の時刻で一意に引ける（下書きで31カットが全部正しい回に落ちるのを確かめた）。どの回の時刻かは spec の `src_video` に並べた
- **1行目と18行目は overrides で `len` を書く。** 書かないと `build_edit.py` が行を文の切れ目で割り、下書きでは18行目の顔が 3.07秒＋19行目 1.83秒になって3秒を越え、1行目の顔の区間にも食い込んだ。1行目は顔 2.2秒、18行目は像を「行の長さ − 1.0秒」にして、顔は18行目で1.0秒、19行目で残りを続ける（19行目は `same_as_prev`）
- 顔のぼかしの帳面（`--blur`）は動画ごとに1冊なので、3本ぶんを合わせる。通りがかりの人が大きく写るカットは選んでいないが、牛の回の 1:09:26 の奥と、橋の 0:30:21 の人は小さく写る
- 実物の声の長さで、カットの秒と上の5つの検査を測り直す。3秒を越えるカットが出たら、その行の `alt_src` で割る
