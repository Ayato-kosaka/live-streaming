## 自己点検（`references/script_writing.md` の4）

- [x] **外から説明していないか** — 全部「僕」の一人称の喋り言葉
- [x] **です・ます調・「〜でした」になっていないか** — 16行目「すいません」だけ。配信でのあやとの謝りかたのまま
- [x] **情報の行が2つ続いていないか** — 5→6は「だらけ」→「20体はおるで」で、6行目が数と驚きの組。7（書いてなかったで）→8（100体は絶対超えてる）は反応と数の組、9→10（コメント → そんな仕様ないよ）、11→12→13は「牛 → 尻尾 → スカスカやないかい」の溜めと落ち、15→16（空洞が普通 → すいません）、18→19→20（顔映したら → コメント → なってもうた）

- [x] **褒めるだけで終わっていないか** — 「作りすぎ」と、牛の空洞を疑うところが欠点の側
