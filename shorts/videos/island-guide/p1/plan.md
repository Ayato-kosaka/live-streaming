## 5. 推す案と理由

**A を推す。**

1. あやとの押したい所②（実際に行った経験から作るガイド）を、いまの面で嘘なく見せられるのは A だけ。行く前に作った面と、配信で起きたこと（いちご味・638円・あちちち）を並べると、「経験で肉付けされていく」が画で分かる
2. 山が3つとも配信の画と本人の声で立つ（バニツァの「倍近い」は数字の落差、温泉は元の声）。B と C は面の説明が中心で、配信の画が1〜2行しかない
3. 参考（1章）で伸びた旅のショートは、「調べた／言われた → 行ってみたら違った」の落差を1つずつ畳んでいた。A の答え合わせ3つはその拍
4. 問い「ガイドと違ってたことある？」は、旅をしたことのある人なら誰でも答えられる

B は「日本語の記事が無い」が初見に強いが、「10個くらい」はあやとの見積もりで、撮る前に数えないと題にできない。C は #1271 と同じ「AI で作った」の話になり、2本並べると重なる。
