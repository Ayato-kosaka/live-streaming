# v3 の B・C の機械の検査（check.py）

北マケドニアの回で出した B（YouTube rVGC150Y3hA）と C（YouTube W96gFSEKxZs）に、
master 67141b45 の `tools/shorts/qa/check.py` を 2026-10-18 に当て直した記録。
#917・#918 の根拠は v1（PR #932）・v2（PR #937）の記録しか無かったので、出した版の分を足す。

## 何に当てたか

| | B | C |

声の倍率はどちらも、いまの上限 1.4（`tools/shorts/render/style.json` の `narration.max_tempo`、#946）を越えている。
いまの `render.py` にこの指示書を渡すと、書き出さずに止まって「原稿を約 20%（B）・約 19%（C）減らす」と出す。

回しかた（work は `render.py` の `--work`。`plan.json`・音の束・字なしの版 `no_text.mp4` がある）:

```bash
python3 tools/shorts/qa/check.py B.mp4 B.work --json B.json --md B.md
```

- OpenCV は `opencv-python-headless==4.12.0.88`（venv。手元の 5.0 には Haar が無い）。numpy 2.2.6・Pillow 12.0.0
- 顔を探す検出器は、Actions の書き出し（`tools/shorts/render/remote.py`）と同じ YuNet にそろえた。
  重みは `fetch_fonts.sh` が落とすのと同じもの（`face_detection_yunet_2023mar.onnx`、sha256 `8f2383e4…52fa4`）を
  `tools/shorts/render/models/` に置き、顔（`faces`）は `SHORTS_QA_YUNET` を渡して `--only faces`、
  字と顔（`text_on_face`）は `--only text_on_face` で測り直した。重みが無いと、どちらも Haar に落ちて結果が変わる（下の2章）
- かかった時間: 全項目（Haar）B 881秒・C 796秒（2本を並べて、4コア）。YuNet の測り直しは顔 10〜11秒・字と顔 67〜75秒

## 検出器で結果が変わる

YuNet の重みが無いと、`faces` も `text_on_face` も Haar に落ちる。Haar のままだと、字と顔は B・C とも不合格になる。

| | YuNet（Actions の書き出し・顔よけと同じ） | Haar だけ |
| --- | --- | --- |
| B 顔 | 人が見る 20件 | 人が見る 36件 |
| B 字と顔 | 合格（例外の印で通した行 2） | 不合格: 7行・90コマ（2.07秒 17コマ・26.77秒 17・29.37秒 5・32.47秒 38・35.4秒 8・35.7秒 3・39.7秒 2） |
| C 顔 | 人が見る 10件 | 人が見る 9件 |
| C 字と顔 | 合格（例外の印で通した行 1） | 不合格: 1行・13コマ（29.0秒「日本やったら／ICカードでピッやのにな」） |

Haar の字と顔の不合格を、いちばん重なったコマに箱を描いて見た:

- **B の7行は、どれも字が配信者の鼻の下から口の高さにあり、目には掛かっていない。** Haar は顔の点を持たないので、「目と鼻」を箱の上から高さの 72% と見積もる。箱が下にずれると、その範囲が口まで届く（35.4秒・35.7秒は Haar の箱そのものが口と顎に乗っていた）。YuNet は鼻の点から範囲を決めるので、口に掛かる字は通す（口から下は被ってよい、あやとの直し #926）
- **C の1行は顔ではない。** 字なしの版の 883コマ目で、Haar の箱は道ばたの売店の屋根と柱に乗っていた

だから、手元で測るときも YuNet の重みを置く（`tools/shorts/render/fetch_fonts.sh` が `render/models/` に落とす。
`faces` は `render/models/` を見ないので `SHORTS_QA_YUNET` も渡す。Actions では `remote.py` が渡している）。
`check.py` の出力の `measured.detector` が `yunet` になっているかを見る。
