# 字の当て — ノマドキッチンカープロジェクト（`book.json`）

`docs/guide-copy.md` の 7章（出す前の当て 1〜7）と 6章（外しがちな形 1〜12）を、面に出る字の全部に当てた表（2026-11-23。点検の指摘を当てて作り直した）。
**型** は当てた字の形（2章〜4章の型・地の文・物の名前・本人の言葉）、**手本** はその形の元にした人の文言（`guide-copy.md` 8章の番号）。
手本は、当てた字と形が本当に重なるものだけ書いた。地の文と表の字は型を「地の文」にとどめ、手本を書かない。
一行の字（見出しの下・景色の一行・なぜたい焼きか・外装と内装の一行・案内鳥のひとこと）は、読点・括弧で強める字（“”『』「」）・字数を
道具で数えた（`python/legend_kitchen_check.py` の `one_line`）。名前の欄は「数＋つの」の呼び名（6章の12）も道具で見た。
節の名前と添え字（「イメージ。まだ決まっていない」「目安」など）は焼く道具が持つので、この表に無い。
