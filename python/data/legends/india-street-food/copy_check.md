# 字の当て — インド屋台飯100食（`book.json`）

`docs/guide-copy.md` の 7章（出す前の当て 1〜5）と 6章（外しがちな形 1〜11）を、面に出る字の全部に当てた表。
**型** は 2章〜4章の型、**手本** はその型の元にした人の文言（`guide-copy.md` 8章の番号）。
一行の字（題・見出し下・決まり・リード・節の題）は、読点・括弧で強める字（“”『』「」）・字数を道具で数えた（`build.py` の `one_line`）。
地の文（窓の字・用語の説明・地域・コツ・答え）は、使わない語（いま・今年・最新・絶品・極上・本場の・正解・できます・になっています・おすすめです ほか）を数えた。
同じ型のリードを3つ続けない（4章）も数えた。

## 7章の当てかた

| 7章 | 何を見たか |
| --- | --- |
| 1 声に出して読む | 一行ずつ読み、意味を聞かれそうな字は直した（下の「直したもの」） |
| 2 型に入るか・手本を言えるか | 下の表の「型」「手本」の列 |
| 3 6章の11項目 | 作った呼び名・読点で2つに割る・箱の違う2つを並べる・括弧で強める・数と並びを詰める・同じリズムを続ける・見出しで説明する、を一行ずつ見た。0件 |
| 4 人の言葉から取らないもの | 最旬・今こそ・話題の・煽り・読む人を絞る語を道具で数えた。0件 |
| 5 出どころ | 一行の事実は窓の字と同じ出どころ（`book.json` の `src`）から取った |

## 調べものから写さなかったもの

調べもの A・B の「一言でいうと」「ひとことで」の字（「ムンバイの“じゃがバーガー”」「北はギーと小麦、窯焼きと宮廷の濃い味」など）は使っていない。使ったのは事実と出どころだけ（`docs/island-misses.md` #344）。候補の名前に付いていた括弧の呼び名（「目玉の高級店」「果物ごと凍らせた」など）も外した。
