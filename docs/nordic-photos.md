# その日の写真と、埋め込むキャラクター

**これは仕様である。** 北欧旅の日ごとの旅程（`/nordic`）に付く。

---

## 1. 何をするものか

**旅の1日が終わったら、あやとがその日の写真を貼る。景色でも風景でも、何枚でも。**

見た人はその写真をダウンロードできる。**そのとき、その日の配信でスパチャしてくれた人の
キャラクターを1人選んで、写真に埋め込める。** 埋め込まなくてもよい。

```
写真を選ぶ
  ↓
「キャラクターを入れる」か「そのまま」を選ぶ
  ↓
入れるなら、その日のスパチャの人から1人選ぶ
  ↓
保存
```

## 2. なぜこの形か

**その日いた人の記録が、写真という持って帰れるものになる。**
順位表でも、点数でも、称号でもない。**その日そこにいた、という事実だけ**が残る。

`docs/island-play.md` の「移植してはいけないもの」に触れていない。
育成でも、島内通貨でも、連続ログインでもない。**1日1回きりで、あとに何も残さない。**

## 3. 誰が貼れるか

**あやとのアカウントだけ。** ログインして、そのアカウントであることを確かめる。
`functions/src/islandApi.ts` がすでに「あやとが書いていいと決めた人だけが書ける」形を
持っているので、そこに寄せる。

## 4. キャラクターの選びかた

**その日の配信でスパチャしてくれた人。**

| 出どころ | 取りかた |
| --- | --- |
| YouTube のスーパーチャット | BigQuery `youtube_chat.chat_messages` の `event_type`（TEXT 以外に PAID がある）から、その配信日ぶんを引く |
| **Doneru** | **自動で取れない。当面は手で入れる** |

**どちらもキャラクターの絵に結び付けるには、あやとの表（issue #113）が要る。**
表に無い人は、キャラクターが選べない。**そのときは「そのまま保存」だけを出す。**
「あなたのキャラクターがありません」と言わない（本人のせいではない）。

## 5. 埋め込みの寸法

**あやとの見本から測った値。** 見本はトビリシのサメバ大聖堂を縦に撮った写真で、
右下にネズミのキャラクターが1体。

| 何 | 値 |
| --- | --- |
| 置く場所 | **右下** |
| 横幅 | **写真の横幅の約 34%** |
| 右端からの空き | 写真の横幅の **2% 前後**（ほぼ右端に付ける） |
| 下端からの空き | 写真の高さの **5% 前後** |
| 傾き | **無し（0度）** |

**キャラクターは地面に立っているように見せる。** 見本では、写真の下のほうにある
「地面」の帯にキャラクターの足元が乗っている。**空や建物の真ん中に浮かせない。**

**縦の写真での値である。** 横の写真では横幅 34% だと大きすぎるはずなので、
**高さのほうを基準にする**（見本の高さは写真の高さの 20% 前後）。
横の写真の見本は無いので、作ったら撮って確かめる。

**傾きは 0度と読んだ。** もし見本に意図した傾きがあれば直す。

## 6. 詰まりそうなところ（先に書いておく）

- **キャラクターの絵は `lh3.googleusercontent.com` にある。** よその置き場の絵を canvas に
  描くと、canvas が汚れて（tainted）**保存ができなくなる**。CORS が付いていなければ、
  Cloud Function 経由で取り直すか、自前の置き場に写す必要がある。**ここは先に確かめる。**
- **写真の置き場が要る。** Firebase Storage を使うなら、そのルールも要る
  （`firestore.rules` と同じで、書けるのはあやとだけ・読むのは誰でも）。
- **写真は重い。** 旅は10日で、1日に何枚でも貼れる。**貼るときに縮めて焼く**
  （長辺 1600px くらい、webp）。元のままだと `/nordic` が一気に太る。
- **保存はスマホでやる人が多い。** `<a download>` は iOS Safari で効かないことがある。
  実機で確かめられないので、**新しいタブで開いて長押しで保存**にも倒せる形にしておく。
