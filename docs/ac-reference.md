# どうぶつの森と、いまの島の差

任天堂の公式スクリーンショット（Nookipedia の press 素材）を実際に落として、
あやと島の画面と並べて見た結果。**印象ではなく、見て取れた違いだけ**を書く。

参照した画像は `/tmp/acref/`（一時。落とし直すには下のスクリプト）。

```bash
mkdir -p /tmp/acref && cd /tmp/acref
# Nookipedia の API から公式スクショを落とす（tools/sprites/acref.py）
python3 /home/user/live-streaming/tools/sprites/acref.py
```

---

## 1. 色。ここがいちばん違う

あやと島の色は**くすんでいる**。どうぶつの森は彩度も明度も、こちらよりずっと高い。

| どこ | どうぶつの森（実測） | あやと島（いま） | どうするか |
| --- | --- | --- | --- |
| 深い海 | `#1466c8` 前後。はっきりした青 | `#2f7391` 灰みの青緑 | 青へ寄せて、彩度を上げる |
| 浅瀬 | `#4fc8d2`〜`#7fe0d8` の明るいターコイズ | ほぼ無い | 砂の外に必ず1本入れる |
| 波の泡 | **真っ白のレース状**。くっきり描いてある | 薄いグラデ | 白でくっきり。ぼかさない |
| 砂 | `#f5e0a8` 明るいクリーム。濡れた砂は一段濃い | `#e8d3a8` 悪くないがやや暗い | 明るく。濡れ砂の帯を足す |
| 草 | **`#52bd5d`**（色相 0.351）| `#7bd350`（色相 0.279）黄に寄りすぎ | 黄をやめて、緑〜青緑側へ戻す |
| 空 | `#4aa8f0` 明るいセルリアン＋白い雲 | 濃い青一色 | 明るく。雲を足す |

**要するに、全体に「霞んでいる」。** 彩度を上げるだけでなく、明度も上げる。
どうぶつの森は影の中まで明るい。

## 2. 岸の作り。3本の帯でできている

公式のビーチ写真を見ると、海から陸へ向かって必ずこの順に帯がある。

1. 深い青
2. **明るいターコイズの浅瀬**（けっこう幅がある）
3. **真っ白な泡のレース**（不規則な弧を重ねた形。ぼかしていない）
4. 濡れた砂（乾いた砂より一段濃い）
5. 乾いた砂

あやと島は 1 → 4 → 5 しかない。2 と 3 が無いので、陸と海の境が
ただの色の切り替わりになっていて、水辺に見えていない。

## 3. 影が弱い

どうぶつの森の接地影は、思っているよりずっと濃い（見た目で 30〜40%）。
真下ではなく、光源の反対（右下）へ少しずれる。

あやと島は 18〜22% で、しかも真下。物が地面に乗っていない感じの原因。

### 影の色 — 測ったら「暖かい灰緑」は誤りだった

公式の落ち影を、影のかかっていない同じ地面で割った比:

| 撮ったところ | R | G | B |
| --- | --- | --- | --- |
| 草の上 | ×0.53 | ×0.58 | **×0.76** |
| 砂の上 | ×0.72 | ×0.70 | **×0.77** |

**青だけ残る。** つまり本物の影は暗い青すみれ（およそ `rgb(12,14,52)` を 30〜50%）で、
暖かい灰緑ではない。屋外の影が空の青を拾うので、物理的にもこちらが正しい。

**ただし、あやと島ではそのまま使わない。** このサイトの影は生成りの紙の上にも落ちる。
紙の上に青すみれの影を落とすと、印刷物ではなく画面の合成に見える。

> **決めごと。向きと濃さは実測に合わせる（右下・30〜40%）。
> 色みだけ暖色に寄せる。**

草と砂の上（島のステージ）では青すみれに寄せてよい。紙の上では暖色のまま。

## 4. 地面の情報量が少ない

公式の草地には、花・雑草・小石・足あとが**びっしり**入っている。
あやと島は木と建物のあいだが空いていて、更地に見える。

## 5. 木の形

どうぶつの森の木は、**丸いかたまり**に明るい側と暗い側があるだけ。面で割れていない。
Kenney の木は多面体なので、面ごとに明るさが違って、そこだけ「3Dモデル」に見える。
焼くときに面の陰影を弱めて、上下のグラデーションで見せると近づく。

## 6. UIの作り

これは近い。ただし違うのは:

- どうぶつの森の窓枠は**もっと太くて、角がもっと丸い**（半径が高さの 1/3 くらい）
- 影は真下に**べたっと**落ちる（ぼけていない板の影）
- 文字は太いゴシックで、**字間が広い**
- 押せるものには必ず**下に厚みがある**（立体の板に見える）

## 7. 紙の図鑑の作り（一覧・詳細ページはこの型を真似る）

どうぶつの森のUIには**2つの型**がある。混ぜると散らかる。

| 型 | どこで使われているか | 見た目 |
| --- | --- | --- |
| **板の型** | 島の上に浮くHUD、ボタン、通知 | 厚みのある板。下にべたっと影。角丸が大きい |
| **紙の型** | いきもの図鑑、カタログ、パスポート、しおり | 紙の上に印刷したページ。影は落とさない。細い罫線で区切る |

**あやと島では、島のステージとボタンは「板の型」、一覧と詳細ページは「紙の型」にする。**
いまは全部が「板の型」なので、ページを開くと同じ形のカードが延々と積まれて見える。

### 紙の型の実測（いきもの図鑑・シーラカンスの面より）

| 何 | 実測 | どう使うか |
| --- | --- | --- |
| 紙の地 | `#eadda9` 〜 `#efe4b6` | **無地にしない。** 明るさが5%ほどムラになっている |
| 外の地（紙の外側） | `#f4efcf` | 紙より明るい。紙が「載っている」ように見える |
| 区切りの罫線 | `#9e976d` 1px | 暖かいオリーブ灰。**黒い線は使わない** |
| 見出しの下敷き | `#dbdc90` | 蛍光ペンで引いたような帯。見出しの字の後ろに敷く |
| 小さなチップ | 地 `#cfc202` | ベタ塗りの角丸。**影を落とさない** |
| 選んでいるものの枠 | `#e2522d` | オレンジ赤の細枠だけ。塗りは変えない |
| 題名 | 白い紙の札 | 少し傾けて、テープで貼ったように置く |

### 紙の型の決まり

1. **紙は無地にしない。** わずかなムラを入れる。CSSなら重ねたラジアルグラデーションで作れる（画像を足さない）。
2. **区切りは影ではなく細い罫線。** 紙の型のカードに `box-shadow` は付けない。
3. **見出しには蛍光ペンの帯を敷く。** これ1つで「印刷物」に見える。
4. **主役の絵は大きく、まわりを大きく空ける。** 図鑑の面は、絵が縦の半分以上を占めている。
5. **チップは平ら。** 厚みを付けるのは「押せるもの」だけ。押せない印に厚みを付けない。
6. **選択は塗りを変えず、細い枠で示す。**

### どちらをどの面に割りあてるか

**`docs/island-world.md` 2章に、21面ぜんぶの割りあて表がある。** 迷ったらそちらを見る。

### どこに効かせるか

- `/kitchen`（スタンプ帳）と `/kitchen/[slug]` — いちばんこの型が合う
- `/legends` と `/legends/[slug]`
- `/map/[slug]`（国の詳細）
- `/nordic/guide`（旅のしおり）
- `/streams/[slug]`

トップページと島の上のボタンは「板の型」のまま。**2つを1つの面で混ぜない。**

## この差をどう埋めるか

- 色は `app/css/tokens.css` の変数を全部見直す
- 岸の3本の帯は `components/island/IslandScene.tsx` の地形で足す
- 影の濃さと向きは `tools/sprites/render.html`（焼き込み）と、島の楕円の両方
- 地面の情報量は `IslandScene.tsx` の飾りの数を増やす
- 木の面の割れは `render.html` の光の当て方
- 紙の型は各ページの CSS（`pages.css` / `streams.css` / `atlas.css` / `nordic.css`）で作る
