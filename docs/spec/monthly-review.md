# 仕様: 月末配信の授賞式（配信で読み上げる1枚）

種別: 仕様

**これは仕様である。拘束力がある。** 授賞式を作る前に全部読む。
変えるときは、先に決定の記録（[`docs/adr/`](../adr/README.md)）を1枚書き、同じ PR でここを直す。
経緯はここに書かない（決定の記録 0021 と `docs/island-misses.md` が持つ）。
作り方の手順は `.claude/skills/monthly-review/SKILL.md`。手順がこの仕様と食い違ったら、この仕様が正。

---

## 1. 用語

| 語 | 意味 |
| --- | --- |
| 授賞式 | 月末配信で読み上げる1枚の画面（`public/<年><月>_monthly_review.html`）。島の `/months/<年-月>` とは別物 |
| 期間 | その月の授賞式が扱う日。2章 |
| 面 | 1画面。コーナーは1つ以上の面を持つ |
| 1押し | ctrl（スマホ）またはクリック・Enter で1つ進むこと |
| 大写し | 一覧の1件を画面の真ん中に大きく出した状態（5章） |
| 貢献額 | `docs/island-money.md` の式で出す額。授賞式で出す額はこれだけ |

## 2. 期間と数

- **MR-1** 期間は「前回の月末配信の日 〜 今回の月末配信の前日」（JST）とする。月初〜月末にしない。月末配信の日は `python/build_monthly.py` の `FINALS` が持つ。
- **MR-2** 配信日の境目は 6:00 JST。0時をまたいだ続きの枠は前の日に数える。
- **MR-3** 出席の日数・分母・皆勤・連続月数・はじめましての人数・しゃべった人数・枠の数は、`site/content/months.ts`（`/months/<年-月>`）の値をそのまま使う。授賞式の側で数え直さない。
- **MR-4** 投げ銭の順位と額は `python/admin/monthly_tips_run.py`（Actions）が出したものをそのまま使う。額は貢献額。実額を出さない。
- **MR-5** 個人ごとのコメント数を画面に出さない。コメント数で賞を作らない。

## 3. 画面の形

- **MR-6** 画面は **1080×1080 の正方形**とする。縦長の配信に載せ、残りに顔を映す。
- **MR-7** OBS 用は `?role=view`、操作用のスマホは `?role=ctrl`、1台で回すときは無指定。進行は Firestore の `monthlyReview/<年月>-<乱数>` で同期し、書けるのは管理者だけ（`firestore.rules`）。
- **MR-8** 見た目は、あやと島の紙の札（輪郭線なし・丸ゴシック）に、その月の投げ銭アラートの季節テーマの絵を重ねる。UI に絵文字を使わない（視聴者さんの引用・配信の題の中の絵文字はそのまま）。
- **MR-9** 視聴者さんに見せる名前は「あやと島案内鳥」。画面のどこにも `Claude` と出さない。名前は「〜さん」をつけて出す。
- **MR-10** 画面で仕組みや式を説明しない（`docs/island-standards.md` §6）。

## 4. コーナーと並び

- **MR-11** 並びはこの順とする。

| # | コーナー | 中身の決まり |
| --- | --- | --- |
| 1 | オープニング | 期間・4つの数（日・枠・はじめまして・しゃべった人。MR-3） |
| 2 | 今月の6分割ふりかえり | MR-14 |
| 3 | 出席日数 | 皆勤の日数から −1・−2・−3 日の人だけ。日数のみ |
| 4 | 皆勤賞 | 出席日数の**あと**。「N ヶ月連続」を必ず出す。1ヶ月目は「はじめての皆勤賞」と書き、色を変える |
| 5 | はじめまして | 総数は出す。札にするのは MR-16 に当たる人だけ |
| 6 | どの配信でしょうクイズ | 10問。MR-15 |
| 7 | 流行語大賞 | ノミネート＋大賞1。MR-18 |
| 8 | 名言・いい話 | MR-17 |
| 9 | おもしろコメント大賞 | 部門賞（4〜6）＋グランプリ1。MR-17 |
| 10 | 付箋大賞 | 島の付箋に貼ってくれた人の表彰。部門賞（5まで）＋大賞1。MR-19 |
| 11 | 調べもの大賞 | 1面に収める。MR-20 |
| 12 | その月のおまけ | 季節テーマ・アラートにまつわる話。任意 |
| 13 | 投げ銭ありがとう | 4位以下 → 3位 → 2位 → 1位＋紙吹雪 → 合計。同額は同順位 |
| 14 | あやと島案内鳥 からの手紙 | MR-21 |
| 15 | エンディング | **投げ銭してくれた人を主役にする。** 皆勤の人を象徴にしない |

- **MR-12** 賞は「多い側を広く、頂点を1つ」とする。部門賞を N 出すとき、大賞・グランプリは1つ。
- **MR-13** 同じ出来事を2つのコーナーで使わない。特にクイズと6分割は、作ったあとに突き合わせて被りを 0 にする。

## 5. 中身

- **MR-14 6分割ふりかえり**: その月を出来事の区切りで6つに割る（週で機械的に割らない）。1コマは見出し＋1〜2行で、その月にしか無い固有名（店・値段・言われた言葉）を1つは入れる。各コマに、その区切りの日の**あやと島カードの写真**を出す（1〜3枚。`islandStreamEventImage` の `role: card`）。
- **MR-15 クイズ**: 配信の題を選ばせない。配信を見た人が中身を覚えていて「ああ、これ」と話せることを、A・B・C の3択で問う（値段・数・点数・どうなったか・何と言ったか）。答えは議事録か字幕で確かめた事実だけ。その日のカードの写真があれば一緒に出す。
- **MR-16 はじめましての札**: 期間中に投げ銭した人と、初コメント以降の配信日の半分以上（2日以上）に来た人だけ。
- **MR-17 視聴者さんの言葉（名言・おもしろ）**: あやとの配信・旅・出来事についての言葉だけを選ぶ。視聴者さん自身の私生活の話（自分の行った店・自分の仕事）は選ばない。説明を足さないと伝わらないもの・内輪の言い回し（「日本語で配信している日本人に、海外から日本語上手」の類）は選ばない。引用1行だけを声に出して読み、伝わらなければ落とす。引用は原文のまま。
- **MR-18 流行語**: `python/buzzwords.py` で数えた上位から選ぶ。手で候補を出さない。「◯◯から」は道具の初出の日をそのまま使い、初出が期間より前の語は日付を出さず件数だけ出す。件数は出してよい。
- **MR-19 付箋大賞**: 島の付箋（`islandNotes`）で期間に貼られたもの・期間に動いたものから選ぶ。表彰するのは**付箋がそのあと何かになったこと**（ショートになった・企画やグッズになった・行き先が決まった）。1件ごとに、付箋の本文（原文）・貼った人（名乗らなければ「名乗らずに貼ってくれた人」）・ハートの数・「そのあと」を出す。
- **MR-20 調べもの大賞**: 「困って止まっていたことが、それで動いたか」で選ぶ。豆知識は選ばない。1面に収まらなければ件数を減らす。
- **MR-21 手紙**: 感動する手紙にする。その月にしか言えないことを1つ言い切る段落を入れる。月の出来事を時系列でなぞらない。「誰々が何々と言いました」を並べない。ほかのコーナーで使った引用を繰り返さない。署名は「あやと島案内鳥 より」。

## 6. 読みやすさ（受け入れの線）

1080×1080 で全面・全ステップを出して測り、全部を満たしたときだけ出す。

- **MR-22** 一覧で3件以上を並べる面は、**1押しごとに1件を大写しにする**。次の1押しで、その1件は一覧の元の位置に戻り、次の1件が上に重なって大写しになる。最後の1押しで全部が一覧に戻る。押す回数が増えることは構わない。
- **MR-23** 大写しの本文は 40px 以上、名前は 48px 以上。
- **MR-24** 一覧の1行は 56px 以上、1面 12 行まで。超えたら面を割る。列を増やして詰めない。
- **MR-25** 字が「…」で切れている要素・はみ出し・横スクロール・JS エラーは 0。
- **MR-26** 撮った絵を横 540px に縮めて目で見て、読めない面が無い。
- **MR-27** Enter で最後まで進み、Backspace で先頭まで戻れる。ctrl の5タップでちょうど5進む。

## 7. 出す

- **MR-28** 本番の道は `https://ayato-arigato.com/<年><月>_monthly_review`。あやとに渡すのはこの道だけ（古いドメインは `.claude/hooks/no-old-domain.sh` が止める）。
- **MR-29** 出したら、`/months/<年-月>` と出席・投げ銭の数を突き合わせる。食い違ったらどちらかが間違っている。
- **MR-30** 月末配信の前日の配信は、配信が終わって取り込まれてから数え直し、出し直す。
