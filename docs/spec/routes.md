## 1. 道の作りかた

**R-1** 道は「種類の接頭辞＋そのものの名前」だけで作る。子は、親の名前の下に名前を足す。

```
/<接頭辞>                 その種類の一覧
/<接頭辞>/<名前>           そのもの
/<接頭辞>/<名前>/<子の名前>  その子
```

**R-2** あとで変わることを、道に入れない。
- どの旅に属するか（国は、いくつもの旅に出る）
- 状態（これから・いま・おわった・伝説になった）
- どの入口の下か（入口は並べ替える）
- 日付の見立て

**R-3** 名前（slug）は英字の小文字・数字・ハイフン。末尾にスラッシュを付けない。日本語を入れない。

**R-4** 1つのものに、道は1つ。同じものを指す2本目の道を作らない。動かしたら、前の道は 301 で新しい道へ送る（手順は [`../island-routing.md`](../island-routing.md)）。

**R-5** `site/app` に在る道の型は、2章の表に載っていなければならない。載っていない型を足すと、`python/route_spec_selftest.py` が書き出しの前に止める。足すときは [`/feature-design`](../../.claude/skills/feature-design/SKILL.md) を通し、この表を同じ PR で直す。

## 3. 道ごとの責務

**R-10** その道に入れてよいもの・入れないものは、下の表のとおりとする。入れないものは、持ち主の面に書き、札で引く（[`model.md`](./model.md) M-20）。

| 道 | 入れるもの | 入れないもの |
| --- | --- | --- |
| `/` | いまの旅の島。「いまここ・つぎ・今夜」 | — |
| `/about` | どんな人で、なぜ旅しているか | 旅・企画の話の書き写し |
| `/streams/…`・`/months/…` | 配信の型の説明。ひと月の数字とふりかえり | 企画の話・旅の話 |
| `/legends/<企画>` | その企画の話。なぜ・決まり・名場面・結果・数字。国をまたぐ体験の話 | 日ごとの記録・国や街の説明 |
| `/travel/<国>` | その国がどんな所か | 旅の話・企画の話・数字の書き写し |
| `/travel/<国>/<街>` | 街のガイド | 同上 |
| `/travel/<国>/<街>/<話題>` | 1つの街で完結する話題 | 国をまたぐ話 |
| `/island/<旅>/…` | 期間・回った国の順・道のり・旅の1日・しおり・その旅の配信 | 企画の「なぜ」と名場面・国の説明 |
| `/kitchen/<料理>` | 料理そのものと、作った回 | 国の説明 |
| `/apps/<アプリ>` | アプリと、作ってきた道のり | — |
| `/friends` | 住人とキャラクター | — |
| `/goods`・`/cards` | 持って帰れるもの | — |
| `/board`・`/updates` | お題と付箋。島をなおしたところ | 企画の一覧・企画の登録 |

## 4. 入口

**R-20** 入口（島の建物）は9つとする。並びは、あやとのこと・配信・伝説の企画・歩いた国・アプリ・作った料理・住んでる人・あやとグッズ・やってほしいこと。

**R-21** 入口は道にかぶせる案内の層である。入口を並べ替えても・減らしても、道は動かさない。

**R-22** 下のボタン・表紙の島の建物・索引（`/all`）の棚・パンくずの2段目は、入口の表1つから引く。手で並べた写しを置かない。

**R-23** どの面も、パンくずの2段目が、2章の表の「入口」と一致する。「建物の外」の面はパンくずに入口を持たない。

**R-24** 状態（いま・これから）のための入口を作らない（[`model.md`](./model.md) M-31）。

**R-25** 道具（建物の外）の面は、索引（sitemap）に出さない。

## 5. 島の外の道（動かさない）
