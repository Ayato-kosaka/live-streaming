## 3. Check — 毎週の表の読みかた

表は月曜の朝（日本時間）に #1262 に出る。手で押すときは Actions の「検索の週の数」（`dry_run` で issue に書かずに要約へ）。
**週は「3日前まで」の7日**（Search Console の数は2〜3日遅れて固まる）。

| 節 | 読むところ |
| --- | --- |
| 1 島ぜんたい | 表示が週ごとに増えているか。**クリックは表示が三桁になるまで読まない**（1回で率が10％動く） |
| 2 狙う語 | 「—」は**行が無い**＝表示が無いか、打った人が少なくて Search Console が伏せた。0 ではない。表示が出た語は順位を見る |
| 3 面ごと | 表示・順位と、Google の台帳（URL 検査）。「載っていない」なら、理由の字を見る |
| 4 画像検索 | 「見どころマップ」を含む語の表示。地区分けの絵が出ているか |
| 5 載った面 | sitemap の面のうち Google に載っている数（前週比）。**Google が別の URL を正と見ている面**は、正を直すまで育たない |
| 6 sitemap | 最終読み込みが1週より古い・エラーが在る → sitemap を見る |
| 7 サイトの作り | `--expect prod` の線。**外れた線は、入れた手が戻ったということ**——その週のうちに直す |
| 読めなかったもの | 鍵・権限・API。**0 と書いていない**ので、そこは数が無い週として読む |

### 効いた／効いていない の決めかた

**1週の上下で決めない。** 表示が一桁の週は、1回の検索で倍にも半分にもなる。決めるのは、手を入れた日から数えた次の線で。

| いつ（手を入れた日から） | 効いた | 効いていない → どうする |
| --- | --- | --- |
| 2週 | 狙う面に表示が出ている（2節か3節） | 表示 0 → 5節で載っているかを見る。載っていなければ入口のリンクと中身。載っていれば題と見出し |
| 4週 | 狙う語のどれかで 20位以内、地図の語なら 10位以内（#1262 の「確実に」の線） | 20位より下 → 4章の「順位が低い」 |
| 8週 | 記事（物価・ヨーグルト）に表示とクリック。島 → YouTube が数えられていれば、その数 | 載らない → **次の国へ広げない**（#1204 の決まり） |

- 順位は表示で重み付けした平均。**表示が5に届かない語の順位は読まない**（1回の表示で決まる）
- 「伏せられた」語は表に出ない。表示があるのに狙う語が「—」なら、Search Console の画面の「検索キーワード」で、
  近い言い換えが出ていないかを見る（出ていたら `seo_targets.json` の `queries` に足す）
- 載った面の数が週で大きく動いたら、5節の内訳の字を見る（Search Console の「ページ」の画面は数日遅れて固まるので、
  URL 検査の数と画面の数が合わないことがある）

## 4. Act — 次の手の決めかた

表を読んだら、#1262 に1コメント（効いた／効いていない・次に入れる手・いつ見るか）。**手を入れたら2章に1行。**

| 表で見えたこと | 次の手 |
| --- | --- |
| 載っていない（「クロール済み・未登録」） | 中身が薄い・どこからもリンクされていない。島の中からのリンクを足す（`/travel` `/all` 国の面）。題と一文が面の中身を言っているか |
| 載っていない（「Google に認識されていません」） | sitemap に在るか・`noindex` が外れているか。Search Console で「インデックス登録をリクエスト」（EC2 の Chrome。`/mymaps` と同じ `ytstudio`） |
| Google が別の URL を正と見ている | 同じ中身が2か所で配られていないか（古い `web.app`・末尾の斜線・`.html`）。301 と canonical |
| 表示はあるが 20位より下 | その語の上位の面を開いて、答えている問いと見出しを比べる。足りない問いを1節に（**言い換えの水増しはしない**） |
| 4〜10位なのにクリックが無い | 題と一文。検索結果に出る30字で「何が分かる面か」が言えているか |
| 狙っていない語で表示が出た | Search Console の画面で語を見る。同じ意図なら言い換えとして足す。別の意図なら、面を分けるかを Plan で決める |
| 画像検索に表示が無い | 絵のファイル名・alt・すぐ上の見出し・`ImageObject`・画像のサイトマップに語が在るか（#1262 のあやとの決め） |
| 7節で線が外れた | 戻した PR を探して直す。**直すまで次の手を入れない**（何が効いたか分からなくなる） |

次に入れる手を選ぶ順は、**直ったら効く数が大きいものから**: 載っていない面を載せる → 載っている面の順位 → 新しい面。
新しい面（1章の候補）は、親の面（ソフィア）が2週の線を越えてから。
