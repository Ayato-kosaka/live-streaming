# 文書の台帳

**このリポジトリの文書は、ここに1行ずつ載っている。** 載っていない文書は置けない（`python/docs_index_selftest.py` が止める）。
決めた理由は [`adr/0001-docs-kinds.md`](./adr/0001-docs-kinds.md)。

## 1. 種別

文書は、次の5つのどれか1つである。

| 種別 | 何を書くか | 書きかた | 直すとき |
| --- | --- | --- | --- |
| **仕様** | 決まったこと。守らなければならないこと | 「〜する」「〜しない」で言い切る。条に番号を付ける。経緯を書かない | 先に決定の記録を1枚書く |
| **決定** | 1つの決定と、その理由 | 1決定1枚。状況・決定・理由・捨てた案・影響 | 直さない。新しい1枚で置き換える |
| **手順** | どう回すか | 上から順に打てば終わる形 | 手順が変わったら直す |
| **台帳** | いま何が、どこに、どう在るか | 事実だけ。数は道具から引く | 現状が変わったら直す |
| **記録** | そのとき起きたこと・調べたこと・検討したこと | 日付つき | 直さない。新しい日付で書き足す |

## 2. 決まり

- **D-1** 決まったことは仕様に書く。issue・コメント・記録・チャットに書いただけのものは、決まったことにならない。
- **D-2** 仕様を変えるときは、先に決定の記録（[`adr/`](./adr/README.md)）を1枚書き、同じ PR で仕様を直す。
- **D-3** issue は作業の単位である。設計を issue の本文やコメントに置いたままにしない。決まった時点で、仕様と決定の記録へ移す。issue と仕様が食い違ったら、仕様が正である。
- **D-4** 記録は規範として読まない。記録から決めごとが生まれたら、仕様へ写す。作る前に読むのは仕様で、記録ではない。
- **D-5** 新しい仕様は `docs/spec/` に、決定は `docs/adr/` に置く。既に在る文書は動かさない（2,800か所以上から名指しされている）。
- **D-6** 仕様は「こう在るべき」を書く。まだそうなっていない所は、同じ文書の末尾の「現状との差」に、条と issue を並べる。直ったら行を消す。
- **D-7** 動く数を文書に書かない。`python3 python/counts.py` が数える。
- **D-8** 文書を足したら・消したら、この台帳を同じ PR で直す。種別と、何を持つかを1行で書く。
- **D-9** 視聴者さんの素性（名前・チャンネル・チャットの本文）を文書に書かない。
- **D-10** `docs/` には、あとから読んで意味のあるものだけ置く（仕組みがどうなっているか、なぜそう決めたか、どこを触ればいいか）。次のものは `docs/` に置かず、GitHub issue を立てる。
  - あやとにやってもらう操作（コンソールの設定、権限付与、鍵の発行）
  - 「これから増やすとしたら」のような検討中の案
  - 期限や状態を持つもの（やった / やっていない が変わるもの）
- **D-11** issue を立てたら、終わったら自分で閉じるところまでやる。開けっぱなしにしない。誰かの操作待ちで止まっているものは、待っていることが分かるように書く。
- **D-12** 閉じるのは「出した、その場で」。あとでまとめて、にしない。セッションが変わると「出したかどうか」が分からなくなって、開いたまま何日も残る（#159 #160 #161 #163 が実際に2日そうなった）。手順は `/island-ship` の6章。

## 8. プロンプト（Claude Code への指示）

文書ではなく指示なので、種別は付けない。置き場と、何を書くかだけを決める。

| 置き場 | 何を書くか | 書かないもの |
| --- | --- | --- |
| `CLAUDE.md` | いつも守ること（立ち位置・やってはいけないこと）と、何をどこで読むか | 手順の中身・経緯・個別のつまずき |
| `.claude/skills/<名前>/SKILL.md` | くり返す作業1つの手順 | 決まりそのもの（仕様を指す） |
| `.claude/hooks/` | 始まりと終わりに機械が言うこと | — |

- **P-1** 決まりはプロンプトに書かず、仕様に書いて、プロンプトからは条を指す。同じ決まりを2か所に書かない。
- **P-2** `CLAUDE.md` に手順を足さない。くり返す手順はスキルにする。
- **P-3** プロンプトに書いた経緯（いつ、何が起きたか）は、記録か決定の記録へ移す。
