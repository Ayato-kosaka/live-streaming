あやと（2026-11-13、ソフィア滞在中）:

> Googleマップのマイマップを使って、それをブログに埋め込んだりするのはOKらしいので、それでいきたい。
> ちょっと今のやつGoogleマップと違って見慣れてなくて見にくいなって思ってて。

## なぜマイマップか（鍵の要る道を採らない理由）

| | 鍵 | 請求先 | こちらのピン | 見た目 |
| --- | --- | --- | --- | --- |
| OSM の絵＋自前の札（1枚目の形） | 要らない | 要らない | ○ | **Google と違う。見慣れない** |
| Maps Embed API | **要る** | **要る** | ✕（1か所だけ） | Google |
| Maps Static API | **要る** | **要る** | ○ | Google（絵） |
| **マイマップ** | **要らない** | **要らない** | **○** | **Google。指で動かせる** |

**Google 自身が「埋め込む」を用意している**ので、スクショを貼るのと違って
条件のグレーを踏まない（`#1189`）。

## 分担。**ピンを手で置かせない**

マイマップを作る口は**画面しか無い**ので、ログイン済みの Chrome が要る。
この箱からは触れない（`.claude/skills/ec2-chrome/SKILL.md` の鍵の確かめ方を先に読む）。

**だが手で置くのは24個ぶんの作業で、1時間溶ける。** マイマップは CSV を取り込めるので、
**取り込む元をこちら側で焼いて渡す。**

```bash
python3 python/bulgaria_mymaps.py     # → python/data/bulgaria/mymaps/{see,eat,buy}.csv
```

| | 誰が | 何を |
| --- | --- | --- |
| 1 | **この箱** | CSV を焼く（上） |
| 2 | **Chrome のあるセッション** | 取り込む → 公開 → 埋め込みの `mid` を返す（下） |
| 3 | **この箱** | `mid` を焼き込んで、面の地図を差し替える |

## Chrome 側の手（3枚ぶん繰り返す）

1. <https://www.google.com/mymaps> →「新しい地図を作成」
2. 「インポート」→ CSV を選ぶ
3. **位置の欄**に `緯度` と `経度`、**タイトルの欄**に `名前` を選ぶ
4. 地図の題を付ける（`ソフィア｜見たいもの` `ソフィア｜食べたいもの` `ソフィア｜買いたいもの`）
5. **「共有」→ リンクを知っている全員が閲覧可**（**ここを飛ばすと、埋め込み先で地図が出ない**）
6. 「…」→「自分のサイトに埋め込む」→ 出てくる `<iframe src="…/maps/d/embed?mid=XXXX">` の **`mid` だけ**を控える
7. 色分けするなら「個別スタイル」→ `印` の列で分ける（◎／○／⚠ が地図の上で見分けられる）

**返すのは `mid` 3つだけ。** iframe の字ごと持ち帰らなくていい。

## 面に埋めるときの決まり

- **`&hl=ja` を付ける。** 付けないと、現地の端末の言葉（ブルガリア語）で開く
- **`loading="lazy"`。** 地図は3つあり、1枚ずつが Google の地図を丸ごと読む。
  最初の描画で3つとも読むと、スマホで重くなる
- **この箱から Google の地図には届かない。** 撮ると空で写るので、
  **「絵が出ない＝壊れている」と読み違えない**（`tools/sprites/prod.mjs` の `PASS`。
  `CLAUDE.md`「このサンドボックスから出られない先」と同じ罠）
- **「Googleマップで開く」のリンクは消さない。** 埋め込みは見るためのもので、
  歩くときに要るのは本物のアプリが開くほう

## 作り直すとき

**ピンを手で直さない。** 材料（`python/data/bulgaria/*.json`）を直して CSV を焼き直し、
マイマップで**取り込み直す**（レイヤを消して入れ直す）。
手で直すと、面と地図で中身が食い違う。
