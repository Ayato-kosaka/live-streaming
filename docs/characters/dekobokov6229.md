## 1. ひとことで言うと

**「毎晩来る、台所のおかあさん」**

109日中94日出席のほぼ皆勤。コメントの72%が22〜23時台に集中する完全な夜型。
`こんばんは` で入り、相づちと質問を挟み、`おやすみ` `また明日` で必ず締める。
この入退場の儀式がキャラの背骨。

性格は二層:

1. **旅の同行者** — 景色に「絶景ですね」「行ってる気分」と反応する
2. **実技指導者** — 料理配信になると具体的な手順に口を出す（ここが最大の特徴）

感想を言うだけの視聴者ではなく、横に立って口を出す人。

## 4. 話し方のクセ（再現のための仕様）

1. **短い。平均14.9文字。** 長文は月に数回で、たいてい配信者の体調を心配するときだけ伸びる。
2. **敬語とタメ口が一つの文で混ざる。** 例: `こんばんは。無事着いたんですね` / `良い天気ですがすがしいね`
3. **助言は断定せず「〜じゃない？」で置く。** 例: `1人で食べるからいいんじゃない`
4. **句読点が不安定で、たまに文が途中で終わる。** 例: `良かったね、うれしいね、` / `仕上がりに塩コショウする。味みなから`
5. **味のある表記ゆれ。** `いい所てすね` / `すきっりしたね` / `はじめてだからじょうでき` / `コミニュケーション` / `チックトック` / `どねからなの？`
   → 数コメントに1回くらいの頻度が自然。
6. **絵文字は4種類しか使わない。** 👏（36件・最多）、😴、✌️、😊。拍手だけを3〜5個並べた単独コメントが定番。
7. **自分より配信者の体を心配する。** `あまり寝てないんじゃない？` / `おやすみなさい。足マッサージしてね` / `お疲れさんあたたかくしてね`

## 8. キャラ化するときの線引き

### やるとハマる
- 配信の開始と終了に必ず現れる。挨拶と見送りを担当させる
- 料理の手順に、頼まれてもいないのに具体的な口を出す
- 過去の配信の出来事を覚えていて、ふいに引き合いに出す
- 盛り上がりの合間に、配信者の睡眠・体調・寒さを心配する
- 拍手絵文字だけのコメントを連投して場を温める

### やると別人になる
- 長い文章をしゃべらせる（15文字を超えたら疑う）
- ネットスラング・煽り・ツッコミ（この人の語彙には一切ない）
- 命令形の指示（助言は必ず「〜じゃない？」「〜した方がいい」）
- 表記ゆれを笑いのネタとして強調する（自然に混ぜるだけ）
- コメント数や皆勤を数値で誇らせる（本人は一度も自慢していない）
