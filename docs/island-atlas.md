# 島をひとつから、島の連なりへ

**これは仕様である。拘束力がある。** 島のかたちを変える作業は、まずここを読んでから始める。

`docs/island-design.md`（絵と触りごこちの決まり）と `docs/island-world.md`（板と紙の決まり）は
そのまま効く。ここはその上に載る「島が何個あるか」の話。

---

## 1. なぜ変えるか

いまは島が1つで、その中に「これから」「あやとのこと」「配信」「アプリ」「歩いた国」「企画」が
建っている。**旅そのものが、島の中の1つの建物（歩いた国）に押し込まれている。**

あやとがやっているのは、**2年かけて西から東へ移動し続けている旅**で、章がある。
ヨーロッパを回った時期、中東を回った時期、ジョージアに落ち着いた時期。
それぞれで配信の中身も、作っていたアプリも、来てくれていた人も違う。

**それを島1つの中の1ページに畳むと、旅が旅に見えない。**
章ごとに島を1つ立てて、島が連なっているようにする。

---

## 2. 章の切りかた

章は**配信の中身と滞在で切る**。`site/content/countries.ts` の滞在期間と、
BigQuery の `youtube_chat.videos`（配信のタイトルと日付）から決めた。

| # | 章 | 期間 | 日数 | 国 | 島の性格 |
| --- | --- | --- | --- | --- | --- |
| 1 | **ヨーロッパ周遊** | 2024-10-28 〜 2025-03-29 | 153 | 9 | 配信が始まった島。週3から毎日へ |
| 2 | **中東周遊** | 2025-03-30 〜 2025-06-28 | 91 | 5 | 祭りが生まれた島（GWエジプト祭） |
| 3 | **コーカサス周遊** | 2025-06-29 〜 いま | 続いている | 3 | **いまいる島。いちばん大きい。** アゼルバイジャンから入って、ジョージアに腰を据えて「なに食べよ」を作り、アルメニアへ出て、また戻った |
| — | ↳ **イランまで歩く**（枝） | 2026-04-29 〜 2026-05-08 | 10 | 1 | **先に進んだのではなく、逸れた。** 歩いて国境まで行って、戻ってきた |
| 4 | **北欧周遊** | これから | — | — | **次の島。まだ建っていない** |

**ジョージアを独立した島にしない。** アゼルバイジャン・ジョージア・アルメニアで
ひとつのコーカサス周遊。ジョージアの274日はその中でいちばん長い滞在だが、
章としては同じ島の中の出来事。

### 枝（逸れた島）を、進んだ島と同じに描かない

イランは、ジョージア／アルメニアから**歩いて国境まで行って、また戻ってきた**。
西から東への流れの中の1歩ではない。**本線から下へ枝分かれした小島**として描く。
船の道も、本線とは別の細い線にする。

### 章が増えたとき

`site/content/chapters.ts` に足す。**期間が重ならないこと**と、
**本線は日付順に一列**であることだけを守る。枝はいくつあってもよい。

**画面は1つも触らない。** 1行足すと、連なりに島が1つ増え、`/island/<章>/` に
**歩ける島**が1つ建つ。輪郭も草木も大きさも建物も、そこから勝手に決まる（3章・4章）。
`ISLAND_ART` に手で形を書いていない章は、`artOf()` が回った国の region から
かたち・草木・色を引く（`site/components/chain/shapes.ts`）。

### いまいる島は、日付で決まる

`chapterNow(new Date())`（`content/chapters.ts`）。**`to` の空欄では決めない。**
空欄で決めていたときは、北欧へ出発しても誰かが `chapters.ts` を書きかえるまで
島が入れ替わらなかった。旅は日付で進むので、判定も日付でやる。

まだ始まっていない章には `opensAt`（出発の日時）を持たせる。
北欧は `content/nordic.ts` の `DEPART` と同じ値。**片方を動かしたら両方動かす。**

**静的書き出しに焼かない。** `output: "export"` なので、ビルドしたときの答えが
HTML に入る（`CLAUDE.md`）。焼くのはいまの島1つだけにして、画面では必ず
`chapterNow(new Date())` を呼び直す。連なりの「いまここ」も、トップの表紙も、
これを見ている。

## 3. 島の見た目は、事実から決める

**手で「この島は大きめ」と決めない。** 全部データから引く。

| 何 | 何で決まるか |
| --- | --- |
| **大きさ** | 滞在した日数。コーカサス周遊（434日）はヨーロッパ周遊（153日）の 2.8倍の面積になる。**ただし下駄がある**（すぐ下） |
| **かたち** | その章で回った土地を、抽象的に思わせる輪郭。ヨーロッパならヨーロッパらしく |
| **草木・建物** | その土地のもの。中東なら乾いた土とナツメヤシ、北欧なら針葉樹と岩 |
| **住人** | **その章のあいだに来てくれていた人**。同じ人が複数の島に出てよい |
| **色** | 章の色ではなく、**土地の色**。`docs/island-design.md` の色の決まりに従う |

### 大きさには、日数と関係のない下駄がある

面積∝日数をそのまま守ると、10日のイランが半径 18 にしかならない。
その大きさでは浜も草木も 1px を切って、**島に見えない**（撮って確かめた）。
なので「**どの島にも、日数と関係のない浜のぶんの面積がある**」ことにして足す。

```
r = √(BASE² + K²・日数)      BASE = 26, K = 118/√434
```

コーカサス 118 → 121 とほとんど変わらず、小さい島だけ持ち上がる。
**大小の順は崩れない**（北欧 31 < イラン 32 < 中東 60 < ヨーロッパ 75 < コーカサス 121）。
`site/components/chain/shapes.ts` の `islandRadius`。
**「日数に比例していない」と思って外さないこと。**

### 住人

BigQuery から引く（`chat_messages` の `author_channel_id` と、章の期間の重なり）。
数え方は `.claude/skills/monthly-review/SKILL.md` 3章と同じにする
（日ごとに数える／配信日は UTC で切る／コメントの残っていない日は当時すでに来ていた人を出席扱い）。

**どの絵が誰かは、alertbox の Viewers 表が決める**（`python/residents_map.json`）。
本人に選ばせない。表に載っていない人は絵が無いので、**人数には入るが島には立たない。**

## 4. 島に建てるものは、章ごとに違う

**どの島も最大6つ。** 島に建っているものは全部押せる（`docs/island-design.md` 6章）。

### いまの島

いま決めてある6つの入口をそのまま使う。

### 過去の島

**その章のときに何をしていたかで決める。** いまの6つを写さない。

**「作った料理」はジョージアに落ち着いてから始めたことなので、ヨーロッパの島には建てない。**
その章に無かったものを建てると、島が嘘をつく。

だから**章ごとに手で並べない。** `site/components/isle/spec.ts` が、
**その章に中身のあるものだけ**を建てる。歩いた国が0なら道しるべは立たないし、
伝説の企画が無い章に館は建たない。素材の足りない章は、建つものが自然に減る。

| 建つもの | 建つ条件 | 中に出るもの |
| --- | --- | --- |
| **この島で歩いた国**（道しるべ） | `countries` がある | 国旗と滞在した街 → `/map/<国>` |
| **この島で起きたこと**（やぐら） | その章の配信がある | 新しい3本 → `/island/<章>/streams` |
| **この島の代表的な企画**（館） | 期間に重なる `legends` がある | 企画と、その1つの数字 → `/legends/<企画>` |
| **はじめての配信**（たき火） | **いちばん古い配信を持っている島だけ** | 1本目の配信 |
| **この島のこと**（石碑） | `chapterStats` がある | 日数・本数・来た人数・国数 |
| **となりの島へ**（船着き場） | **いつでも** | ひとつ前の島／つぎの島／島の地図 |

船着き場だけは、あふれても削らない。島から出る道が消えると、島が袋小路になる。

### 次の島（北欧）

- この旅のこと（テント。**出発まであと何日**が札に付く）
- これから歩く国（`/nordic/<国>`。中身はもう全部そろっているので、島の中に作り直さない）
- 旅のしおり
- この旅の掲示板
- となりの島へ

ショート動画は建てていない。**一覧がリポジトリのどこにも無い**（9章）。

### 建物の中身は、島から出ずに見る

あやとの言葉:「その中の**やぐらみたいな感じで**、この島で歩いた国とか、
この島で起きたこととか、この島の代表的な企画とかが見れて」。

だから建物を押しても島から出ない。**島の上に板が1枚開いて、その中に一覧が出る**
（`components/isle/IsleSheet.tsx`）。島の外へ出るのは、その一覧の1つを押したとき。
島は板なので、開くものも板（`docs/island-world.md` 1.5）。

## 5. 次の島は、集まったぶんだけ建つ

**豚の貯金箱（Doneru）の集まりぐあいで、次の島の建設が進む。** いまの目標は5万円。

| 集まり | 島の姿 |
| --- | --- |
| 0% | 更地。地面と杭だけ |
| 10% | 鉄筋が立つ |
| 50% | 壁と屋根がかかる |
| 100% | 完成。草木も住人も入る |

**これは進捗バーではない。** `docs/island-play.md` は進捗バーを「移植してはいけないもの」に
挙げているが、あれは**やらされている感を出す棒**のこと。ここは**島の絵そのものが変わる**。
数字を棒で見せるのではなく、行った先の景色が育つ。

**集まらなくても旅には行く**（`docs/nordic-fund.md`）。
建っていない島へ船で行けること自体は変えない。更地に立てる。

### 歩ける島では、草木まで消さない

連なりの絵（`components/chain/IslandMark.tsx`）は 0% を土だけで描く。
**歩ける島（`/island/nordic`）はそうしない。** 草木まで消すと、歩ける島に見えない。
育つのは**建物のほう**で、島そのものは最初からそこにある。
0% は「まだ杭しか打っていない区画」が島のまん中にある姿。

**出発したら、この区画は消える。** その日からは「これから建つ島」ではなく、
いま歩いている島になる。判定は日付（2章）で、画面が出てから決める。

## 6. 島から島へは、船で行く

**押した瞬間に切り替えない。** 船が出て、水路をたどって、着く。かわいく、ゲームらしく。

- 動きを減らす設定の人には、船を出さずに切り替える
- 船に乗っているあいだも押せる（急ぐ人を待たせない）
- **島の連なり全体を見わたす画面**が要る（`/atlas`）

着いた先の島では、**浜に船着き場があって、舟がつないである。**
あやとはそこから歩きはじめるし、そこを押せばとなりの島へ渡れる。
連なりの画面のカヌーと、島の浜の舟は同じ絵（`canoe`）。

## 7. 決まっていること（オーナーが選んだ）

### トップは、いまの島

**`/` を開いたら、いままでどおり「いまの島」に降り立つ。** 連なりは右上の
「島の地図」から見る。毎日来る人に、島へ入るための1タップを増やさないため。

代わりに、**はじめて来た人には島が複数あることが見えない**。ここは
「島の地図」の札の出しかたで補う（`docs/island-play.md` の「世界のほうが先に口を開く」）。

### ページは、過去の島だけ絞る

| | 何が出るか |
| --- | --- |
| `/island/europe/streams` | **その章の配信だけ** |
| `/streams` | **全部**（いまの島から入るのはこちら） |

過去は**振り返る場所**、いまは**使う場所**、と役割を分ける。
いまの島の6つは、これまでどおり全体のページへ行く。

### 次の島は、姿と数字の両方を出す

**島の姿（更地・鉄筋・完成）＋ 集まった額 ＋ 目標額。**

```
（鉄筋だけが立っている絵）
北欧周遊
3万円 / 5万円
```

姿だけだと、出した人が自分の1回の効きめを見られない。
目標額まで出すと「あとどれくらいか」が分かる。

## 8. いま建っているもの

| どこ | 何 |
| --- | --- |
| `/atlas` | 島の連なり。4つの島＋枝1つが日付順に縦に並ぶ |
| 島の右上「島の地図」 | そこへの入口（`.stage-atlas`）。トップは変えていない |
| `/island/europe` `/island/middle-east` `/island/iran-walk` `/island/nordic` | **歩ける島**。いまいる島いがい全部 |

### 歩ける島は、どう作ってあるか

**`site/components/isle/`。** いまの島（`components/island/`）は 1200四方に
300要素を手で置いた1枚もので、章ごとに輪郭も草木も建物も変えられない。
**あちらは1文字も触っていない。** 借りたのは輪郭を描く道具（`geometry.ts`）と
スプライトの置き方（`Sprite.tsx`）だけ。

| ファイル | 何 |
| --- | --- |
| `spec.ts` | 章 → 建てるもの（4章の表）。`content/` しか読まない |
| `world.ts` | 島の地形・建物の座標・草木・道。**手で置いた座標は1つも無い** |
| `IsleGround.tsx` | 地面。海の模様・浅瀬・浜・草・道の8枚 |
| `IsleStage.tsx` | 歩く・カメラ・当たり判定・札 |
| `IsleSheet.tsx` | 建物の中（島の上に開く板） |
| `folk.ts` | 住人のふるまい。持ち場を引数で受け取る |
| `Cover.tsx` | トップの表紙を、いま何章かで入れ替える |

触りごこちはいまの島と同じにしてある。**押したところまで歩く／カメラが付いてくる／
近づくと札が開く／住人に話しかけると吹き出しが出る／引いて島ぜんぶを見る。**
あやとの「コーカサス周遊と同じぐらいのクオリティに」がここ。

### 値段 — 島が5つでも、払うのは1つぶん

見えている島はいつも1つなので、原理的に1つぶんで済む。そのために、
いまの島で効いた3つをそのまま持ってきた。

1. **`viewBox` を書き換えない。** 書き換えると SVG の中身が全部塗り直される。
   画面より広く焼いておいて、ズレは CSS の `transform` で見せる
2. **同じ値を書かない。** 属性に書けば、値が同じでもその要素は塗り直される
3. **見えていないあいだは動かさない**（画面の外／別のタブ）

やらないこと: **SMIL を使わない**（中身を全部塗り直す）。
**島を囲む大きさの形を動かさない**（海のきらめきは静止。動かすと、海が画面の
1割しか写っていなくても10割ぶん払う）。

実測（390×844・dpr3・放置6秒・`Performance.ProcessTime`。交互に測って比を読む）:

| 面 | 1秒あたりの CPU |
| --- | --- |
| `/board`（島の無い面。下駄） | 55 ms |
| **`/`（いまの島）** | 267 ms |
| `/island/europe`（いちばん大きい章の島） | **192 ms** |
| `/island/middle-east` | 178 ms |
| `/island/nordic` | 115 ms |

歩かせると `/` が 532ms、`/island/europe` が 293ms（×0.55）。
PC（1440×900）で `/` が 165ms、`/island/europe` が 145ms（×0.88）。
**どの島も、いまの島より安い。**

`/island/europe` を**歩ける島にする前**（絵が出るだけだった紙の面）と
交互に測ると **×1.00**。エンジンを1本足して、1秒あたりの CPU は変わっていない。

### 数字の出どころ

BigQuery にしかないものは、全部ここに焼いてある。**手で直さない。**
作り直すのは `BQ_PROJECT_ID=... python python/build_chapter_stats.py`。

| ファイル | 何 |
| --- | --- |
| `site/content/chapterStats.ts` | 章ごとの人数・配信の本数・**その章にいた住人** |
| `site/content/chapterStreams.ts` | 過去の島の配信ぜんぶ（240本）。`/island/<章>/streams` が読む |

日数だけは静的書き出しに焼くと止まるので、画面が出てから数え直している。
