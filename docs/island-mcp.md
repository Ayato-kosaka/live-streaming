# 外の口が切れたときの直しかた（MCP）

**このセッションから外を引く口は MCP で繋がっている。** 切れると、繋ぎ直せるのは
**あやとだけ**（認可はブラウザで人が押すもので、こちらからは押せない）。

**切れていることに気づかないのがいちばん悪い。** 引けないまま「0件でした」と
報告すると、**無いのか引けないのかが区別できない**（`docs/island-misses.md` の
「落ちようのない測り方で測らない」）。

---

## 1. 何が繋がっているか

| 口 | 何に使うか | 切れると |
| --- | --- | --- |
| **Google Cloud BigQuery** | チャット・投げ銭・配信の実績を引く | 島の数字を**この箱から確かめられない** |
| **GitHub** | issue・PR・Actions | ほぼ全部止まる |
| **Slack** | （いまは使っていない） | — |

---

## 2. 切れたときに出るもの

セッションの途中で、こういう知らせが入る。

```
The following MCP servers require authentication before their tools can be used:
Google_Cloud_BigQuery
```

道具の一覧からも消える。**呼ぼうとすると「見つからない」と言われる**ので、
**「見つからない＝無い」と読まないこと。**

---

## 3. 直しかた（あやとの操作）

**こちらからは押せない。** 認可はブラウザで人が押すものなので、頼む。

- **claude.ai のコネクタ**なら → claude.ai の設定 → コネクタ から繋ぎ直す
- **それ以外**なら → 対話セッションで `/mcp`、または `claude mcp`

**こちらが合言葉や URL を聞き出そうとすることはない。** 聞かれたら疑うこと。

---

## 4. 繋ぎ直るまでの代わり（BigQuery が切れているとき）

**「引けないので分かりません」で止まらない。** たいてい代わりがある。

| 知りたいこと | 代わりの見かた |
| --- | --- |
| 配信の実績（どの国・いつ） | `site/content/cityStreams.ts`（焼き込み。毎晩更新） |
| 国ごとの人数・件数 | `site/content/countryStats.ts` |
| 住人の「一緒にいた日数」 | `site/content/residents.ts` |
| 章ごとの数字 | `site/content/chapterStats.ts` |
| 取り込みが通ったか | **Actions の run を見る**（`Fetch YouTube Chat Data`） |
| 投げ銭の額 | 本番の口 `GET /island-api/fund` を curl |

**焼き込みは前の晩までのぶん**であることを忘れない。今日の配信は入っていない。

**2026-09-22 に実際にそうした。** スウェーデン到着日の配信が取り込めたかを
`videos` テーブルで見たかったが BigQuery が切れていたので、
**`countryStats.ts` にスウェーデンの行（`msgs: 1232`）が出たことで裏を取った。**

---

## 5. Actions 側は別物（切れない）

**管理スクリプト（`run_admin_script.yml`）は、この箱の MCP を使っていない。**
あちらは Actions のランナーで、自前の資格情報で BigQuery と Firestore を引く。

**つまり MCP が切れていても、`run_admin_script` 経由なら本番の数字を触れる。**

```
Actions > 管理スクリプトを実行 > script = <名前> / ARGS = {}
```

**ただし ARGS もログも公開。** 名前や書類IDを引数に入れないこと。

---

## 6. 気づくための決まり

- **引けなかったものを「無かった」に畳まない。** 数えるものが無いときは
  終了コード **2**（`0 = 通った / 1 = 見つかった / 2 = 測れていない`）
- 報告に「引けなかった … N個」を**必ず並べる。** 0 であることが、
  「測れている」の証拠になる
- **対照を先に当てる。** 在ると分かっているものを1つ測って、それが在ると
  出ることを確かめてから本番を測る
