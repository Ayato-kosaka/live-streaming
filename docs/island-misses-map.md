# 記録の決めごとの行き先

種別: 台帳

**`docs/island-misses.md`（記録）の節から出た決めごとが、仕様のどこに在るかの表。** 1つの決めごとに1行。
作る前に読むのは行き先の仕様で、記録ではない（`docs/README.md` D-4）。決めた理由は `docs/adr/0010-misses-to-spec.md`。

- 1行の決めごとは `python3 python/misses_rules.py` が記録から抜いたもの。番号 `#N-k` は節 `#N` の k 番目、`先-N` は記録の頭の「決めごと（先に読む）」
- 行き先の読みかた
  - `§N` は `docs/island-standards.md` の N 章、`§N.M` はその条。`出す前のチェック` は同じ文書の末尾
  - `README D-n` は `docs/README.md` の決まり。`*.md` は `docs/` の仕様
  - `この節かぎり` は、その節の1件の直しそのもの（道具の名指し・その面だけの寸法や置き場）か、道具や面がもう無いもの。仕様には写さない
- 記録に節を足したら、同じ PR でここに行を足す（`docs/island-standards.md` §22）。抜けとずれは `python3 python/misses_rules_selftest.py` が止める
- 抜いた数はここに書かない。`python3 python/misses_rules.py --count` が数える（D-7）
