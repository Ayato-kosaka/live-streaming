# 卓上カレンダー（SUZURI）の作りかた

2027年版を 2026-10 に作った記録と、**来年もう一度作るときの手順**。
決めごとのやりとりは #759（型を選ぶ）と #786（月ごとの絵）にある。ここは結論と、繰り返すための道だけ。

## 1. 何を作ったか

- **SUZURI の卓上カレンダー**（12ページ・表紙なし・1月はじまり）。出すのは**正方形の絵を12枚**で、
  暦の面付けは SUZURI が持つ。こちらで暦を描かない
- コンセプトは **「あの時の思い出が蘇る」**（あやと 2026-10-12）。暦の N月のページに、
  その1年前後の**同じ月の思い出**を1枚。2027年版は暦1〜10月＝2026年の同じ月、11・12月＝2025年
- 絵は ChatGPT で描いた、実写寄りの景色＋**住人は小さな人形の姿で景色の中にひっそり**。
  あやとは場面に合わせて「後ろ姿の人」か「サングラスのちびキャラ」（そろえない。あやと「適材適所」）
- **住人は、その月の投げ銭ランキング上位7人**（同額の7位は全員。図鑑に絵の無い人は入れない）
- 右下に**画家のサインのような細い字の一言**を1行（年月も `ayato` の名前も入れない）。
  最初は太い丸文字にふちと年月を付けていたが、悪目立ちした（あやと「絵画にサインしてる感じ。文字も絵になると邪魔にならない」）。
  次に2行を1行にした（あやと「フォントは良い感じ。1行にしたい」）。2行をそのままつなぎ、**読点・句点・空白は入れない。**
  4月だけ「トビリシにさよなら、アルメニアへ」と読点を入れる（あやとの指定）
- できあがるまでは `/goods` の「カレンダー」の欄に月のタブで並べ、付箋で場面の注文を受けていた。
  **出品した 2026-10-14 に欄ごと消して、付箋も閉じた**（あやと「カレンダー検討中の項目は削除して、付箋も閉じて」）。
  いまは `/goods` の SUZURI の升目の3つ目（全部見る → トート → カレンダー）が入口。
  焼いた絵（`site/public/goods/calendar/`）は SUZURI に上げる元と来年の見本として残してあり、面からは指していない

**最初に「いいねで型を選ぶ」試作（イラスト／海外の風景／配信のスクショ）を出したが、
あやとが見本の絵を作ってきて、イラストに決まった。** 来年は型選びから始めなくてよい。

## 2. 手順（来年も同じ形で回す）

| 順 | やること | 道具 |
| --- | --- | --- |
| 1 | **月ごとの思い出を掘る。** 配信の一覧・チャットの山・料理・行事から、月ごとにテーマ案を3つ | BigQuery（`youtube_chat.videos` / `chat_messages`）、`site/content/` の焼き込み。`/clip-cut` の山の数え方が使える |
| 2 | **テーマ案を issue であやとに見せる。** 絵を作る前に（作ってから直すと手戻りが大きい） | `/ask-ayato` |
| 3 | **月ごとの上位7人を数える** | `tools/goods/calcast/rank.sql`（`periods` を変える） |
| 4 | **住人の見本を作る**（番号だけ・名前なし） | `tools/goods/calcast/sheet.py` |
| 5 | **ChatGPT で描く。** 見本の絵（タッチ）と住人の見本を毎回添付。1枚ずつ頼む。候補は月3枚 | `/chatgpt-image`、頼みの文の形は `tools/goods/calcast/swap-prompt.txt` |
| 6 | **1枚ずつ自分の目で見る**（下の 3） | |
| 7 | **8位以降も小さく隠して描く**（2026 で足した。図鑑に絵のある人を「ウォーリーをさがせ」の大きさで）。ChatGPT は絵ぜんぶを描き直すので、返ってきた絵は使わず、**足された住人の画素だけを決まった元絵へ移す** | `/chatgpt-image`、やり方と見比べは `tools/goods/cal-cands/README.md` の `hidden/` |
| 8 | 元絵を `tools/goods/cal-src/<MM>-a.png` に置いて焼く。一言は焼くときに重なる | `tools/goods/calbake.py`（一言の表は `SIGNS`） |
| 9 | 焼いた絵を並べてレビューを回す（2026 は `/goods` に欄を作って出した。出品の日に欄は畳む）。選ばなかった候補は `tools/goods/cal-cands/` に残す | `/island-ship` |
| 10 | SUZURI に上げる正方形を書き出す | `python3 tools/goods/calbake.py --print <置き場>` → `/suzuri` |
| 11 | `/goods` の SUZURI の升目に1マス足す（写真を焼く・`SHOP_GOODS` に1件・台帳を取り直す。トートの次に置く） | `tools/goods/shopgoods.py`、`site/content/goods.ts` の `SHOP_GOODS` の注 |

## 3. 絵を通す前に見ること

ChatGPT は「描き直して返す」ので、毎回ずれる。**数で見られないところは目で見る。**

- タッチが見本と同じ世界か（フラットなアニメ調に崩れていたら落とす）
- 住人が**全員1回ずつ**か。足りない・同じ子が2回・見本に無い子、は落とす。1体ずつ数える
- 住人が大きすぎないか（人の姿の住人は**等身大の人間**に描かれがち。2026年1・3月で起きた）
- テーマの具体物が入っているか（12月なら大雨・花火・横一列のジャンプ）
- 余計な字・崩れた字が無いか（地面に数字の「6」、包み紙に字のような模様、が出た）
- **住人だけ入れ替える**頼みでは、元の絵と並べて**入れ替えた場所の外が変わっていない**か

## 4. 気をつけること（2026 に踏んだもの）

- **ChatGPT に視聴者さんの名前を渡さない。** 住人は番号の見本で渡す
- **私人の写真（あやとが送ってくれた人の写真）はリポジトリにも面にも置かない。**
  ChatGPT への添付だけにし、絵では写真のまま描かず人形寄りの姿にする
- **既成のキャラクターにそっくりな住人がいる**（黄色いねずみ・トナカイの船医など）。
  ChatGPT が「第三者の作品に似すぎる」と断ることがある（新しい会話で頼み直すと通った）。
  売るときにどうするかはあやとが決めた（2026: そのまま）
- **月の途中で数えたランキングは確定ではない。** 2026年10月は 10/11 夜までの並びで描いた
  （あやとの判断で、そのまま確定にした）。来年は作る時期と締めの月が重なるかを先に見る
- **EC2 は、起こしたときにもう動いていたら止めない。** 誰かが使っている。2026-10-13 に、
  確かめに使ったあと止めてしまい、すぐ起こし直した
- 一言は絵の幅の 2.6% の細い字（Zen Kurenaido）で、ふちは付けない。**読めないときは、ふちに戻さず影の濃さか置き場で直す**
  （`calbake.py` が字と地の比を測って落とす）。住人のいる月は字が体を横切ることがあるので、`SIGN_NUDGE` でずらす
  （2027年版は4月を左へ、9・10月を下へ）。**1行は横に長いので、角から離れた住人の足もとにも届く**——
  一言か絵を替えたら、12枚の右下を等倍で1枚ずつ見る
- 一言は**1か月1本の文字列**で、改行やタプルで2行に戻すと `calbake.py` が落とす。区切りを入れてよい月と字は
  `SIGN_PAUSE` に書く（2027年版は4月の「、」だけ）。それ以外の月に読点・句点・空白があっても落とす
