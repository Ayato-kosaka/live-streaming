# 0002 面は種類を1つ持ち、切り口は5つとする

- 日付: 2026-11-22
- 状態: 採用
- 決めた人: あやと（仕様）／運営（設計）
- 仕様の条: `docs/spec/model.md` M-1 M-2 M-6 M-20 M-21

## 状況
あやと（2026-11-22）:「回った国に北欧周遊がない。粒度・切り口が違う。設計の決めが甘くて、責務分離が甘い。企画はこういうもの、回った国はこういうもの、と決めないといけない。歩いた国のアルメニアに『イランまで歩きました』のブログが出来たら、伝説の企画のイラン旅と重なる」

数えた（master `aa11da4` と本番）。
- 「イランまで歩く」の話が5か所に手書き（伝説・アルメニア・イラン国境・旅の章・あやとのこと）。日数は12日と10日、起点はエレバンとアルタシャトと、面によって違う。北欧ヒッチハイクは4か所
- データでは結べるのに画面にリンクが無い組: 料理→国、国↔伝説、伝説↔料理、旅↔月、北欧以外の国→旅
- 結びかたが3通り混ざる: 名前の鍵、日付の重なり、リンク先の直書き。ほかに、街の名前の文字の一致、たまたま同じ字の id

## 決定
- 切り口を5つとする: 場所・旅・企画・配信・つくったもの。ほかに人と声
- 面は種類をちょうど1つ持つ。種類は切り口をちょうど1つ持つ
- 同じ事実・文章・数字は、持ち主の種類の1か所にだけ書く。ほかの面は札で引く
- 種類どうしを結ぶ鍵は、名前の鍵と日付の2種類だけとする
- 国をまたぐ体験の話は企画に、1つの街で完結する話は街の話題に、日ごとの記録は旅の1日に書く

## 理由
- 「どこ」「いつ・どの順」「何をやったか」は別の問いで、1つのものが3つの問いに同時に住むと、足すたびに置き場で迷い、書き写しが増える
- 書き写した文章は、片方だけ直されて食い違う（実際に5か所で食い違っている）
- 鍵を2種類に絞ると、片方を直したときに黙って切れる結びかたが無くなる

## 捨てた案
- **旅の下に国を入れる階層**（旅 → 国 → 街 を1本の木にする）。ジョージアのように1つの国が3つの旅に出るので、国の面が旅の数だけ要る
- **企画と旅を1つの種類にする。** 旅は時間を隙間なく割り、企画は重なる。性質が違うので、同じ表にすると不変条件が書けない
- **タグで自由に結ぶ。** 置き場が決まらないので、いまと同じ継ぎ足しになる

## 影響
- 札をひとりでに出す仕組みと、種類の表（#1357）
- 話と数字を企画の面1か所に寄せる（#1356）
