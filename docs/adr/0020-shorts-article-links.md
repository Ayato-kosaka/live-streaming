# 0020 ショートを出す回は島の記事を持ち、記事とショート・本編を双方向にリンクする

- 日付: 2026-11-26
- 状態: 採用
- 決めた人: あやと（仕様）／運営（設計）
- 仕様の条: `docs/guide-design.md` ★4「動画の欄」の記事の行

## 状況

あやと（2026-11-26・チャット。#1453）:

> ショート投稿する時に、（これから予約分で良い）
> あやと島の記事書いて欲しい。（既存のソフィアのガイドとかにリンクされてるやつわかりますか？あやと島カードの写真も使って。）
> で、その記事をショートと本編からリンクして、あやと島の記事からショートをリンクするという双方向にして欲しい。

街の面には動画の欄（★4。行った所の札のショート・面の下のショートの横並び）が在るが、記事（`/travel/<国>/<街>/<話>`）には
「この記事の配信」（アーカイブの一覧）しか無く、ショートを載せる欄が無かった。ショートと本編の説明にも、島の記事への道が無かった。

## 決定

- ショートを出す回は、その回の記事（街の話題）を持つ。無ければ書く。写真はその日の あやと島カード
- リンクは3本: ショートの説明（YouTube・TikTok・Instagram）→ 記事、本編（配信アーカイブ）の説明 → 記事、記事 → ショート
- 記事 → ショートは、記事の「この記事のショート」の欄（「この記事の配信」の前）。部品は街の面の動画の欄と同じ縦の枠
  （押すまでサムネイル・`VideoObject`）に、同じショートの TikTok・Instagram へのリンクを添える。**空の間は欄も目次の行も出さない**
- 欄の鍵は YouTube のショートの id。題と日付はショートの名簿（`content/shorts.ts`）が持ち、記事の台本には写さない。
  名簿に無い id（予約中・公開前）は焼く道具が止める

## 理由

- 新しい面・道・表は足さない。記事は既に在る種類（街の話題）で、ショートは既に在る表（ショートの名簿）の行。足すのは記事の欄1つ（`/feature-design` の 3-A）
- 予約中のショートは見られない。記事から先にリンクすると、公開までの間、死んだリンクを張ることになる
- TikTok・Instagram の投稿は島のどこにも名簿が無く、URL を持つ所が記事の台本しかない

## 捨てた案

- 記事の台本にショートの題を写す: 題の持ち主が2つになる（`docs/spec/model.md` M-20）。公開すれば名簿に入るので、待てばよい
- 予約した時点で記事にリンクを張る: 公開まで死んだリンクになる
- ショートを記事の頭（表紙の下）に置く: 記事は検索から来た人が読む面で、先に答え（★3）。動画は本文のあと、配信の一覧の前に置く

## 影響

- `components/travel/article/Article.tsx` の `Shorts`、記事の型の `shorts`、`python/guide_article.py` の確かめ
- 投稿の手順（`tools/shorts/post/README.md`「島の記事と双方向にリンクする」・`/viral-shorts-creator` 段7）
- 最初の記事はソフィアのメキツァ（③揚げパン）とビリヤニ（②）。記事がもう在る回（①ムサカ = ネフスキー大聖堂、④クリスマスマーケット）は、在る記事に欄を足す
