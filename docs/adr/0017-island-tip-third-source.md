# 0017 島で受ける投げ銭を3つ目の出どころとし、貢献額には払った額のまま入れる

- 日付: 2026-11-23
- 状態: 採用
- 決めた人: あやと（仕様: 貢献額への入れかた・ログイン・金額・コインの段階）／運営（設計: 決済・箱・届けかた）
- 仕様の条: `docs/island-money.md` 1章（式）・3章（名寄せ）、`docs/island-db.md` 4.2、`docs/island-api.md` 13章

## 状況

投げ銭の出どころは、スパチャと Doneru の2つだった。¥1,000 の投げ銭で、あやとに届くのはおおよそ次のとおり（#1405 に出どころつきで数えた）。

| 出どころ | 視聴者が払う | 届く |
| --- | --- | --- |
| Doneru | ¥1,000 | 約¥775〜800（1どね＝1.2円の上乗せ・決済手数料・振込手数料） |
| スパチャ（ウェブ・Android） | ¥1,000 | 約¥636 |
| 島で受ける（Stripe） | ¥1,000 | 約¥960（3.6%と、その消費税） |

あやとが「島に投げ銭をつけたい」と言い、#1405 で次を答えた（2026-11-23、チャット）。

> そうか、ストライプでも1000円の投げ銭で960円届くのか。A案で良い。

> 投げる人はGoogleのYouTubeのログイン。（略）YouTubeのログイン必須にさせたいです。

> 12秒ってことは結構遅れるな。ドネルとかスパチャとかは割と早く届いてるので、そのくらいの速さで届いてもらわないと困る気がする。

貢献額の式（`docs/island-money.md` 1章）は出どころを2つと決めていたので、3つ目を足すには式を変える必要があった。

## 決定

1. **島で受ける投げ銭を、3つ目の出どころとする。** 決済は Stripe Checkout。受け取るのはあやと本人だけ
2. **貢献額には、払った額のまま入れる。** `貢献額 = スパチャ ÷ 2 + Doneru + 島の投げ銭`。Stripe の手数料は引かない
3. **投げられるのは、YouTube のチャンネルを島に結んだ人だけ。** 名寄せは `channelId` でぴったり当てる。名前で当てない
4. **金額**: 最小 ¥100（入力欄の初期値も ¥100）。ボタンは ¥200・¥500・¥1,000・¥2,000・¥5,000・¥10,000 と自由入力。1人1日の上限は置かない。メッセージの字数と1回の上限は Doneru に合わせる
5. **コインは作らない**（段階1）。都度払いで動かし、コインは Stripe の確認のあとに別の決定で足す
6. **アラートへは約1秒で届ける。** Stripe の知らせを受けた口が、アラートの合言葉ごとの書類1枚に書き、アラート画面がそれをリアルタイムで購読する
7. **テストの支払い（Stripe のテスト環境）は、台帳・貯金箱・貢献額・配信に出ている本番のアラートのどれにも入れない**

## 理由

- **払った額のまま**: Doneru も手数料を引く前の額（どね）で入れている。島の投げ銭だけ手数料を引くと、同じ¥1,000が出どころで別の貢献額になる。スパチャを ÷2 にしているのは、YouTube の取り分が手数料の域を超えて大きいから（`docs/island-money.md` 1章「なぜ」）
- **YouTube のチャンネル必須**: Doneru は名乗りで当てていて、同じ名前の人がいると寄せられない（同3章）。チャンネルで当てれば、図鑑・カード・月末の順位が1本の鍵で揃う。いたずらの払い戻し請求（1件 ¥1,500）も減る
- **約1秒**: Doneru はつなぎっぱなしの接続で届き、スパチャも数秒で届く。12秒の口への相乗りは、あやとが求める速さに届かない
- **リアルタイム購読をアラート画面に持ち込む**: 島のほかの面では Firestore の SDK（縮めて約125KB）を外した（`site/lib/hereRest.ts`）。ログインしていない人にも乗る飾りだったから。アラート画面を開くのは OBS と PRISM だけで、段の動画を 23.7MB 持つので、ここでは釣り合う。2秒ごとに読む案は、開きっぱなしの晩に1日の読み取りの無料枠を食う
- **「寄付」と呼ばない**: Stripe は日本で「個人への寄付」を禁止している。自分のサイトで自分のコンテンツを出すクリエイターへの投げ銭は、事前の承認が要らない（Stripe の禁止・制限業種、2026-09-22 更新）。だから「メッセージを配信のアラートに出す」サービスとして出す

## 捨てた案

- **届いた額（手数料を引いた額）で入れる**: Doneru の扱いと食い違う
- **ログインなしで名前を書いて投げる**: Doneru と同じ名寄せの穴が、3つ目の出どころにもできる
- **12秒ごとの口（もう一度出す）に相乗り**: 接続は増えないが、最大12秒遅れる。あやとが退けた
- **Firestore を2秒ごとに読む**: 遅れは0〜2秒だが、1時間 1,800回の読み取り。開きっぱなしの晩に1日の無料枠（5万回）を食う
- **Functions から流しっぱなし（SSE）**: 開いているあいだ、関数が1本起きっぱなしになって課金される
- **最初からコインも作る**: Stripe は「売り手が自分で発行する残高」を上限の対象にしうる。確認が取れるまで先へ進めなくなる
