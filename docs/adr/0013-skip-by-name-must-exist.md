# 0013 見張りが外すものは名前で断り、断った名前が消えたら赤くする

- 日付: 2026-11-22
- 状態: 採用
- 決めた人: 運営（設計）
- 仕様の条: `docs/island-standards.md` §25.1

## 状況
記録の決めごとを仕様へ写したところ（0010）、2つが食い違って読めた。
- `island-misses.md` #141 の決めごと1:「拾い方は『全部拾って、外すものだけ名前で断る』」（回すものを表に並べると、足した日に書き足し忘れても赤くならないため）
- `island-misses.md` #200 の決めごと5:「『見ない』で黙らせない。名指しで除くと、そのファイルが本当に消えた日も黙る」

前者は名前で外せと言い、後者は名前で外すと黙ると言っている。

## 決定
- 両方を1つの条にする: 見張りは全部拾い、外すものだけを名前で断る。**断った名前が在るかも見て、消えていたら赤くする**
- 断る理由は名前と並べて印字する（#141 の `SKIP` の形）

## 理由
- #141 が守っているのは「足したものが黙って拾われない」こと、#200 が守っているのは「外したものが消えても黙る」こと。向きが逆なだけで、どちらも黙るのを止めたい
- 断った名前の在る・無しを見れば、両方の穴が同時に塞がる

## 捨てた案
- **名前で外すのをやめ、形（拡張子・置き場）で外す。** 形で外すと、外したくないものまで同じ形なら黙って外れる
- **#141 だけを採る。** #200 で実際に踏んだ「消えた日も黙る」が戻る

## 影響
- `docs/island-standards.md` §25.1 に、断った名前が消えたら赤くすることを書いた
- 既に名前で断っている見張りのうち、断った名前の在る・無しを見ていないものは、触るときに直す（§5）
