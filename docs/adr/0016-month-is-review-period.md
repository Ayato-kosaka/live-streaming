# 0016 月の期間は、ふりかえりの面が数える期間（前の月末配信の日〜今回の月末配信の前日）とする

- 日付: 2026-11-23
- 状態: 採用
- 決めた人: 運営（設計）。期間そのものはあやと（2026-09-26。`docs/island-money.md` 5章）
- 仕様の条: `docs/spec/model.md` 3章の種類の表の「月」、6章「引きかた」の「月に居た国・旅・企画」

## 状況

仕様は「月」を**暦のひと月**と定めていた。一方で、月の面（`/months/<月>`）と、お金の式（`docs/island-money.md` 5章）は、
ひと月を**前回の月末配信の日〜今回の月末配信の前日**で数えている（あやと 2026-09-26「月初〜月末」ではない）。
出席の分母・投げ銭・はじめましての人数・配信の本数は、どれもこの期間。焼くのは `python/build_monthly.py`、
期間は `content/months.ts` の `from` `to` に入っている。

W10（#1357）で、国・旅・企画の面と月の面を札で結んだ（`site/lib/tags.ts`）。札を暦のひと月で引くと、
月の面が数えていない日の国が札に出る。2026年10月の面は 9/26〜10/30（の前日まで）を数えていて、暦で引くと
10/31 の国が出て、9/26〜9/30 のアルバニアが出ない、という食い違いになる。

## 決定

**月の期間は、ふりかえりの面が数える期間とする**（前回の月末配信の日〜今回の月末配信の前日）。
月どうしは隙間も重なりもなく並ぶ（前の月の終わりの翌日が、つぎの月の始まり）。

月の札（その月に居た国・旅・企画／国・街・旅の「いつ居たか」の月）は、この期間と重なるもので引く。
**月の面がまだ無い月**（月末配信の前）は、暦のひと月で引く（`lib/tags.ts` の `monthSpan`）。

## 理由

- 月の面は「このひと月」をこの期間で語っていて、数字もこの期間。札だけ暦で引くと、同じ面の上で
  「この月に居た国」と「この月の配信」が別の期間を指す
- 期間の持ち主は月末配信（あやとの決定）で、暦ではない。札が別の期間を持つと、期間の持ち主が2つになる（M-20）

## 捨てた案

- **暦のひと月のまま、札だけ合わせる**: 仕様と実装が食い違ったまま残る。読む人が「月」の意味を2つ覚えることになる
- **月の面を暦のひと月に直す**: お金の式と出席の分母があやとの決定で動いているので、面の側は動かさない

## 影響

- `docs/spec/model.md`: 3章の「月」の定義と、6章の「月に居た国・旅・企画」の行を直した（この PR）
- `site/lib/tags.ts` の `monthSpan` は、すでにこの期間で引いている（#1357）
