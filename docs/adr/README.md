# 決定の記録

**1つの決定を、1枚に書く。** 何を決めたか・なぜか・何を捨てたかを、あとから引けるようにする。
仕様（[`../spec/`](../spec/)）は「いま決まっていること」だけを持ち、経緯を持たない。経緯はここが持つ。

## 決まり

- **A-1** 仕様を変える前に、ここに1枚書く。仕様の変更と同じ PR に入れる。
- **A-2** 1枚に、決定は1つ。題は、決めたことを1文で言う。
- **A-3** 書いたら直さない。誤字と、リンク切れだけは直してよい。
- **A-4** 取り消す・変えるときは、新しい1枚を書き、古い1枚の「状態」を `置き換え（→ 番号）` にする。古い1枚は消さない。
- **A-5** 番号は4桁の通し番号。空きを作らない。
- **A-6** あやとの言葉は、日付つきでそのまま引く。視聴者さんの素性は書かない。
- **A-7** 決めたのが仕様（あやとが何を求めているか）か、設計（どう作るか）かを書く。仕様はあやとが決め、設計は運営（Claude Code）が決める。

## 雛形

```markdown
# NNNN 決めたことを1文で

- 日付: YYYY-MM-DD
- 状態: 採用
- 決めた人: あやと（仕様）／運営（設計）
- 仕様の条: `docs/spec/…` の何条

## 状況
何が起きていて、何を決めなければならなかったか。数えたものは数で。

## 決定
決めたこと。「〜する」「〜しない」。

## 理由
なぜそう決めたか。

## 捨てた案
ほかに何が在って、なぜ採らなかったか。

## 影響
何が変わるか。直す作業（issue）。
```
