# 0004 企画の表を1つにし、伝説はその印とする。移動と滞在は企画にしない

- 日付: 2026-11-22
- 状態: 採用
- 決めた人: あやと（仕様）／運営（設計）
- 仕様の条: `docs/spec/model.md` M-3 M-4 M-16

## 状況
あやと（2026-11-18）:「企画というのが要らない。企画を出す人も付箋でやってる。企画は付箋に統合したい」「伝説の企画は、初見さんが来たときに面白い」
あやと（2026-11-22）:「企画はこういうもの、と責務分離をしっかり」

数えた。
- `content/plans.ts` に、移動・滞在／単発の出来事／月末配信が混ざっている。企画は「日付のある出来事」の型なので、滞在を入れると「〜へ移動」「進行中」になり、日付で終わる
- `content/legends.ts`（9件）と企画の表は結ばれていない。`nordic` が同じ字なだけ
- 視聴者さんが企画を出す道は 2026-10-01 に畳んであるが、口8本のうち4本・机の道具・`/me` のタブが残っている

## 決定
- 企画は種類として在る。定義は「名前のついた挑戦・祭り・節目。始まりと終わりが在る」
- 企画の表は1つ。伝説は、企画に付く印（殿堂入り）とする
- 移動と滞在は企画ではない（滞在の表へ）
- 旅そのものが企画のとき（北欧ヒッチハイク・イランまで歩く）だけ、企画が旅を名前の鍵で指す
- 視聴者さんが口を出す先は付箋1つ。お題は、企画か国か日付に結ぶ
- 企画を並べる面（`/next`）と、企画を登録・操作する道具は畳む（0006）

## 理由
- あやとが要らないと言ったのは、企画の面と登録の仕組み。伝説の企画は残したい。両方を満たすのは「種類は在る、専用の面と道具は要らない」
- 伝説を別の表にすると、企画が伝説になった日に、同じ話を2つの表に書くことになる

## 捨てた案
- **企画という種類を無くし、単発の出来事を日付つきのお題にする**（2026-11-18 の案）。お題は声の入れ物で、話と数字の持ち主になれない。伝説との線も切れる
- **北欧とイランの島だけ、伝説の企画の下に置く**（2026-11-18 の案）。旅によって置き場が変わる決め方で、あやとの指摘（2026-11-22）で取り消した
