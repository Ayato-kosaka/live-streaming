# 0019 島の投げ銭は、そのとき配信していれば、案内鳥のチャンネルから配信のチャットに1行書く

- 日付: 2026-11-23
- 状態: 採用
- 決めた人: あやと（仕様: 書くアカウント・いつ書くか・何を書くか・テストの支払い）／運営（設計: 配信を探す鍵と書く鍵・書く回数・待つ上限・鍵が無いあいだ）
- 仕様の条: `docs/island-api.md` 13章「配信のチャットに書く」

## 状況

島で受ける投げ銭（決定の記録 0017）は、払い終わると配信のアラートに出る。Doneru の投げ銭は、それに加えて
配信のチャットに `〇〇 1000 円、投げ銭ありやと！` と1行書かれる。島の投げ銭には、チャットに残る1行が無かった。

あやとが #1405 で次を答えた（2026-11-23、チャット）。

> 案内鳥のチャンネルを作って。プロフィールもしっかりして。

> 配信していないときに投げられたらださない

書く1行の形・テストの支払いの扱いも、同じ日に #1405 で決まった（決まったことの表は #1405 の 2026-11-23 のコメント）。
決まったのは issue のコメントの上だけだったので、仕様（`docs/island-api.md` 13章）に写す。

## 決定

1. **本番の支払いを書けたとき、そのとき配信していれば、YouTube の配信のチャットに1行書く。** 書くのはチャンネル「あやと島案内鳥」
2. **形は `〇〇さん ¥1,000 島の投げ銭ありやと！「メッセージ」`。** 名前・額・メッセージは、配信のアラートに出すものと同じ字。額は3桁で区切る。メッセージが無い・禁止ワードに当たったときは「」ごと出さない。名前が無いときは「名無しさん」（「さん」を重ねない）
3. **配信していないときは書かない。** あとからまとめて書くこともしない
4. **テストの支払い（`livemode` が偽）は書かない**
5. **配信を探すのはあやとの鍵、書くのだけ案内鳥の鍵**（設計）
6. **書くのは、知らせを受けた口が取引を済ませたあと、`written` のときだけ。** Stripe の再送（`already`）では書かない。書けなくても知らせには 200 を返す。YouTube を待つのは4秒まで。書き直さない（設計）
7. **案内鳥の鍵が無いあいだは書かず、ログに1行だけ残す。** 口は止めない（設計）

## 理由

- **案内鳥のチャンネルで書く**: 視聴者さんに見せるところでは「あやと島案内鳥」と名乗る（`docs/island-standards.md` §17）。あやと本人の鍵で書くと、あやとが自分で書いた1行に見える
- **探す鍵を分ける**: 配信を探す `liveBroadcasts.list`（`broadcastStatus`）は、鍵の持ち主の配信だけを返す。案内鳥の鍵で探すと、案内鳥の（無い）配信を探して、いつも「配信していない」になる
- **`written` のときだけ**: Stripe は 2xx を受け取るまで、同じ知らせを何度でも送り直す。2xx を返したあとでも、同じ知らせが2回届くことがある。取引の中で `written` になるのは1通だけなので、そこに乗れば1回の支払いで書くのは1回になる
- **書けなくても 200・上限つき**: 台帳・貯金箱・アラートは取引で入り終わっている。チャットは添え物で、YouTube の遅れやしくじりで Stripe への返事を遅らせたり、送り直させたりしない。上限で返ったあとに YouTube が書き終えても、それは1回目で、2回目は起きない
- **書き直さない**: 2回書くと、1回の投げ銭が配信で2回読まれる。1回欠けるほうが害が小さい
- **鍵が無いあいだも口を配る**: 案内鳥のチャンネルと鍵は、Google の確認を挟むので別の担当が作っている途中。投げ銭そのもの（台帳・アラート）を、チャットの鍵で止めない

## 捨てた案

- **あやと本人の鍵で書く**: 本人が書いた1行に見える（§17）
- **案内鳥の鍵で配信を探す**: 案内鳥の配信を探してしまう（上）
- **配信していないときの分を、次の配信でまとめて書く**: あやとが退けた（「配信していないときに投げられたらださない」）
- **返事を返してから書く**: Cloud Functions は、返事を返したあとの処理が終わるまで動く保証が無い。書き終わらない晩がある
- **書いた書類を見る別の関数（Firestore のトリガー）で書く**: 返事は待たせないが、トリガーは同じ出来事で2回動くことがあり（少なくとも1回）、2回書かない守りを別に持つことになる。配る関数も1本増える

## 影響

- `functions/src/tip.ts`（書く1行を作る・`written` のときだけ書く・上限）、`functions/src/liveChat.ts`（案内鳥として書く）、`functions/src/youtubeClient.ts`（案内鳥の窓口。鍵は呼ばれたときに読む）
- `.github/workflows/firebase-functions-deploy.yml`: Secret `YOUTUBE_GUIDE_REFRESH_TOKEN` を `functions/.env` へ書く。空なら書かない（Stripe の2本と同じ形）
- `docs/island-api.md` 13章: 「配信のチャットに書く」を足した（この PR）
- YouTube の1日の割り当て（2026-11-23 に YouTube の表で確かめた）: 配信を探すのが1単位、書くのが20単位。配信中の投げ銭1件で21単位、配信していないときの1件で1単位。案内鳥の鍵はあやとの鍵と同じ OAuth のクライアントで出すので、同じ枠を使う
- 案内鳥をあやとのチャンネルのモデレーターにする（書いた1行が確認待ちに回されないように）のは、チャンネルを作る作業のほう（#1405）
- 視聴者さんに見せる額の表（`docs/island-money.md` 2章）には、配信のチャットの行がまだ無い。チャットに出す額はアラート（`islandAlertFeed`）に出す額と同じで、島の投げ銭は払った額のまま貢献額に入る（0017）ので、式は変わらない
