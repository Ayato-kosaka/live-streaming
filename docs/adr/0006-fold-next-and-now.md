# 0006 企画の面といまどこを畳み、状態を言うのは表紙だけとする

- 日付: 2026-11-18
- 状態: 採用
- 決めた人: あやと（仕様）
- 仕様の条: `docs/spec/model.md` M-31 M-32／`docs/spec/routes.md` R-24

## 状況
あやと（2026-11-18）:「企画というのが要らない」「いまどこも要らない。島のトップに『これから』でソフィアが出ていて、『あやとって、どんな人』にもバルカン周遊中と出るので分かる」「へ移動、は変。移動はもうしちゃってる。ソフィアに居る、は欲しい」「企画をぜんぶ見る、は要らない。自分もやってほしいことを出せる、は要る」

## 決定
- `/next`（企画の面）と `/now`（いまどこ）を畳む。建物・机の道具・島だより（ひとこと・今週やること）も外す
- 「いまここ・つぎ・今夜」を面として言うのは、表紙だけとする
- 表紙の「これから」は、着く前は「◯月◯日から ◯◯へ」、着いたら「◯◯」と［いまここ］。「〜へ移動」「進行中」「企画を、ぜんぶ見る」を出さない
- `/next` は `/board` へ、`/now` は `/` へ 301

## 理由
- 状態は場所ではない。建物にすると、表紙と同じことを言う面がもう1つ要り、そちらが古くなる（`/now` は 51日古かった）

## 捨てた案
- **`/now` を、いまの国の面へ転送する。** 旅が進むたびに転送先が変わる道になる（#1201 で無くした形）
