# 0003 居場所を手で書くのは、滞在の表1つとする

- 状態: 採用
- 決めた人: 運営（設計）

## 状況
「いま、どの国・街に居るか」を手で書いている所が5つ在った（2026-11-18）: Firestore `island/state.current`／`content/chapters.ts`／`AHEAD_COUNTRIES`／`COUNTRIES[].stays`／`content/plans.ts` の移動の企画。
- `/now` の島だよりは 2026-09-28 で止まり、51日古かった
- 表紙の「進行中 ブルガリア・ソフィアへ移動」は終わりを 11-19 と見立ててあり、まだ居るのに 11-20 に消える形だった（PR #1282 で止血）。同じ見立ては `spec.ts` の `GUIDES` にも在り、そちらだけ先に外してあった
- 国を移る手入れは最低3か所・ふつう5〜6か所で、常設の札 #664 が要っていた

あやと（2026-11-18）:「告知を入れ終わったら、その日が過ぎても進行中で出るようにしてほしい」「国を移るときは Claude に言う」

## 決定
- 居場所（予定を含む）を手で書くのは、滞在の表1つとする。置き場は Git（`site/content/`）
- 着いた国・章の国・案内の出し分け・表紙の「いまここ・つぎ」・毎晩の焼き直しは、滞在の表から引く
- 終わりの日を見立てで書かない。「いまここ」は、つぎの滞在が始まった日に入れ替わる
- 国は、着いた日に「歩いた国」へ入る（歩き終わるのを待たない）

## 理由
- 5か所は別々に古くなる。1か所なら、古くなる所が1つで済む
- 置き場が Git なのは、国を移るのを頼む相手が Claude Code だから。画面から書く道具（机の「いまどこ」）は 51日使われていなかった

## 捨てた案
- **Firestore に置いて机から書く。** 使われていなかった。静的書き出しなので、焼き直しと二重になる
- **企画の表に「滞在」の型を足す。** 企画は終わりの日を持つ出来事の型で、滞在に合わない

## 影響
- #1275（表を1つに）・#1276（表紙）・#1278（いまどこを畳む）。#664 の表が縮む
