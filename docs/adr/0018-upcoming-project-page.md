# 0018 始まる前の大きな企画にも伝説の道に面を持たせ、公開するまでは下書きの印で隠す

- 日付: 2026-11-23
- 状態: 採用
- 決めた人: あやと（仕様: 企画の中身と「動線はまだ繋がない」）／運営（設計: 道・印・持ち主）
- 仕様の条: `docs/spec/model.md` M-8（新）・M-21・M-33（新）、`docs/spec/routes.md` R-10

## 状況
あやと（2026-11-23、#1404）:

> インドの汚い屋台飯で100食食べるまで帰れません、っていう配信の企画考えてて。
> 今企画書から作ってほしいと思ってて。それを僕が承認したら実際にウェブサイトに作って。まだちょっと動線をつなげるのはまだ待ってほしいです。

企画書（#1404 の本文）は同じ日に承認された。作る前に数えた（#1404 の調べもの F）。

- 企画の面は、`content/legends.ts` の `PROJECTS.filter(isLegend)` だけが建つ。始まる前の企画には面が無い
- 企画・旅・滞在・お題の表には、下書きの印が無い。日付が先の企画は、表紙の「これから」と便りに出る（`lib/leadPlan.ts`）。旅の行は島の連なりと索引に、滞在の行は表紙の［つぎ］に、お題の行は掲示板の棚に、足した時点で出る
- 街には `draft: true` が在り、印1つで noindex・索引・サイトマップ・llms.txt から外れる（`content/cities.ts`）
- この企画のガイド（食べるべき100品・地域ごとの料理の違い）は、インドとスリランカの2国にまたがる

## 決定
- 企画は、伝説の印のほかに**面の印**を持てる。面の印の付いた企画は、始まる前から `/legends/<企画>` に面を持つ。伝説の丘（`/legends`）に並ぶのは、伝説の印の付いた企画だけとする
- 企画は**下書きの印**を持てる（街の `draft` と同じ意味）。下書きの企画は、面は在るが noindex にし、どの面からも引かない（表紙の「これから」・便り・掲示板・伝説の丘・索引・サイトマップ・llms.txt）
- 下書きの企画に結ぶ旅・滞在・お題の行は、印を外す日に足す。旅・滞在・お題には下書きの印を持たせない
- 2国以上にまたがる、その企画のためのガイド（選んだ品・地域ごとの違い）は、企画が持つ（M-21）。あとで国の面を作るときは、札で引く

## 理由
- 1つの企画の話は、予告・最中・結果まで1つの URL に置く（R-4）。始まる前だけ別の道に置くと、伝説になった日に 301 が要る
- 印を旅・滞在・お題にまで広げると、「いまここ」「つぎ」を引くところ全部に印の判定が要る。印は企画と街だけに留め、ほかは行そのものを足さない
- 2国にまたがるものを国の面に置くと、どちらの国にも半分ずつしか載らない

## 捨てた案
- **旅のしおり（`/island/<旅>/guide`）に置く。** 旅の行が要り、足した時点で島の連なりと索引に出る。企画の話（決まり・100食）は企画が持つ（M-20）
- **伝説の印を最初から付ける。** 殿堂入りの印の意味が崩れ、始まる前の企画が伝説の丘に並ぶ
- **新しい道（`/projects/<企画>`）を作る。** 伝説になった日に、同じ企画の2本目の道ができる（R-4）
- **国の面（`/travel/india`）に置く。** スリランカの分が入らない。国の行を足すと、歩いた国に出る

- 最初の1件は #1404（インド屋台飯100食）
