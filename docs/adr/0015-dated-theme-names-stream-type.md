# 0015 日を持つお題は、その日の配信の型を名前の鍵で指す

- 日付: 2026-11-23
- 状態: 採用
- 決めた人: 運営（設計）
- 仕様の条: `docs/spec/model.md` M-2 の「お題」の行・M-32

## 状況
告知の札の表（`site/content/plans.ts`）を畳んだ（#1277）。そこに字で残っていた月末配信の回（`monthly-2026-10`）の行き先は、M-32 の「定例の配信のつぎの回」として表紙の「これから」に出る、日を持つお題とした（ADR 0004・0006）。

お題の指す先は「企画（slug）か、国（slug）か、日付」の3つだけだった。日付だけでは、その日が**どの定例の配信の回か**が言えない。読む所が2つある。
- 表紙の「これから」の3段目（M-32）。押した先は、その配信の型の面（`/streams/<型>`）
- `/streams` の「今夜は◯◯の日」（`components/streams/Tonight.tsx`）。月末配信の夜だけそう言う

前の表は、行に `streamType: "monthly"` を字で持っていた。

## 決定
- 日を持つお題は、その日の配信の型（`content/streamTypes.ts` の slug）を名前の鍵（`stream`）で指してよい。日を持たないお題は持たない
- 定例の配信のつぎの回（M-32）は、`date` と `stream` を持つお題から引く（`lib/leadPlan.ts` の `AHEAD`）

## 理由
- 「月末配信の日か」を、題（「10月の月末配信」）の字や行き先の道（`/streams/monthly`）で当てると、M-6 の「名前の文字・リンク先の文字列で結ばない」に外れる
- 配信の型に「つぎの回の日」を持たせると、同じ日がお題と型の2か所に書かれる（M-20）。日はお題1か所に置き、型は鍵で指す

## 捨てた案
- **配信の型の表に回の日の並びを持たせ、お題は日付だけで結ぶ。** 日が2か所に書かれる。片方だけ直した日に、表紙と掲示板の締め切りが食い違う
- **日を持つお題は、どれも月末配信とみなす。** 2つ目の定例（年越し配信など）に日を立てた日に、黙って月末配信として出る

## 影響
- `site/content/themes.ts` の `Theme` に `date` `stream` `project` を足した（#1277）
- `docs/spec/model.md` M-2 の「お題」の行の指す先に、配信の型を足した
