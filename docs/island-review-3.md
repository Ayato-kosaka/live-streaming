
コントラストは **実際に描かれた画素**から測った。要素を撮って、いちばん多い色を地、
`getComputedStyle` の `color` を字とする（3パーセンタイルを字にすると、
中のアイコンや縁取りを字と取り違える）。**グラデーションの地は、字を `color: transparent`
にしてもう一度撮って、残った画素を地とした。** 4.5 : 1 を割ったら読めないものとする。

性能は書き出したもの（`.next-verify`）を静的に配って `perf.mjs`。**CPU は4倍遅くしてある。**
`crawl.mjs`（87面）と `noemoji.mjs` は通っている（bad 0 / リンク切れなし / 絵文字なし）。
`align.mjs` も「ズレなし」で通る（寄り・引きの20件とも dx=0、dy は最大3px）。

> **数字の但し書き。** このサンドボックスは8人で共有していて、測ったときの load average は
> 8〜21 あった。フレーム間隔は環境の影響を受けるので、島の性能は**4回測って幅で書いた。**

**次に測る人へ、この測り方の落とし穴を3つ。** どれも一度ずつ踏んだ。

1. **`color-mix()` は `rgb()` では返ってこない。** 計算後の値は `color(srgb …)` になる。
   `/rgba?\(/` で色を拾う正規表現を書くと、`color-mix` で作った地とふちを
   「透明」と読み違えて、親の紙の色を地にしてしまう。
   実際それで `/board` の `.signin-go` を「白い字が紙の上で 1.31 : 1」と誤判定した
   （本当は `color(srgb 0.14 0.32 0.33)` の濃い青緑の上で、読める）。
   **厚み（`0 Npx 0`）を数えるときも同じ。** 色を先に消してから数を読む
2. **要素だけを撮る（`elementHandle.screenshot`）と、揺れている物・畳んである物で
   時間切れになる。** `page.screenshot({ clip })` で撮る。ただし
   **`boundingBox()` を取ってから撮るまでに要素が動くと、まるで別の場所を撮る。**
   箱は撮る直前にもう一度取る
3. **大きい太字は、字そのものが最頻色になる。** 26px の白い見出しを撮ると、
   白が地として返ってくる（比 1.00 になって、逆に気づける）。
   **字を `color: transparent !important` にしてから撮り直す。**

**住人の名前と顔写真は、このサンドボックスでは出ない。**
`useResidentShow()`（`lib/liveStats.tsx:75`）が実行時に API を読む形なので、
`.who-name` は 0 個になる。**島の絵そのもの（キャラクター）は
`python3 tools/sprites/avatars.py` ＋ `route.mjs` の `offline()` で本物が出る。**

## 4. 「押せる厚み」と「地面に落ちる影」が、見分けられない形をしている

`island-world.md` 5.3 は2つを別のものと決めている。トークンの値がこう。

```css
/* app/css/tokens.css:197 */
--shadow-1: 1px 3px 0 rgba(52, 66, 32, 0.30);   /* 物が地面に落とす影 */
/* app/css/tokens.css:204 */
--pop-sm:   0   4px 0 var(--frame-dark);         /* 押せるものの厚み */
```

**違いは横 1px と縦 1px だけ。どちらもぼかし 0。** 遠目には同じ「下にずれた同色の板」で、
`island-design.md` 3章-3 の「合図は厚み1種類だけ」は、
**合図でないものが同じ形をしている**ので成り立たなくなっている。

そのせいで、21面を機械で数えると「押せないのに厚みがあるもの」がこれだけ出る:

| 部品 | 数 | どこ |
| --- | --- | --- |
| `h2`（紙のパネルの題名札） | **23** | `/about` `/apps` `/apps/nanitabeyo` `/board` ほか |
| `svg` | **20** | `/about` `/nordic/finland` |
| `details.fold` / `details.ty` | 10 | `/streams` |
| `p.gsay-bubble`（カモメの吹き出し） | 3 | `/board` `/kitchen` `/next` |
| `img` / `.aapp-logo` | 4 | `/next` `/apps` |

`ac-reference.md` 7章の決まり2は「**紙の型のカードに `box-shadow` は付けない**」。
`.panel.paper > h2`（`pages.css:639`）は `--shadow-1` を持っている。
紙に貼った札なので落ち影があること自体はおかしくないが、**厚みと同じ形をしている**のが問題。

**先に `--shadow-1` を直すほうが安い。1行で21面に効く。**
