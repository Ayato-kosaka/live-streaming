# いま島にいる人を、島に出す

**これは仕様である。** オーナーからの依頼:

> ログインしたら、そのログインしたチャンネルのアイコンをトップページの島の中に出せるようにしてほしい。
> で、それがトップページの島の中で操作したら、**他の人から見ても操作が動く、見える**ようにして。
> で、チャンネルのアイコンの右下とかに**オンライン中ってわかる**ようにしてほしい。
> で、例えば企画掲示板のページを見に行ったら、**企画掲示板のところにそのチャンネルのアイコンがいる**みたいな感じがいいかなと思います。
> **これはもう特にそのチャンネルのアイコンとかは押せなくて大丈夫**です。ただ動きが見れたら、
> 他の人から見たら、誰々さんがオンラインやみたいなのが見えたら面白いってだけです。

---

## 1. 何を作るか

- ログインした人の **YouTube のチャンネルのアイコン**が、島の上に出る
- **その人が動かすと、他の人の画面でも動く**
- アイコンの右下に **いまオンラインだと分かる印**
- **その人が見ているページの場所に立つ。** `/board` を見ていれば「企画をだす」の建物のそば
- **押せなくてよい。** 見えるだけ

## 2. 島の住人（キャラクター）とは別物

島にはすでに、視聴者さんが作った**キャラクター**が12人立っている（`content/residents.ts`）。
**あれは日替わりの顔ぶれで、その人がいまいるかどうかとは関係ない。**

ここで足すのは**「いま、ほんとうにここにいる人」**。
**同じ島に2種類のものが立つので、見た目で分ける。**

| | キャラクター（いまある） | いる人（これ） |
| --- | --- | --- |
| 絵 | 視聴者さんが作った絵 | **YouTube の丸いアイコン** |
| 押せる | 押すと喋る | **押せない** |
| いつ出る | その日の顔ぶれ | **いまページを開いているあいだだけ** |
| 印 | なし | **右下にオンラインの印** |

## 3. どうやって「他の人からも動いて見える」ようにするか

**いまの島は、ブラウザから Firestore を直接触らない**（全部 `islandApi` 経由、`firestore.rules` は全部 deny）。
その形のままだと、他の人の動きを見るのに数秒ごとに問い合わせることになる。
**「動いて見える」には足りない。**

**ここだけは、ブラウザから Firestore を直接読み書きする。** 新しいコレクションを1つ作り、
**そこだけルールを開ける。** 他は全部 deny のまま。

```
islandHere/{uid}
  at      いま見ているページ（"/", "/board" など）
  x, y    島の上の位置（ワールド座標）
  seenAt  最後に動いた時刻（サーバー時刻）
```

### ルール

- **読むのは誰でも。** ログインしていなくても、いる人が見える
- **書けるのは自分のぶんだけ。** `uid` がドキュメント ID と一致すること
- **書ける項目を絞る。** 上の4つ以外は受け付けない
- **`seenAt` はサーバー時刻でなければならない。** 手元の時計を書かせると、いつまでも「オンライン」でいられる

### なりすまし

**名前とアイコンを、このドキュメントに書かせない。** 書かせると、他人の名前を名乗れる。

名前とアイコンは **`islandApi` の `GET /state` が返す `residents`**（サーバーが本人確認したもの）から引き、
**チャンネル ID で突き合わせる。** つまり `islandHere` には**位置と時刻しか入らない**。

**ただし `islandHere` の鍵は `uid`、`residents` の鍵はチャンネル ID** なので、そのままでは結べない。
**ログインのときに、Cloud Function がチャンネル ID をカスタムクレームに入れる**のがいちばん素直。
そうすればルールでも `request.auth.token.channelId` が使えるし、突き合わせもできる。
**ここは実装の前に確かめる**（Admin SDK の `setCustomUserClaims`）。

## 4. 書き込みの回数を抑える

**指で動かすたびに書かない。** Firestore は書いた回数で課金され、読むほうも
「見ている人の数 × いる人の数」で効いてくる。

- **2秒に1回まで**。しかも**位置が変わったときだけ**
- ページを閉じたら消す（`beforeunload` と、`visibilitychange` で隠れたとき）
- **60秒より古い `seenAt` は、画面に出さない。** 消し忘れたぶんは、読む側で無視する
- 古いものの掃除は、毎日の集計ジョブのついでにやる

## 5. 出さない・やらない

- **人数を数えて出さない。** 「いま3人」は、たいていの時間帯に「1人」と出る
  （`docs/island-play.md` 仕掛け18。日単位の「今日◯人が来た」はすでにある）
- **誰がどこを見ていたかの履歴を残さない。** いまいる人だけ。過去は持たない
- **話しかける・つつくを作らない。** 押せなくてよい、と言われている

## 6. 島の外のページでは

**そのページの建物のそばに立つ。** `/board` を見ている人は「企画をだす」のそばに、
`/kitchen` の人は「作った料理」のそばに。

**島の外のページそのものにアイコンを出すかは、まだ決めていない。**
オーナーの言葉は「企画掲示板のページを見に行ったら、企画掲示板のところにそのチャンネルの
アイコンがいる」で、**島の上の話とも、そのページの上の話とも読める。**
まず島の上に出して、撮ってから決める。
