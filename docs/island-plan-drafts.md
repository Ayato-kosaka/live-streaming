# 企画のページを、視聴者さんと一緒に作る

これからの企画のページ（`/nordic` のようなもの）を、あやと1人で作らなくてよくするための仕組み。

## 入れ物は1つ（#161）

長いあいだ、企画は2つの入れ物に割れていた。

| | 何字 | ログイン | 誰が書けたか |
| --- | --- | --- | --- |
| `islandIdeas`（一言の提案） | 200字 | 要らない | 誰でも |
| `islandDrafts`（ページ1枚の下書き） | 12,000字 | 必須 | `canDraft` の人だけ |

**同じものの粒度違いなのに、一言を出したあと下書きへ進む道が無かった。**
あやとの言葉（2026-09-06）:

> ログイン不要、企画ページ1枚（12,000字。題・日付・場所・本文・リンク・写真）書ける。
> もちろんアイデア形式でざっくりでも良い。

いまは `islandNextPlans` 1つ。**題ひとつで出して、あとから育てる。**
欄の一覧は [`island-db.md`](./island-db.md) にある。

## 流れ

1. `/board`（企画をだす）で **題ひとつ**を出す。ログインも名前も要らない
2. 出したその場に「くわしく書く」が出る。押すと `/next/new?id=…` へ
3. そこで日にち・場所・本文・リンク・写真を足す。**何回でも、あとからでいい**
4. ハートが集まったものを、週のはじめの会議で見る
5. 日にちが決まったら、あやとが段を「これから」に動かして、
   `site/content/plans.ts` にページを1枚立てる。`planId` で結び付ける
6. 大きい企画なら `/nordic` のように専用ページを足し、`plan.href` でつなぐ

はじめからページ1枚ぶん書きたい人は、`/board` の「はじめからページ1枚で書く」から
`/next/new` へ直接行ける。

## 誰が書けるか

**誰でも。** ログインは要らない。

直せる人だけは分けてある。ログイン不要にした以上、本人の証は端末の印（`cid`）しか無く、
印を推測できれば他人の企画を直せてしまうため（あやと承認済み・#161）。

| 出したとき | 直せるのは |
| --- | --- |
| ログインしていた | その人だけ。いつでも |
| ログインしていなかった | 同じ端末だけ。**出してから24時間だけ** |
| — | あやとはいつでも |

24時間の窓は、画面が**押す前に**言う（`/next/new` に「あと◯時間」と出る）。
過ぎたものには「直す」を出さない。押してから断られる形にしない。

## 段（status）

**提案 → これから → やった が1本**（#159 で決めた形）。
段を動かせるのはあやとだけで、`/board` の各企画に出る「段を動かす」から。

「これから」に上げるときは、Git 側の企画の id（`content/plans.ts` の `PLANS`、
`content/legends.ts` の `LEGENDS`）を一緒に入れる。**結び付けないと、
掲示板に出た提案と、実際に立っているページが画面の上で他人のままになる。**

**この5歩目は、忘れても分かるようにしてある。** ページを立てただけで段は動かないので、
清書したのに「提案」の札が付いたままになる（ジョージアバイバイが実際にそうだった）。
題も日付も同じ企画ページが Git 側にあるのに結び付いていない行は、`/board` で
あやとにだけ「食い違っている」と出て、「段を動かす」の欄に id が先に入っている。
**結ぶのは押したときだけ。** 同じ id を2つの行が持つことはできない（サーバーが 409 で断る）。

## API

| メソッド | パス | 誰が | 何をする |
| --- | --- | --- | --- |
| `GET` | `/island-api/nextplans` | 誰でも | 一覧。`?archived=1` はあやとだけ |
| `GET` | `/island-api/nextplans/:id` | 誰でも | 1件 |
| `POST` | `/island-api/nextplans` | 誰でも | 出す。題だけでいい |
| `POST` | `/island-api/nextplans/:id` | 出した人 | 育てる |
| `POST` | `/island-api/nextplans/:id/heart` | 誰でも | ハート。もう一度押すと外れる |
| `POST` | `/island-api/nextplans/:id/status` | あやとだけ | 段を動かす |
| `POST` | `/island-api/nextplans/:id/archive` | あやとだけ | しまう・戻す |

1日12件まで（出すのも育てるのも同じ枠）。1件12,000字まで。

**古い口（`GET/POST /ideas` `/drafts`）はまだ動いている。** Functions と Hosting は
別々に手で起動するので、片方だけ先に出た日に画面が 404 で止まらないようにしてある。
畳むのは #171。
