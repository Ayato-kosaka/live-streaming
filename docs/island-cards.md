# あやと島カード

**これは仕様である。** その日に投げ銭してくれた人へ、その日の写真が1枚ずつ渡る。
[`nordic-photos.md`](./nordic-photos.md) の写真の上に成り立っているので、そちらも読む。

---

## 1. 何をするものか

**その日の配信で投げ銭してくれた人が、その日の写真をもらう。**
あやとの言葉:「焼き込みをしようがしまいがあやと島カードはゲットした扱いになります。」

写真の上に、その人のキャラクターが1体立っている。それだけ。
順位でも点数でも称号でもなく、**その日そこにいたという事実だけ**が残る
（`nordic-photos.md` 2章と同じ考え方）。

もらったカードは、じぶんのこと（`/me`）に**勝手に増えていく**。
「もらう」を押す場所はどこにも無い。

## 2. カードは配らない。引くときに組み立てる

**ここがこの機能の芯。**

```
カード = その日の写真（nordicPhotos） × その日の名簿（nordicDays.people）
```

「写真を貼ったら、その日の人ぶんカードを作って置く」にしてはいけない。
**名簿は BigQuery から翌朝に入る**（`python/nordic_supporters.py` が毎朝置く）。
写真を貼った夜の名簿は空なので、配る作りだと**その日ぶんが永久に0枚になる。**
あとから名簿が入っても、配る合図はもう過ぎている。

だから置き場には何も配らない。読むたびに掛け合わせる。
こうすると **写真が先でも名簿が先でも同じ結果**になる。

| 何 | どこから |
| --- | --- |
| カードのID | `<写真のID>__<チャンネルID>`。決め打ちなので、両方そろえば勝手に存在する |
| 置き方の既定値 | IDから決まる（`defaultPlace`）。毎回同じ場所に立つ |
| 動かしたぶん | `islandCards/{cardId}` に**上書きだけ**。動かしていないカードは1行も無い |

置き方は `x` `y` `rot` `scale`（あやとの「理想はXY軸、回転、拡大などをもってほしい」）。
`x` `y` は写真に対する 0〜1 の割合で、`y` は**足元**の高さ。焼いた絵は置き場に持たない。
同じ写真に何人も乗るので、焼くと同じ写真を人数ぶん置くことになる。

既定値の芯は**見本の右下**（`nordic-photos.md` 5章）。そこから ID で少しだけ散らす。
同じ写真に何人も乗るとき、全員が寸分たがわず同じ場所に立つと、
並べたときに「同じ絵が人数ぶん」に見えるため。

## 3. 誰のカードか

名簿は YouTube のチャンネルIDを持つ。ログインしている人とは
`islandUsers/{uid}.channelId` で結び付く。**自分のカードとは、自分のチャンネルIDのカード。**

**`icon` しか無い人（Doneru の人）は、持ち主が分からない。**
あの人たちは `python/admin/nordic_supporter.py` から手で足されていて、
YouTube のチャンネルを持っていない。**カードは存在するが、誰のマイページにも入らない。**
勝手に誰かのものにしない。

キャラクターの絵をチャンネルに結び付けるのは `site/content/residents.ts` だけ。
**サーバーは絵を知らない**（絵の割り当てが2か所に散らないようにするため。
`python/build_residents.py` の頭に同じ話がある）。絵に結びつかない人のカードは、
画面に出ない。「あなたのキャラクターがありません」とは言わない。

## 4. どこに出るか

| どこ | 何を |
| --- | --- |
| `/cards` | 配られたカードぜんぶ。新しい順。面の名前は「あやと島カード」 |
| `/about` の「住んでる人」の下 | 最近の2枚と、`/cards` への札 |
| `/friends` | 図鑑の1枚の中に、その人のもらったカード |
| `/me` | 自分のカードが勝手に増えていく |

**URL は `/cards`。** 日本語の URL は貼ると `%E3%81%82…` に化けるので、
「あやと島カード」は面の名前としてだけ出す。

カード1枚には**その日の企画**も出す（あやとの「フードワインフェスの企画に紐つけて欲しい」）。
**紐は日付1本**で、カードにも写真にも企画の欄は無い。
`content/plans.ts` の `date` が写真の `day` と同じ形なので、そのまま引ける
（`PLAN_BY_DAY`）。長い企画（`until` を持つもの）は始まった日にしか付かない。
旅の写真ぜんぶに同じ名前が並ぶと、何も言っていないのと同じになるため。

## 5. 動かす

置き方を動かせるのは**本人だけ**（`POST /cards/{cardId}`）。あやとは全部動かせる。
自分のカードかどうかは、送られてきた値ではなく `islandUsers/{uid}.channelId` で決める。

**動かす画面はまだ無い。** 口と持ち方だけが先にある。

## 6. どこを触ればいいか

| 何 | どこ |
| --- | --- |
| 組み立てと口 | `functions/src/cards.ts`（`islandApi.ts` には取り付けだけ） |
| 1枚の見た目 | `site/components/cards/CardOne.tsx` |
| 絵の突き合わせ・取得 | `site/components/cards/cards.ts` |
| 見た目の決まり | `site/app/css/cards.css` |
| 企画の表 | `site/content/plans.ts` の `PLAN_BY_DAY` |
