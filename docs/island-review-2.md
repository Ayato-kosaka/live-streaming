## 1. 紙の面の上では、押せるチップの厚みが消えている（`.panel.paper` が消している）

**いちばん効く。** 1周目の 7.3 で直したはずのものが、**別のファイルから戻っている。**

`pages.css` は正しく直っている。

```css
/* app/css/pages.css:800 */
a.chip, button.chip, .chip.link {
  min-height: 48px;
  box-shadow: inset 0 1.5px 0 rgba(255,255,255,.8),
              0 6px 0 color-mix(in srgb, var(--frame) 58%, var(--frame-dark));
}
```

ところが `atlas.css` に、あとから読まれる詳細度の高い規則がある。

```css
/* app/css/atlas.css:752 */
.panel.paper :is(.chip, .stat) {
  box-shadow: none;              /* ← 押せるチップの厚みも消す */
  border: 1.5px solid var(--pg-rule);
  background: color-mix(in srgb, var(--paper) 82%, var(--pg-sheet));
}
```

`.panel.paper :is(.chip)` は詳細度 (0,3,0)。`a.chip` (0,1,1) と `.chip.link` (0,2,0) の
どちらにも勝つ。**紙のパネルの中では、押せるチップが平らになる。**

実測（`/next` の `.chip.link`「イランまで歩く」）:

| | 高さ | 角丸 | 厚み |
| --- | --- | --- | --- |
| いま | 48px | 999px | **`none`** |
| あるべき | 48px | 999px | `0 6px 0` |

`island-world.md` 3.4 の「押せる＝厚み／押せない＝平ら」が、
**紙の面ではまた成り立っていない。** 紙の面は21面のうち19面なので、ほぼ全面で効いている。

**直しかた。** `atlas.css:752` の対象から押せるものを外す。

```css
.panel.paper :is(.chip:not(a):not(button):not(.link), .stat) { box-shadow: none; ... }
```

`pages.css` にも `atlas.css` にも同じ内容の `.panel.paper` 規則が二重にある
（`pages.css:466-486` と `atlas.css:740-756`）。**同じことを2か所に書いているのが原因。**
`atlas.css` 側を消して1本にする。

触るファイル: `site/app/css/atlas.css`（740–756行）/ `site/app/css/pages.css`（466–486行）

## 3. `/nordic` と `/nordic/[国]` と `/now` が、まるごと板のまま

`island-world.md` 2章の表は、この3面を**紙**と決めている。実際は1枚も紙になっていない。

各面の `.panel` を数えた（390px）:

| 面 | `.panel` の数 | うち `.paper` | 押せないのに厚みのある箱 |
| --- | --- | --- | --- |
| `/nordic` | 7 | **0** | **8個** |
| `/nordic/finland` | 3 | **0** | 4個 |
| `/now` | 1 | **0** | 1個 |
| `/next/new` | 1 | **0** | 1個 |
| `/about` | 7 | 5 | 2個 |
| `/board` | 3 | 2 | 1個 |
| `/apps` `/apps/[アプリ]` `/map` `/map/[国]` | 2〜4 | 全部 | 0 |

いちばん大きいのが `/nordic` の `.tnow`（h1 とカウントダウンが入っている主役の箱）。

```css
/* app/css/nordic.css:19 */
.tnow {
  border: var(--bw-3) solid var(--frame-dark);
  box-shadow: var(--pop-lg), var(--shadow-3);   /* 厚み 8px ＋ 落ち影 */
}
```

実測 366×925px。**生成りの紙の地の上に、厚み8pxの板が925px積んである。**
`ac-reference.md` 7章が「これをやると同じ形の窓が延々と積まれて見える」と
名指しで禁じている形そのもの。しかも押せない。

**根っこは1つ。型が opt-in になっている。**

```tsx
// components/ui/Bits.tsx:49
export function Panel({ children, className = "" }) {
  return <section className={`panel ${className}`}>{children}</section>;
}
```

既定が板で、`<Panel className="paper">` と**書いた面だけ**が紙になる。
書き忘れた面は静かに板になる。実際 `paper` を渡しているのは
`/about` `/apps` `/apps/[slug]` `/design` `/map` `/map/[slug]` `/next` `/streams` `/streams/[slug]` の
9ファイルだけで、残りは全部落ちている。

**直しかた。既定をひっくり返す。**
`main.page` の中の `.panel` は紙、島とトップだけ板にする。CSS 1行で切り替えられる
（`tokens.css` が地でやっているのと同じやりかた）。

```css
body:has(main.page) .panel { /* 紙の型の見た目 */ }
```

板にしたい例外（`/next/new` の書く欄など）だけ `className="board"` で戻す。
**「書き忘れたら正しいほうになる」向きにしないと、面が増えるたびに同じことが起きる。**

触るファイル: `site/app/css/pages.css`（`.panel` 〜 `.panel.paper`）
/ `site/app/css/nordic.css`（19行 `.tnow`、`.nchero`、`.panel.is-map`）
/ `site/components/ui/Bits.tsx`（49行）
