# ③ あやとのステッカー（あやとの絵）をグッズにする

**先に [`ops.md`](ops.md) を読む。** ここは「絵をどこから取るか」と「題・本文」だけ。

## 1. 元絵のありか

| 絵 | どこ | 注意 |
| --- | --- | --- |
| 島にいるあやと | `tools/characters/isle-src/ayato.png`（1254px の原寸） | 島で配っている `site/public/characters/ayato.webp` は 442×640 に縮めた版。**グッズには原寸を使う** |
| 歩いているあやと | `site/public/goods/ayato-walk.png` | 透過のまま |
| ヒッチハイクするあやと | `site/public/goods/ayato-sticker.png` | 透過のまま。「STOP」の字が入っている |
| そのほか | `site/content/goods.ts` の `STICKERS` が名簿 | 1枚足されたら、ここを見る |
| ChatGPT で作った絵 | 共有リンク（`https://chatgpt.com/s/m_…`） | 下の 2 |

手元の絵は、スクラッチパッドで塵（alpha 8 未満）を落とし、中身で切ってから `ec2.py put` で EC2 に送る
（`prep()` が EC2 側でもう一度余白を整える）。

## 2. ChatGPT の共有リンクから取る

共通の土台の `fetch_image` を使う（SUZURI に限らない道具なので `ec2-chrome` に置いてある）:

```bash
python3 .claude/skills/ec2-chrome/ec2.py run <(echo 'cd /home/ubuntu/cdp && python3 cdp.py fetch-image https://chatgpt.com/s/m_… /home/ubuntu/suzuri/x.png') 150
```

絵の URL は数分で切れる署名付きなので、URL を写して後から取りには行けない。
2026-10-09 の2枚は 1254×1254 の PNG だった（カラーは青い四角の地まで描いてある絵、モノクロは透過の丸）。

## 3. 題と本文

題: **「あやと ― ○○」**（○○ は `goods.ts` の `name` と同じ）

本文: 1行目だけ絵ごとに書き、あとの2行は共通。

```
（1行目: その絵のあやとが何をしているか）
あやと（YouTube@あやとグルメアプリ）のライブ配信「あやと島」から、あやと本人がグッズになりました！
配信のおともに、旅のおともに。いつでも、どこでも、あやとと一緒に🏝️✨
```

| 題 | 1行目 | id |
| --- | --- | --- |
| あやと ― 島にいるあやと | スマホとタブレットを抱えて、今日もあやと島を歩いているあやとです。 | 21116647 |
| あやと ― 歩いているあやと | サングラスで、すたすた歩いていく横顔のあやとです。 | 21116648 |
| あやと ― ヒッチハイクするあやと | 親指を立てて「STOP！」。次の街まで乗せてもらう気まんまんのあやとです。 | 21116653 |
| あやと ― みんな大好き AYATO（モノクロ） | どこの街にもありそうな、みんな大好きなお店の看板になったあやとです。 | 21116656 |
| あやと ― みんな大好き AYATO（カラー） | （同上） | 21116745 |

**他社のロゴに似た絵は、題と本文にその会社の名前を入れない**（「みんな大好き LIDL なあやと」は
LIDL のロゴの色と形を借りている。あやと 2026-10-09: 出す、ただし名前は入れない）。

## 4. 作る

```python
t = fresh_tab()
src = prep("/home/ubuntu/suzuri/ayato-x.src.png", "/home/ubuntu/suzuri/ayprep/x.png")
mid = retrying(lambda t: create(t, src, "あやと ― ○○", "（1行目）" + AYATO_COMMON, 300))
```

縦長の絵（歩いているあやと）も、大きさは `layout()` が中身の縦横から決める。
作ったら `sheet()` で見本を見る。**頭がパネルの上端に付いていないか**（縦は横より少し大きく刷られる）。
