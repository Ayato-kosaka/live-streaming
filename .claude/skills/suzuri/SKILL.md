# SUZURI のグッズ

**1本のスキルで、ファイルを用事ごとに分けてある。** まずここを読み、用事のファイルへ進む。

| 用事 | 読むファイル |
| --- | --- |
| どの用事でも先に（ログイン・読み書き・絵の上げ方・大きさ・確かめ方） | [`ops.md`](ops.md) |
| 島に新しいキャラクターが入った／キャラの絵が描き直された | [`characters.md`](characters.md) |
| あやとのステッカー（や、あやとの絵）をグッズにする | [`ayato.md`](ayato.md) |

道具:

| ファイル | どこで動く | 何をするか |
| --- | --- | --- |
| `suzuri_ops.py` | EC2（`/home/ubuntu/cdp/`） | 読む・書く・上げる・消す・大きさを決める・見本を並べて焼く・**非公開で用意したものを決めた時刻に公開する（`publish`）** |
| `suzuri_calendar.py` | EC2（`/home/ubuntu/cdp/`） | 卓上カレンダー（API では作れない品目 733）を非公開で組む・12か月の見本を 1530px で取る（`ops.md` の「卓上カレンダー」） |
| `login.py` ＋ `login_ec2.sh` | EC2 ＋ 手元 | ログインの確かめ（`check`）と、切れていたときの Google ログイン（確認コードはあやとから） |

Chrome を起こす・固まったときの直し方は、ここには書かない。

## 決まっていること（あやと 2026-10-09、#731）

- **利益（トリブン）は 1アイテム 300円。** 全部そろえる（イギリスのトートだけ 1,000円で別物）
- **品目は5つ:** Sticker / Acrylic Key Chain / Tin Badge / Mug / Acrylic Panel。**大きさは絵ごとに合わせる**
- コンセプトは「架空のシェアハウス カサ・アヤト」から**「あやと島」に変わった。** 本文はあやと島の文。
  題の「カサ・アヤトの住人 ○」は、あやとの指定でそのまま
- 他社のロゴに似た絵を出すときは、**題と本文にその会社の名前を入れない**（Q4）
- 島の `/goods` 面の「SUZURI グッズ」欄の写真は、グッズを足しても差し替えない（#732）

## 出す前に、必ず目で見る

**API が 200 を返しても、絵は切れうる。** 作ったら売り場の見本を1枚に並べて `Read` で見る
（ワークフローの `sheet` → 成果物 `suzuri-sheet` を持ち帰る。手順は `ops.md` の 6）。缶バッジとアクリルパネルが切れていないか、
大きさがほかの住人とそろっているか（2026-10-09 に、見本を見て3回直した）。

## 公式の API と MCP について（2026-10-09 に読んだ）

SUZURI には **REST API**（`suzuri.jp/api/v1`、ユーザごとの API キー）と、**SUZURI MCP**
（`https://mcp.suzuri.jp/mcp`、Claude から OAuth で繋ぐ）がある。何ができて何ができないかは
[`ops.md` の「公式の API と MCP」](ops.md#公式の-api-と-mcp) に表にしてある。
**どちらで回すかの表は `ops.md` の同じ節にある。** API はドキュメントに無いが缶バッジとパネルの大きさも
保存できる（2026-10-09 に確かめた）。EC2 のスキルに残るのは、絵の差し替えだけ（見本を並べるのもワークフローでできる。#741）。

## 島の `/goods` から辿れるようにする（あやと 2026-10-13）

> 住人ページ、あやとステッカーページから「グッズを買う」ボタンで
> …スズリデザインページへの導線あると良い。
> **住人からもステッカーからも導線がないものは** … **SUZURI のグッズお店 に導線作ると良い**

デザインは題で3つに分かれる。**どこから行くかが、それぞれ別。**

| 題 | 島のどこから行くか |
| --- | --- |
| `カサ・アヤトの住人 ◯` | 住人の面 |
| `あやと ― ◯` | あやとステッカーの面 |
| **そのどちらでもない** | **`/goods` の SUZURI の欄**（`site/content/goods.ts` の `SHOP_GOODS`） |
| 非公開（題なし） | 売り場が無いので、どこからも行かない。Tシャツの**裏の絵**がこれ |

### グッズを作ったら、ここまでやって終わり

住人グッズとあやとステッカーは**面のほうが名簿から引く**ので、何もしなくてよい。
**どちらでもないものを作ったら、3つ置く:**

1. **写真を焼く** — `tools/goods/shopgoods.py` に1行足して回す。
   見本の URL は `suzuri_api.yml` の `command: sample` が出す
   （**`og.suzuri.jp` は使わない。** SUZURI の透かしとロゴが焼き込まれている）
2. **`SHOP_GOODS` に1つ足す** — id・題（**店と同じ字**）・写真
3. **台帳を取り直す** — `suzuri_api.yml` の `command: materials` を押して、
   出た行から `tools/sprites/shopgoods-census.json` の `designs` を作り直す

**忘れても気づける。** `tools/sprites/shopgoods_selftest.mjs` が、
`tools/goods/goods.json` に在って島に出ていないものを見つけて赤くなる
（毎 PR で回る）。台帳が古いままだと 3 だけ赤が残るので、そこで取り直す。
