# 視聴者さんのキーワードを見つける

**出すのはキーワードと、その根拠になったコメントまで。** 絵は描かない。

あやとがそれを見て、キャラクターにする。だから基準は「当たっているか」ではなく、
**その人が自分の絵を見て「俺だ」と思うか。**

## いちばん外しやすいところ（最初に読む）

**名前とアイコンを先に見る。** これを飛ばしてコメントだけ読むと、
**確定した5つのうち2つが永久に出てこない。**

@ゆずたつ-q3n で実際にそうなった。あやとが決めたのは:

> 柚子 / 黒いチワワ / 謎解き / 人差し指に冷えピタ巻く / 社畜のおっさん・奥さんと子どもがいる

**柚子は名前から。黒いチワワはアイコンから。** コメント1521件をいくら読んでも
出てこない。こちらが最初に出した3案（カンガ・マヨネーズ・ピラミッド）は
全部コメント発で、**1つも採用されなかった。**

順番はこう。

1. **名前**を分解する（ゆずたつ → 柚子）
2. **アイコン**を見る（黒いチワワ）。`islandChannels` に写真が入っている
3. そのあとでコメントを読む

## 出す数と形

**5つくらい。3つに絞らない。** 枠も固定しない。

そのかわり、**全部「絵にできる形」で書く。** ここが効く。

| だめ | いい |
| --- | --- |
| タプタプ戦士 | **人差し指に冷えピタ巻く** |
| 熱心なファン | 社畜のおっさん。奥さんと子どもがいる |
| 謎が好き | 謎解き |

あやとが「タプタプ戦士」ではなく「人差し指に冷えピタ巻く」を選んだのは、
**そっちが描けるから。** ラベルではなく、その人がやった動作を書く。

## コメントは全部読む

```sql
SELECT COUNT(*) AS n,
  FORMAT_TIMESTAMP('%Y-%m-%d', MIN(published_at),'Asia/Tokyo') AS first_day,
  FORMAT_TIMESTAMP('%Y-%m-%d', MAX(published_at),'Asia/Tokyo') AS last_day,
  COUNT(DISTINCT video_id) AS videos
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
```

**絞り込んで読むと外す。** @ゆずたつ-q3n で一人称や「好き」で釣って130件だけ
読んだら、謎解きも冷えピタもタプタプも1件も入っていなかった。
1521件のうち1割を見て「候補が出そろった」と思っていた。

300件ずつに分けて、**全部通す。**

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') AS d,
  REGEXP_REPLACE(message_text, r':[a-z0-9_+-]+:', '') AS t
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
  AND LENGTH(message_text) >= 8
  AND NOT REGEXP_CONTAINS(message_text, r'^(:[a-z0-9_+-]+:)+$')
ORDER BY published_at LIMIT 340 OFFSET 0
```

絵文字だけの行と短い相槌は落とす（1521件 → 1323件）。
`OFFSET` を 340 ずつ送って最後まで。**200件を切る人は、この手順では立たない。
足りないものは足りないと言う。**

口ぐせは別に取る。キーワードにはならないが、**その人の声**が分かる。

```sql
SELECT message_text, COUNT(*) AS n
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
GROUP BY message_text ORDER BY n DESC LIMIT 40
```

## 見つけた言葉は、全員ぶんで引き直す

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') AS d, author_name, message_text
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE REGEXP_CONTAINS(message_text, r'その言葉')
ORDER BY published_at LIMIT 40
```

- **何回言っているかが分かる。** 1回の相槌か、1か月続く癖かで重みが違う
- **その人しか言っていないかが分かる。** みんなが言う言葉は、その人の印にならない

@ゆずたつ-q3n の「カンガ」はこれで意味が変わった（小馬の名付けの場で本人が
出した名前で、2日後に様子を聞きに戻っていた）。**結局は採用されなかったが、
引き直さなければ候補にも挙がらなかった。**

## 選び方

- **絵にできる形にする。** 動作・持ちもの・見た目に落ちるまで書き直す
- **その人しか言えないものを優先する。** 「ラーメン好き」は50人が言う
- **繰り返しているものを優先する。** 1回の宣言より、別の日に何度も出るほう
- **本人が言ったことだけ。** あやとが付けたあだ名、他の人の評は使わない
- **数を揃えるために弱いものを混ぜない。** 4つで足りるなら4つ

## 返し方

**候補を出し惜しみしない。** 選ぶのはあやと。こちらは全部並べて、推しを先に書く。

@ゆずたつ-q3n のときは、20個ほど並べてようやく「謎解き」と「冷えピタ」が
拾われた。**こちらが3つに絞った時点では、1つも刺さっていなかった。**

分類して並べる（その人に合う見出しでよい）:

```
A. 名前とアイコンから
B. その人が配信に置いていったもの（名付け・持ちネタ・一場面）
C. 好きなもの・食べもの
D. 憧れ・場所
E. その人そのもの（仕事・家族・声）

いまの推し: ○ × ○ × ○
  ○  根拠のコメント（日付つき）
```

**根拠のコメントと日付を必ず付ける。** 並べただけでは、あやとが確かめられない。

## やってはいけないこと

- **住んでいる場所・勤め先・本名を掘らない。** 出てきても書かない。
  作るのはキャラクターで、身元ではない
  （「社畜のおっさん」「奥さんと子どもがいる」は本人が配信で何度も言っていて、
  かつ人物像であって身元ではないので使ってよい。線はそこ）
- **3つに揃えるために弱いものを昇格させない**
- あやとの言ったことを、その人のことにしない
