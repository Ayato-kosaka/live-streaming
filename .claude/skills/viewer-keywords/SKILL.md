# 視聴者さんのキーワードを見つける

**出すのは3つのキーワードと、その根拠になったコメントまで。** 絵は描かない。

あやとがそれを見て、キャラクターにする。だから**当たっているかどうかより、
「本人がこれを見て自分だと分かるか」**が基準。

## 校正になる1人

@たぃpi = **チンチラ × 筑前煮 × 南極**（あやとが実際に付けた3つ）。
出どころを引くと、3つとも**本人が自分で言ったこと**だった。

| キーワード | 元になったコメント |
| --- | --- |
| チンチラ | 「えー無いけど好きな動物はチンチラ」（8/31）。以後6回出てくる |
| 筑前煮 | 「じゃあ筑前煮」「筑前煮！！！」「醤油買えたら筑前煮が作れる！」（8/18〜8/31） |
| 南極 | 「ワイは一生のうちにいつかドレーク海峡渡って南極に行くのが夢」（8/16） |

**あやとが言ったことではない。他の人がその人について言ったことでもない。**
本人が、自分の話として、繰り返し書いたもの。

## 1. 全体の形を見る

```sql
SELECT COUNT(*) n,
  FORMAT_TIMESTAMP('%Y-%m-%d', MIN(published_at),'Asia/Tokyo') first_day,
  FORMAT_TIMESTAMP('%Y-%m-%d', MAX(published_at),'Asia/Tokyo') last_day,
  COUNT(DISTINCT video_id) videos
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
```

100件を切る人は、この手順では出ない。**足りないものは足りないと言う。**
無理に3つ埋めると、誰にでも当てはまる3つになる。

## 2. 口ぐせを見る

```sql
SELECT message_text, COUNT(*) n
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
GROUP BY message_text ORDER BY n DESC LIMIT 40
```

同じ文が何度も出てくるものが口ぐせ。**キーワードにはならないが、
その人の声はここで分かる**（拍手の連打、決まった煽り、あいさつの形）。
最後に添える人物像に効く。

## 3. 本人が自分について言ったところだけ拾う

**ここが本体。**

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') d, message_text
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
  AND REGEXP_CONTAINS(message_text,
      r'好き|嫌い|飼っ|ペット|犬|猫|動物|行きたい|行ってみたい|夢|住ん|出身|地元'
      r'|食べたい|好物|作って|俺|ワイ|僕|私')
ORDER BY published_at LIMIT 130
```

一人称（俺・ワイ・僕・私）が効く。**その人が自分の話をしている行だけが釣れる。**

拾ったら、次の3つの枠に振り分ける。

| 枠 | 何を探すか |
| --- | --- |
| 生きもの | 好きな動物、飼っている子、**その人が名前を付けたもの** |
| 食べもの | 作ってほしいと頼んだ料理、不動の一位、料理につける癖 |
| 場所 | 行きたい国、昔から気になっている場所、好きな街 |

## 4. 出てきた言葉を、もう一度だけ引き直す

枠に入りそうな言葉が見つかったら、**その言葉で、もう一度全員ぶんを引く。**

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') d, author_name, message_text
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE REGEXP_CONTAINS(message_text, r'その言葉')
ORDER BY published_at LIMIT 40
```

理由は2つ。

- **何回言っているかが分かる。** 1回だけの相槌か、1か月にわたる癖かで重みが違う
- **その人しか言っていないかが分かる。** みんなが言っている言葉は、その人の印にならない

実例: @ゆずたつ-q3n の「カンガ」を引き直したら、**小馬の名前を決める場で
本人が出した名前**で、他の人が「カンガもいいかも」と乗り、2日後に本人が
「小馬のカンガ元気にしとるかな？」と聞きに戻っていた。**1回のコメントだけ
見ていたら、ただの一言で終わっていた。**

## 5. 3つに絞る決まり

- **本人が言ったことだけ。** あやたが付けたあだ名、他の人の評は使わない
- **繰り返しているものを優先する。** 1回の宣言より、別の日・別の話題に何度も出るほう
- **その人しか言えないものを優先する。** 「ラーメン好き」は50人が言う。使えない
- **3つの枠が埋まらなければ、埋まらないと書く。** 2つで出す。
  枠のために弱い候補を昇格させない
- **迷ったら両方出す。** 選ぶのはあやと。ただし**こちらの推しを先に書く**

                場所を「浜松」（「俺結構好きなんよ」8/27）

**根拠のコメントと日付を必ず付ける。** キーワードだけ3つ並べても、
あやとはそれが当たっているかを確かめられない。

## やってはいけないこと

- **住んでいる場所・勤め先・本名・年齢を掘らない。** 出てきても書かない。
  作るのはキャラクターで、身元ではない
- **弱い候補を3つ目に据えない。** 「たぶんこれ」はキーワードではない
- あやとの言ったことを、その人のことにしない（#5 と同じ間違いがいちばん起きやすい）
