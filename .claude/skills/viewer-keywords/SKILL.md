# 視聴者さんのキーワードを見つける

**出すのはキーワードと、その根拠になったコメントまで。** 絵は描かない。

あやとがそれを見て、キャラクターにする。だから基準は「当たっているか」ではなく、
**その人が自分の絵を見て「俺だ」と思うか。**

## いちばん外しやすいところ（最初に読む）

**本人が「これで作って」と言っていないかを、まず探す。**

3人つづけてここで外した。**3人とも本人が注文していたのに、こちらはコメントを
全部読んで特徴を当てにいっていた。** 後から「名前とアイコンから来ている」と
説明を付けたが、**それは間違いだった。**

| 誰 | いつ言ったか | 何と言ったか |
| --- | --- | --- |
| @ゆずたつ-q3n | 人生初スパチャの**1分後** | 「柚と黒いチワワで何か作って欲しい。あとはおまかせで‼️」 |
| @くまたん-m8q | 初スパチャの本文と、その後 | 「**もぐって**ましたけど浮上」「潜りです ごめんね **猫ファースト**」 |
| @YOKOHAMA_Night | 初スパチャの**2分後** | 「猪のキャラでお願いします！理由は親の実家の畑を荒らしたからです！でも可愛いです」 |

**投げ銭の前後10分だけ読めば、一発で出る。**

```sql
SELECT author_name, FORMAT_TIMESTAMP('%m-%d %H:%M', published_at,'Asia/Tokyo') AS jst,
  event_type, message_text
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
  AND published_at BETWEEN TIMESTAMP('投げた時刻') - INTERVAL 10 MINUTE
                       AND TIMESTAMP('投げた時刻') + INTERVAL 30 MINUTE
ORDER BY published_at
```

**その日の配信ぶんは BigQuery にまだ無い。** Firestore の `streamChatMessages`
（配信中のキャッシュ）を見る。金額も**そちらにしか入っていない**。

```
script: firestore_read
args:   {"collection":"streamChatMessages","order_by":"at","desc":true,"limit":700}
```

**`desc` を付け忘れると古いほうから取る。** 今日ぶんは末尾にいる（1回やった）。

**無言で投げる人がいる。** 鴨川さん・desora さん・YOKOHAMA_Night さんは
本文を添えずに投げた。**本文が空の行は取り込みで捨てられていた**ので、
「言葉が無い＝投げていない」と読み違えないこと（#○ で直した）。
金額だけの行も投げ銭として数える。

## 注文が無かったときだけ、名前とアイコンを見る

ここも効く。**コメントを何件読んでも出てこない**種類のものだから。

- **名前**を分解する（ゆずたつ → 柚子／鴨川小夜 → 鴨・夜／YOKOHAMA_Night → 横浜・夜）
- **アイコン**を見る。公開のチャンネルページから直に落とせる:

```bash
curl -sL "https://www.youtube.com/@ハンドル" -o /tmp/ch.html
grep -o 'https://yt3\.googleusercontent\.com/[A-Za-z0-9_/=.-]*' /tmp/ch.html | sort -u | head
curl -sL -H "User-Agent: Mozilla/5.0" "<いちばん長いURL>" -o /tmp/icon.jpg   # UA が無いと HTML が返る
```

実例: @鴨川小夜 は Five Nights at Freddy's の二次創作（白い動物の頭・指に赤白の
縞テープ・つまんだ目玉）。@YOKOHAMA_Night はみなとみらいの夜景の写真。
**@desora-t5n は既定のまま（紫の四角に白い「d」）で、ここは空振りだった。**
空なら空と書く。

## もう作ってあるかを先に確かめる

```
GET /island-api/characters/lookup?channel=@ハンドル     → {"character":{...}} か {"character":null}
```

**図鑑（`GET /characters`）はクエリを読まずに全件返す。** あれで確かめると
存在しない名前でも「あり」に見える（1回やった）。**引き当ては `lookup` のほう。**

## 出す数と形

**5つくらい。3つに絞らない。** 枠も固定しない。

そのかわり、**全部「絵にできる形」で書く。** ここが効く。

| だめ | いい |
| --- | --- |
| タプタプ戦士 | **人差し指に冷えピタ巻く** |
| 熱心なファン | 社畜のおっさん。奥さんと子どもがいる |
| 謎が好き | 謎解き |

あやとが「タプタプ戦士」ではなく「人差し指に冷えピタ巻く」を選んだのは、
**そっちが描けるから。** ラベルではなく、その人がやった動作を書く。

## コメントは全部読む

```sql
SELECT COUNT(*) AS n,
  FORMAT_TIMESTAMP('%Y-%m-%d', MIN(published_at),'Asia/Tokyo') AS first_day,
  FORMAT_TIMESTAMP('%Y-%m-%d', MAX(published_at),'Asia/Tokyo') AS last_day,
  COUNT(DISTINCT video_id) AS videos
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
```

**絞り込んで読むと外す。** @ゆずたつ-q3n で一人称や「好き」で釣って130件だけ
読んだら、謎解きも冷えピタもタプタプも1件も入っていなかった。
1521件のうち1割を見て「候補が出そろった」と思っていた。

300件ずつに分けて、**全部通す。**

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') AS d,
  REGEXP_REPLACE(message_text, r':[a-z0-9_+-]+:', '') AS t
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
  AND LENGTH(message_text) >= 8
  AND NOT REGEXP_CONTAINS(message_text, r'^(:[a-z0-9_+-]+:)+$')
ORDER BY published_at LIMIT 340 OFFSET 0
```

絵文字だけの行と短い相槌は落とす（1521件 → 1323件）。
`OFFSET` を 340 ずつ送って最後まで。**200件を切る人は、この手順では立たない。
足りないものは足りないと言う。**

口ぐせは別に取る。キーワードにはならないが、**その人の声**が分かる。

```sql
SELECT message_text, COUNT(*) AS n
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE author_name = '@ここに名前'
GROUP BY message_text ORDER BY n DESC LIMIT 40
```

## 見つけた言葉は、全員ぶんで引き直す

```sql
SELECT FORMAT_TIMESTAMP('%m-%d',published_at,'Asia/Tokyo') AS d, author_name, message_text
FROM `live-streaming-d3cac.youtube_chat.chat_messages`
WHERE REGEXP_CONTAINS(message_text, r'その言葉')
ORDER BY published_at LIMIT 40
```

- **何回言っているかが分かる。** 1回の相槌か、1か月続く癖かで重みが違う
- **その人しか言っていないかが分かる。** みんなが言う言葉は、その人の印にならない

@ゆずたつ-q3n の「カンガ」はこれで意味が変わった（小馬の名付けの場で本人が
出した名前で、2日後に様子を聞きに戻っていた）。**結局は採用されなかったが、
引き直さなければ候補にも挙がらなかった。**

## 選び方

- **絵にできる形にする。** 動作・持ちもの・見た目に落ちるまで書き直す
- **その人しか言えないものを優先する。** 「ラーメン好き」は50人が言う
- **繰り返しているものを優先する。** 1回の宣言より、別の日に何度も出るほう
- **本人の注文がいちばん強い。** 注文があるのに別のものを推すのは、ただの勘違い
- **本人が言ったことだけ。** あやとが付けたあだ名、他の人の評は使わない
- **数を揃えるために弱いものを混ぜない。** 4つで足りるなら4つ

## 返し方

**候補を出し惜しみしない。** 選ぶのはあやと。こちらは全部並べて、推しを先に書く。

@ゆずたつ-q3n のときは、20個ほど並べてようやく「謎解き」と「冷えピタ」が
拾われた。**こちらが3つに絞った時点では、1つも刺さっていなかった。**

分類して並べる（その人に合う見出しでよい）:

```
A. 名前とアイコンから
B. その人が配信に置いていったもの（名付け・持ちネタ・一場面）
C. 好きなもの・食べもの
D. 憧れ・場所
E. その人そのもの（仕事・家族・声）

いまの推し: ○ × ○ × ○
  ○  根拠のコメント（日付つき）
```

**根拠のコメントと日付を必ず付ける。** 並べただけでは、あやとが確かめられない。

## やってはいけないこと

- **住んでいる場所・勤め先・本名を掘らない。** 出てきても書かない。
  作るのはキャラクターで、身元ではない
  （「社畜のおっさん」「奥さんと子どもがいる」は本人が配信で何度も言っていて、
  かつ人物像であって身元ではないので使ってよい。線はそこ）
- **3つに揃えるために弱いものを昇格させない**
- あやとの言ったことを、その人のことにしない
