1行ずつ「何を見れば合格か」。**1つでも欠けたら公開しない**——直す担当に配る（あやとに見せて待つのでもない）。

## 全部そろったら（公開）

```bash
gh api repos/Ayato-kosaka/live-streaming/pulls -f title='<街の名前>を検索に出す' -f head='claude/<街>-public' -f base=master \
  -f body='<型の数と、この表の6行の結果を1行ずつ>。#1228 は閉じない'
gh api -X POST repos/Ayato-kosaka/live-streaming/issues/<番号>/labels -f 'labels[]=出す'
```

- 公開の枝に `docs/seo.md` 2章の行がある。日付が公開の日と違えば、その枝で直してから札を付ける。`tokens.md` の1行も同じ枝に積む（`SKILL.md` 5章）
- 旗を倒した値での書き出し・`seo_audit`・`crawl` は PR の CI が回す（#331）。ship のコメントの1行目で読む
- 公開したら `SKILL.md` 3章の段6（知らせる・入れた手の控え・インデックス登録・週の表・控え）
