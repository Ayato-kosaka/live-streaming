# LINE Creators Market でスタンプを出す

**先に `ec2-chrome` を読む。** 画面の操作はその上に乗る。最初の1セット（あやと島のなかまたち、#716）で
2026-10-13 に通った道を書いてある。

```
このセッション ──SSM──▶ EC2 ──CDP──▶ Chrome（~/cdp-line）──▶ creator.line.me
```

## 1. 道具

| ファイル | どこで動く | 何をするか |
| --- | --- | --- |
| `line_pack.py` | どこでも（PIL） | 絵を LINE の寸法に落とす（`sticker` / `main` / `tab` / `check`）。`--outline` で白いフチを足す |
| `line_form.py` | EC2（`/home/ubuntu/stamp/`） | 新規登録の欄を `meta.json` から埋める。**保存は押さない**（画面を撮って見てから押す） |
| `line_tags.py` | EC2（`/home/ubuntu/stamp/`） | タグを枠ごとに付ける（`{"01": ["やっほー", …]}`）。押すたびに「n/9」が増えたかで確かめる |

## 2. ログイン

- **あやとが、リモートデスクトップのふだんの Chrome（既定のプロファイル）でログインする。**
  CDP は既定のプロファイルに繋げないので、`up("line")` が `~/cdp-line` に複製して開く（初回だけ複製する。拡張などは写さないので約35MB・数秒。#1013）
- ログインしているかは `https://creator.line.me/my/` を開いて見る。入っていれば
  `/my/<クリエイターID>/sticker/`（Manage Items）に飛び、右上に「Log Out」と名前が出る。
  トップページ（`/ja/`）はログインしていても「登録はこちら」を出すので、そこでは決めない
- 画面は**英語**で出る（アカウントの言語）。字で探すときは英語の字で探す

## 3. 画面の道（URL）

| | URL（`/my/<クリエイターID>` の後ろ） |
| --- | --- |
| 出品の一覧 | `/sticker/` |
| 新規登録（スタンプ） | `/sticker/create`（`/create` で種類を選ぶ画面を飛ばせる） |
| 1セットの管理 | `/sticker/<スタンプID>`。タブは `data-test` が `tab-detail-information` / `tab-image` / `tab-tag` / `tab-price` |
| 画像 | `/sticker/<スタンプID>/image` |
| タグ | `/sticker/<スタンプID>/tag#/01`（枠ごと） |
| アカウント設定 | `/seller/edit_basic`（基本情報 / メール / 振込先のタブ） |

最初のセットは **スタンプ ID 48307603**（「ちゃす！集まれ、あやと島の仲間たち」、2026-10-13 に申請）。

## 4. 画面の癖（2026-10-13 に踏んだもの）

- **画面は Vue。** 文字の欄は JS で `value` を入れず、押して打つ（`line_form.py` の `typein`）
- **select は `input` と `change` の両方を投げる。** `change` だけだと Vue が拾わず、作者名の小窓で
  「Add」を押しても言語が足されなかった
- **ボタンは `data-test` で探す。** 字で探すと同じ字のボタンが何個もある（「Edit」「Add」「OK」）
- **保存（Save）の `<input type=submit>` は、`<label class=mdBtnLabel>` の中に幅0で隠れている。** 押すのは label のほう
- **確かめの小窓は2つの形がある。** 「Save this form?」「The number of stickers in this set will be changed」は
  `.cm-modal-content` の中の OK。作者名の小窓は `section.FnEditAuthor .mdPOP01Window`（`.MdPOP01Modal` の形）。
  片方だけで探すと「押したのに保存されない」に見える（2026-10-13 に表示情報の直しで踏んだ）
- **宣伝の小窓が最初に出る**（刀剣乱舞のスタンプ、など）。「Don't show this again」に印を付けて Close。
  付けないと開くたびにかぶさって、ほかの小窓が見つからない
- **アカウント設定の振込先タブは、画面の字に銀行名がそのまま出る。** `innerText` を出力しない。
  埋まっているかは欄の**字数だけ**で見る（`len=`）。本名・住所・電話・口座も同じ

## 5. 新規登録の欄（何を入れたか）

`line_form.py` が埋める。入れた値は `meta.json`（例は下）。

```json
{"title": {"en": "Ayato Island Friends", "ja": "あやと島のなかまたち"},
 "description": {"en": "…（160字まで）", "ja": "…（160字まで）"},
 "creator": {"en": "Ayato", "ja": "あやと"},
 "copyright": "©2026 Ayato Island",
 "ai": "AI was used", "style": "Humorous", "character": "Other",
 "release": "Start sales automatically",
 "note": "審査の人に向けた一言（Supplementary Notes）"}
```

- タイトルと説明は**英語が必須**。日本語は「Add Languages」で足す（英語は訳の無い国で出る）
- 種類（Sticker Type）は**あとから変えられない**
- 既定のままでよいもの: 店に出す（Show）・プレミアム（Join）・全地域・特集（Not interested）・並べ替え機能（Participate）・
  お試し（Participate）・写真なし
- 特集（季節・犬の日など）は「テーマに合うスタンプが8枚以上」の条件つき。合わないものは入れない
- 保存すると `/sticker/<スタンプID>` に移り、状態は **Editing**

## 6. 画像

### 寸法（制作ガイドライン）

| | 寸法 | |
| --- | --- | --- |
| スタンプ | 最大 370×320、**縦横とも偶数** | 外枠と中身のあいだに 10px ほど |
| メイン | 240×240 | **1番目のスタンプとは別に1枚上げる**（店の一覧に出る） |
| トークルームタブ | 96×74 | トークのスタンプ一覧の見出し |
| 共通 | PNG・背景透過・1枚 1MB 以下 | ZIP は 60MB 以下 |

```bash
P=.claude/skills/line-creators/line_pack.py
python3 $P sticker 元.png 01.png [--outline 24]   # 370×320 の地に 350×300 で収める
python3 $P main 元.png main.png --outline 24
python3 $P tab 元.png tab.png --box x0,y0,x1,y1 --outline 24   # 顔のまわりを切る（字が入らないように）
python3 $P check *.png
```

- **線画だけの絵（あやとの17枚）には白いフチを足す**（`--outline 24`。住人の絵のフチと太さがそろう）。
  足さないと LINE のダークモードで黒い服と字が地に沈む。暗い地（#1c1c1e）の上に置いて見てから出す
- 住人の絵（ChatGPT で描いたもの）は、はじめからフチがあるのでそのまま
- メインは、店の一覧で小さく出ても**顔が分かる1枚**（全身の絵は縮むと顔が消える）

### 上げかた

1. `/sticker/<ID>/image` で **枚数（`[data-test=select-image-amount]`）を先に選ぶ** → 小窓に OK。枠が 40＋main＋tab の 42 になる
2. **ZIP を `input[type=file][name=file]` に渡す。** 中身の名前は `01.png`〜`40.png`・`main.png`・`tab.png`。
   **その名前の枠に入る**ので、並びはファイル名で決まる
3. 空の枠（`[data-test=no-product-image]`）が 0 になったら入った。画面を撮って、番号と絵を見比べる

EC2 には `zip` が無い。python の `zipfile` で固める。

**一度申請したあと（編集に戻したあとも）は、枚数の選択欄が出ない**（枚数は固定）。ZIP を渡すだけでよい。


### 並び順

トークで開くと**1段4枚**で並び、最初に見えるのは上の2〜3段。よく使うもの（あいさつ・返事・お礼）を前に置き、
用途ごとにかためる。店のページも1番から並ぶので、**1段目に何のセットかが分かるもの**を置く。
並び替えは ZIP の名前を変えて上げ直すだけ（申請の前なら何度でも）。**承認のあとに変えるのは申請し直し。**

## 7. 値段（Price Tier）

- 既定で **¥190**（タイ以外の最安。タイだけで売ると ¥120）。段は ¥190 / 250 / 320 / 350 / 370 / 490 / 610
- **売っている最中は変えられない。** 「販売停止」→ 値段を変える → 再開。変えたあと24時間は変えられない。
  止めるとプレミアムへの参加も外れる（入れ直しが要る）

## 8. タグ（Tag Settings）

- 1枠に**9個まで**、決まった語の中から選ぶ（日本語の語の一覧は「日本語」で切り替える）。トークで字を打ったときに、
  そのスタンプを候補に出すための札
- **付けなければ承認後に自動で付くが、自動のタグは見ることも直すこともできない。** なので手で付ける
- **タグは枠の番号に付く。** 並びを変える前に付けると、絵とタグがずれる。**並びが決まってから付ける**
- **押したその場で保存される**（「Changes saved」）。外すのも同じ「押す」なので、付いているものを押すと外れる。
  `line_tags.py` は付いているものを先に読み、押すたびに「n/9」が1つ増えたかで確かめる
- 同じ語の札が「Recommended tags」と一覧の2か所に出る（どちらを押しても同じタグ）。季節の語（「春」など）は
  畳まれた見出しの中にあるので、検索欄（`input[type=search]`）に打ってから押す
- 一覧の言語は `select[name=language]` を `ja` にすると日本語の語で出る
- 1枠に付けたのは3〜6個（合う語だけ。9個まで埋めない）。最初のセットの割り当ては #716
- **並べ直すと、枠の中身が替わってもタグは前のまま残る。** 替わった枠だけ `line_tags.py … --exact <枠…>` で付け直す
  （いったん全部外してから足す。外すのは上の箱の札の「×」で、一覧の札をもう一度押しても外れない）

## 9. 申請

- 管理画面の上の「Request」は `[data-test=detail-btn-request] a`（字が「Request」の `button` は無い。
  `span` の中の `a`）。「Preview」も同じ形
- 押すと「Request Review」の小窓（`.cm-modal-content`）。権利・透過・タグの注意と、**写真や人物の肖像についての同意文**。
  「I Agree」に印を付けて OK。下の「Get exclusive news from the LINE Creators Market official account」は
  **最初から印が付いている**ので外す（あやとのアカウントの受信設定を勝手に増やさない）
- 送ると「Review request sent.」。状態が **Waiting for Review** → In Review → Approved。自動販売なら承認でそのまま売り出される
- 「Requests Remaining Today: n/30」は**その日に出した申請の数／上限**（申請で 0/30 → 1/30 になった）
- 審査待ちのあいだは「Revert to Edit」（`[data-test=btn-revert-edit]`）で編集中に戻せる（戻すと審査の順番はやり直し）。
  **自動販売にしてあるので、出したあとに直すところが見つかったら、まず戻す。** 審査が通った時点で、直す前のものが売り出される
- **審査中は作者名も変えられない**（作者名の説明に書いてある）
- 同意文の「人物の肖像」は、絵の中の実在の人のこと。最初のセットで描いた人物はあやと本人だけで、住人はキャラクター
