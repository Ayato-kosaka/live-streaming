# エージェントに配る

**自分の手を動かすのは、配る前の判断と、出したあとの確認まで**（CLAUDE.md）。
1ファイルで閉じる作業は、指摘が来た時点で配る。

**ここは依頼文の雛形。** 毎回手で書くと抜ける。実際に抜けて痛い目を見た4つを、
下の型で埋める。

## 1. 型（この4つが無い依頼文は投げない）

### ① 合格の条件

**「前より良い」は条件ではない**（`docs/island-standards.md`）。
**何が見えていれば通るか**を数で書く。

```
- `cd site && npx tsc --noEmit` が通る（`echo $?` で 0 を確認）
- `python3 python/selftest_runner.py`（`echo $?` まで報告）
- **次の6通りを実際に走らせて、出力を報告に貼る。** 頭の中で辿るのは不可
- **守りを1つ外したら、その足だけが落ちること**（対照。BREAK= で切り替える）
```

**対照を必ず入れる。** 「通った」だけでは、見張りが空回りしていても緑になる
（`docs/island-misses.md` の「空回しの緑は、本当の緑より弱い」）。

### ② 確かめかた

**どの道具をどう回すか。無ければ作るところまでが仕事。**

```
- `tools/sprites/node_modules` が無ければ `npm ci`（CLAUDE.md の表を読むこと）
- 書き出して全ページを回す:
    cd site && NEXT_DIST_DIR=.next-verify npx next build
    python3 -m http.server 4321 --directory .next-verify &
    cd ../tools/sprites && node crawl.mjs
  終わったら落とす（`lsof -ti:4321 | xargs -r kill -9`）
- **絵で見るものは絵で見る。** 撮るときは `route.mjs` の `offline(ctx)` を使う
  （使わないと住人が全員同じ顔で写って、レビューしても何も分からない）
```

### ③ 触ってよい範囲

**他の担当と同じファイルを踏ませない。** いま誰が何を触っているかを書く。

```
- 触ってよいのは `functions/src/islandApi.ts` **だけ**
- `site/content/*.ts` に差分が出たら `git checkout --` で戻す
  （`chapterStats` `residents` `streamPeaks` `onThisDay` `cityStreams`
   `countryStats` は**毎晩ひとりでに焼ける**。自分の変更ではない）
- `.github/workflows/clip_fetch.yml` は**別の人が触っている。開かないこと**
```

### ④ 出しかた

```
- ブランチ `claude/<短い名前>` を master から切る（`git fetch origin master` してから）
- コミットメッセージは日本語で、**なぜそうしたか**を書く。モデル名を入れない
- 末尾に:
    Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
    Claude-Session: <このセッションのURL>
- `git push -u origin claude/<名前>`
- PR を作る。本文に実測を貼る。閉じる issue があれば `Closes #NNN`、
  **触れるだけで閉じないものは `#NNN は閉じない` と1行**（`closes_check` の逃がし方）
- **マージもデプロイもしない。** PR 番号と実測を報告する
```

## 2. 秘密の扱い（公開リポジトリなので必ず入れる）

配る相手にも同じ縛りをかける。**報告に素性を書かせない。**

```
- **視聴者さんの素性（channelId・名前・チャット本文・どねID・uid・ハンドル）を
  報告に出さない。** 件数と日付と video_id までにとどめる
- 伏せていない値が要るなら、**スクラッチパッドのファイルに書いて、パスだけ報告**
- `run_admin_script.yml` の ARGS は**公開ログに出る。** 名前を引数に入れない
- BigQuery は **1GB を超える SQL を流さない**
```

---

## 3. 配ったあと

- **報告を鵜呑みにしない。** 数字と、それをどう測ったかを見る。
  「枠を広げないと載らない」のように、**2つの別の話が混ざっている**ことがある
- **出す前に自分で差分を読む。** 特に「何かを捨てる判定」は、
  捨てすぎていないかを自分で確かめる
- 担当が挙げた「指示に無かったが直した」は**丁寧に読む。** たいてい本物の地雷
- **マージとデプロイは自分でやる。** 担当にはさせない

---

## 4. 並べて走らせるとき

- **同じファイルを2人に触らせない。** 先に範囲を切る
- worktree を切るなら `functions/node_modules` は symlink 可、
  **`tools/sprites/node_modules` は実体を複製**（CLAUDE.md の表。symlink だと1本落ちる）
- ビルドは `tools/build.sh` から。**並列で `next build` を3本回すと箱が止まる**
