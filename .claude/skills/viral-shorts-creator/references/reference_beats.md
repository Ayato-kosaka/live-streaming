# 参考の拍の要約（作文者と批評役に渡す1枚の材料）

`tools/shorts/script/brief.py --ref <略号>` が、ここから選んだ参考の節だけを切り出して、頼む文に入れる。
**他人の台本の全文は、公開のリポジトリに置かない**（`script_writing.md` の頭）。ここにあるのは、秒ごとに「何が起きるか」と
「前の行にどう応えるか」（`script_writing.md` 0.8 のつなぎ）の要約と、1本に数か所までの短い引用だけ。
書き起こしの全文はセッションの作業場所（`scratchpad/research/scripts/<videoId>.md`）にある。2026-10-21 に、そこのビート表から作った。

**写すのは構成の手（拍の置きかた・つなぎ）だけ。** 言い回し（サマス・〜だと！？）・企画の型・山とオチは写さない（`script_writing.md` 0.5、帳面 F-005）。

どれを選ぶか（`script_writing.md` 7.1）: 値段の落差で引っ張る → ael・vJo・HPJ／人の一言にツッコむ → OEF・u9M／同じ判定を繰り返す一覧 → IhF／段のある講座 → f8t・qumq。
