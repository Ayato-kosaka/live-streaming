# 参考の見た目と音（書体・大きさ・位置・縁・色・動き・BGM の差）

あやとの言葉（2026-10-16）:

> フォントとアニメーションは https://youtube.com/shorts/HPJrXDpkfuo を参考にして。あと、BGMの大きさもこれを参考に

参考は前から渡されていたのに、こちらは台本しか測らず、見た目と音は自分で決めていた
（字幕 66px・黄色1種の強調・BGM は参考より 4〜5.4dB 小さかった。`docs/island-misses.md` #278）。
ここは**測る決まり**と、**いま測ってある基準**。台本の書き方は `script_writing.md`。

## 1. 決まり

- **参考を渡されたら、台本だけでなく見た目と音も測ってから作る。** 測るのは
  書体・大きさ・位置・縁・色・動き（出かた・いるあいだ・消えかた）と、声と BGM の差
- **自分の好みで数を決めない。** style.json（`tools/shorts/render/style.json`）の字と音の数は、
  測った参考の値から写す。写していない数は「仮」と分かるようにしておく
- **合わせたと言う前に、自分の書き出しを同じ道具で測って並べる。** 物差しが違うと、合っているかが言えない
- 新しい参考を測ったら、下の 3 に日付つきの表を足し、どちらを基準にするかを書く（古い表は消さない）
- **参考の実物（mp4・コマ・音・並べ画像・連続画像）と台本の字は、リポジトリに置かない。**
  ここに置くのは数と言葉の説明だけ。役割は字の中身ではなく見た目の名前で呼ぶ

## 2. 測る手順

`tools/shorts/style/README.md` に1から書いてある。流れだけ:

1. 取り込みの `clips` で参考を1本まるごと取る（元の縦横・fps・音）→ 手元で開く → 作業枝から下ろす
2. 音: `bgm_gap.py measure` → こちらの書き出しの作業の置き場に `bgm_gap.py match`
3. 見た目: コマを抜いて字の見本を書く → `font_match.py` と `font_sheet.py` で書体 →
   `style_measure.py` で大きさ・位置・縁・色・発光・書体の px
4. 動き: `anim_probe.py` で連続画像と矩形 → 動いて出るものだけ `anim_curve.py` で曲線
5. style.json に写し（写し先の表は README の 7）、書き出したものを同じ道具で測り直す

### 3.3 動き（**ほぼ全部、1コマで出て1コマで消える**）

| 役割 | 出る | いるあいだ | 消える |
| --- | --- | --- | --- |
| 題の札（2つとも） | 動画の頭（0コマ目）から出来上がった形で出ている | 止まっている | **2.3秒でカット。同じコマで字幕が出る** |
| 字幕 | **行ぜんたいが1コマで出る**（2行も一度に。1字ずつ足さない・ふわっと出さない） | 止まっている | 次の字幕・大きい字と同じコマで差し替わる（間を空けない） |
| 白・集中線 | カット | 大きさは一定、**位置だけ 30fps で毎コマでたらめに跳ねる**（横 σ13.5〜19.5px・最大21〜47px、縦 σ16〜19px・最大36〜37px。振れ幅は font px の 0.10〜0.15） | カット（0.85〜1.07秒いる） |
| 赤→黒 | カット | 止まっている | カット（1.13秒） |
| ピンクの発光 | 画面のカットと同じコマで、薄くぼやけて現れ、くっきり白く締まる。大きさは変わらない。濃さは 30fps の 0 / 2 / 4 / 8 / 9 / 10 / 11 コマ目で 0 / 0.06 / 0.44 / 0.76 / 0.90 / 0.98 / 1.0。ぼけは8コマ目まで強く、9〜12コマ目で締まる（0.4秒） | 止まっている | カット |
| 黒の筆字 | **拡大して出る**。30fps の倍率 0.29, 0.39, 0.48, 0.67, 0.81, 0.93, 1.02, 1.06, 1.09, 1.07, 1.04, 1.02, 1.01, 1.00（0.25秒で 1.10倍まで行き、0.17秒で戻る。拡大中は動きのぼかし） | 止まっている | カット（出てから 0.73秒） |

- 大きい字が出るコマに効果音（「シュッ」「キラキラ」系。0.3〜0.5秒。声と同じくらいに聞こえる）
- 書き出しの `telop.pop` に写すなら、拡大のものは上の倍率の並び、カットのものは `[1.0]`

## 4. 分からなかったこと

- **本物の書体の名前は分からない。** IoU 0.70〜0.81 は「近い」であって「同じ」ではない。
  M PLUS の派生（けいふぉんと！など）の可能性があるが、配布元（font.sumomo.ne.jp・fontopo.com・
  fontna.com・jikasei.me・osdn.net）にこの箱から届かず、当てられなかった
- 白・集中線の大きい字は、候補3本（Kaisei Tokumin・Zen Maru Gothic・Zen Antique）が 0.70〜0.74 で並び、
  数では決められなかった。手書きのマーカー風は無料で近いものが無い（最良 0.59）
- 集中線・白枠の差し込み・かすれた地・ざらついた縁の**質感**は数にしていない（色と太さだけ）
- **効果音の大きさは道具で測っていない**（「声と同じくらい」は聞いた感じ）
- 音の高い帯（2.5〜5kHz）は物差しの誤差が大きい（平均 +3.2dB・最大 8.4dB）。目安だけ
- ダッキングの有無は、参考の話している割合が 95% で声の切れ目が少ないため、聞こえない・測れない
- 測ったのは**この1本だけ。** 西園寺さんのほかの回やほかの参考で同じかは確かめていない
- 色の分け方（`font_match.py` の `classes`）の閾値は、この参考に合わせて決めた。別の参考では見本の取り出しを目で確かめる
