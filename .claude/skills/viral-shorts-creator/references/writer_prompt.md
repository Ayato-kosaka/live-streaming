## 書きかた（`script_writing.md` 0〜2 の要点）

- 1行＝字幕1枚＝約2秒・14字前後（35字まで）。事実1行 → 反応1行を2〜3秒ごと。説明を2行続けない
- 0〜2秒: 題の札（「〈場所〉に来たら／行ったら、〈本当に起きたこと〉」。参考にしたい型なら「〈場所〉を〈日数〉〈手段〉旅してみた」）。
  3〜5秒: 数か条件 → すぐ自分の口調で反応。5〜10秒: 見続ける枠を一言で
- 文末は体言止め・言いさし・関西の文末。です・ます調と「〜でした」は、ふざけるとき以外使わない
- 人の言葉は「」でそのまま入れ、誰の言葉かの印（〜って・言われて・コメントで）を**声に**入れる
- 最後は「みんな」への問いか、「アーカイブ見てね」の1行。挨拶・まとめ・お礼で終えない
- 全部で 350字・22行まで（声の倍率の上限 1.4 で60秒に入る量）

## 書く前の自己点検（あやとに前にも言われたこと。1つでも当たれば、書き直してから渡す）

1. **行間を空けない（F-039）**: 下の表の「つなぎ」を全部の行に付ける。**跳**（前の行の頭から渡れない）と書くしかない行は書き直す。
   配信で起きた順に並べただけの所ほど跳ぶ。配信を見ていた人には、チャットと何分ものあいだがつなぎを渡していたが、ショートでは消える。
   **つなぎを声で言うか、その段ごと外す**
2. **二転三転させない（F-040）**: 本人が言い切ったことを打ち消す（取消）のは1本に1回・1行だけ。その行に印（思てたら・でも）と理由（誰に何を言われたか・根拠の事実）を**声で**入れる。
   2行以上かけて積んだ結論は打ち消さない。打ち消したすぐあとに、謝る・言い直す・元に戻すで、もう一度向きを変えない。
   外の出来事で良し悪しが入れ替わる（閉まっていた・雨が降った）のは取消ではない（ハラハラはこちらで作る）
3. **答えのあとに行を重ねない（F-037）**: 題の答えになる行に【答】を付ける。【答】のあとは、締め（問いかアーカイブ）までに2行まで。
   その2行も「この行が無いと話が通じないか」を問い、無くても通じるなら消す。「最後にもう一笑い」は足さない
4. **題の形（F-031・F-043）**: 題は場所と、本当に起きたこと（出来事・数字）で言い切る。比喩・見立て・「乗ってみた」の報告にしない。
   国の名前の前に国旗。題の札の字と、読み上げる1行目は別にしてよい
5. **同行者を主役にしない（F-043）**: 「参考にしたい」の型では、主役は旅の手段と日数。同行者（家族・友達）の話を題・回収・問いに入れない
6. **問いは答えるまで同じ話題の上に置く**: 〜？・なんと・〜たら で切った行は、答える行まで別の場面へ移らない。あとで拾う数・前提は、拾う行より前に声で言う
7. **「？」を残さない（F-008）**: 出てくる人・場所・物は、使う前に紹介するか、誰でも知っている言葉にする

## 書く手順

1. 「伝えたいこと」を1行で書く（題の気持ち。全部の行がそこへ向かうか）
2. 原稿を書き、下の表の「つなぎ・聞いた直後の頭の中・向き」を**全部の行**で埋める（つなぎ: 題・答・反・足・前・転・外・跳・締。
   頭の中: 知（知ったこと）・問（抱いている問い）・期（期待）。向き: 取消／動／空欄）
3. 上の自己点検を1つずつ当てて直す
4. `python3 tools/shorts/script/lint.py <script.txt>` を通す。**✕ が残っているうちは渡さない。** △ の行は、渡すときに1行ずつ「本人の言い方か・正しいか」を添える
5. `script.txt`（1行1文。【足】【答】の印つき）と、spec の行（`line`・`why`（根拠の時刻。【足】【答】も）・`visual`・`telop`）と、下の表を返す
