# 作文者への頼む文（雛形）

`tools/shorts/script/brief.py writer --video <id> --range <区間> --ref <参考> --title "<題の札>" --next "<次の配信>" --about "…"` が、
下の線より後ろの `{{…}}` を埋めて1枚にする。まとめ役は、この1枚のパスと、書き出す先（`shorts/videos/<id>/p1/`）だけを作文者に渡す。

## なぜ、こう作り直したか（2026-10-23 #1019、帳面 F-048〜F-050）

前の1枚（2026-10-21〜23）で書いた滝の回 p1 は、17行のうち13行が配信の字幕をほぼそのまま写していて、あやとに
「安易に配信の文字起こしを繋げてるだけ」「今までの約束も漏れすぎ」「一回プロンプト削除して、ゼロベースで」と言われた。前の1枚を下敷きにせず作り直した。

- **約束が届いていなかった。** 前の1枚は帳面を「題＋直しの最初の1組（90字で切る）」に縮めていて、決まり（する／しない）は0字だった。
  いまは帳面の決まりと直しを1字も切らずに「約束のカード」にして、**1枚の先頭**に置く（帳面から毎回組む。手で写さない）
- **材料に引っ張られていた。** 前の1枚は6割が字幕とチャットの生の文で、その真上に「まずここからあやとの言葉を拾う」とあった。
  いまは字幕を**いちばん後ろ**に下げ、チャットの本文は入れない。方針（参考7本の研究。#1019 に報告）を、字幕より前に置く
- **逆を教えていた。** 「誰の言葉かの印（〜って・コメントで）を声に入れる」「字幕に何度も出る口ぐせは残す」と書いてあり、8・9行目はその字どおりに書かれた。全部消した
- **当てたかを誰も見ていなかった。** いまは1行ずつ4欄（元の出来事／見る人に届く文／残した本人の言葉／選んだ理由）で書かせ、
  カード1枚ずつの当て表（spec の `promises`）を付けないと lint の L-ATE が ✕ にする。「選んだ理由」は、あやとの返事（#1019「なぜそれを選んだか理由付きで」、帳面 F-051）から
- **書く時間を削らない**（F-050「推論を用いてトークンをしっかり使って」）。F-044 の「頼む文を磨いて往復を減らす」は往復の上限として残すが、
  そのために1枚を薄くする・書く時間を縮める（前は原稿の段が3分半だった）は採らない

## 雛形を直すとき

- 方針の例は、参考の短い引用（1本に数か所まで。他人の台本の全文は置かない）と、あやとの直しから取る
- カードの中身は帳面（`ayato_feedback.md`）で直す。ここに帳面の字を写さない（写すと、帳面を直しても1枚が古いまま残る）
- 直したら `python3 tools/shorts/script/brief_selftest.py` を回す（カードが全部・全文で先頭にあるか・チャットの本文が0か・字幕が後ろか）

## 3. 方針（参考7本と、あやとの直しから。2本以上で同じだったもの）

参考は、生き急ぐOL西園寺さんの伸びたショート7本（どれも AI の声で、本人が書いた原稿を読む作り）。写すのは**作りの手**で、言い回し（サマス・ザマス）・企画の型・山とオチは写しません（F-005）。

1. **字幕は材料。原稿は、帰ってきてから見る人に向けて書く語り。**
   一人称・関西弁はそのまま。残す本人の言葉は、**擬音・口ぐせ・味の言い方・ツッコミだけ**。文の形は、その行だけ聞いて意味が通る日本語に組み直す（主語・助詞・理由を戻す）。
   その場の誰か（配信の視聴者・犬・同行者・その場の自分）に向けた呼びかけ・相づちは、そのまま行にしない
   - 参考: スイス一周は36行のうち、その場の実況に聞こえる行が2つだけ。裁判傍聴は27行で0。光るどろだんごは、その場の叫び（「光ったぁ」など4〜13字）を4行挟むだけで、話をつなぐ行は全部あとから書いている
   - あやとの直し: 「ひたすら道なき道を、歩いていこう。」「ちょっと待って。緊急事態発生。」→「ひたすら道なき道を、歩いていると、緊急事態発生！」（配信の言葉を無理やりなぞるのでは無く、聴きやすく）／
     「振り出しに戻ったら、ポチが駆け足で寄ってきた。」→「始まりの位置まで戻ったら、野良犬が駆け足で寄ってきた。」（文字起こしをそのまま使って何言ってるか分からない）／
     「怖いから、ゆっくりおいで……」→「怖いから近づかないで！」（犬に向けた言葉のままでは、聞く人には意味が逆に聞こえる）

2. **失うものを、危なくなる前に言う（ハラハラ）。** 何が懸かっているかを1行で先に置く。あとで本人が言った「困る理由」は、危なくなる前の行へ移してよい（事実は変えない。時刻は why に書く）
   - 参考: グランクラスは「お値段なんと」→「通常料金の2倍」で失うもの（2倍のお金）を先に出してから「見せてもらおか‼」と問いを立てる。裁判傍聴は「家庭裁判所は…おもんない！」と、選び間違えたときの損を先に言う

3. **行の終わりを開けて渡し、次の行でひっくり返す。** 「〜けど／〜のに／〜たら」で開けた行の次で、結果か7〜14字のツッコミを言う。
   問いは1〜3秒（次の1〜2行）で答え、答えるまで場面を変えない。長く引っ張るのは題の約束1つだけ（答えは全体の3分の2あたり）
   - 参考: 光るどろだんごは37行中10行が「〜けど／〜から／〜たら」で開けたまま次へ渡す（滝の回 p1 は17行中0行）。インド料理は「…ちぎるんドスけど」→「こーれーが意外と難しい‼」と1秒で返し、題の答えは61秒の41〜44秒
   - あやとの直し: 閉じた2行を「〜と、」でつないで1文にした（上の「歩いていると、緊急事態発生！」）

4. **1つの出来事は「前ふり → 結果 → ツッコミ」の3行前後に畳む。** 試行錯誤は、笑えるか見る人の得になる1つだけ残す。調子に乗った一言を前に置くと、落ちが効く
   - 参考: インド料理のカリフラワーは「どうやってちぎるんや！？やったるで〜‼」→「思ってたらベタベタ系は爪楊枝で刺すらしい」→「もっと自分貫けよ！」の3行・6秒。
     光るどろだんごは「私が1番綺麗なの作ってやるからなぁ！」を前に置いて、29秒後に「子供の方が話聞いてんの草」で落とす

5. **海外の有益は、持って帰れる1〜3行。** 行き方・時間・注意・値段を、日本の物差しで（円だけ・日本と比べる）。1回きりの出来事は、行く人が使える決まりに言い直す
   - 参考: スイス一周は1回の体験を「毎週水曜はお祭り」「水着持ってきた奴が勝つ場所」と決まりに直す。四国は「日本の感覚で油断した一言 → 叫び → 理由（うどん屋は昼過ぎには閉まる）→ 対策（朝が勝負）」。役に立つ話には、おかしな結果を1つ結ぶ

6. **海外を感じるのは、画に任せる所と声の所を分ける。** 景色と料理の見た目は画に任せ、「きれい」「おいしい」を足さない。
   声は画に映らないもの（足元の感触・なぜ得か・現地の人のひとこと・暮らしの1点）を言う。日本の物で言い換えるのは、本人の口から出た物に限る（作った見立ては言わない。F-035）
   - 参考: マグロのエサやりは景色の形容0回、料理3皿で「おいしい」0回。代わりに「ちなみにマグロの食費月70万らしい」→「私よりええもん食うてるやん」と、数と自分の物差しで言う
   - あやとの直し: 「黒くてずっしりした、ライ麦パンの味。」→「味は外サク中ドロのヨーロッパライ麦パンや！」（形容を並べず、本人の味の言い方で）

7. **初見に通じる言葉だけ。** 配信の内輪（コメント・チャット・あだ名・常連の言葉）は出さない。人に言われた話は、画に居る人（地元の人・宿の人・店の人）のものだけ。呼び名は誰でも分かる言葉にする
   - 参考: 7本とも、声に視聴者・配信の話は無い（四国の「フォロワーさん曰く」の1か所だけで、これは写さない）。人は名前でなく「職場のインド人」「ガイドさん」「爺さん」のように、関係か種類の1語で呼ぶ
   - あやとの直し: 「配信のコメントで「…」って。」→ 行ごと削除（「身内感出さないで欲しい。ショート動画はほとんどが初見」）／「ここは、ポチだらけの草原。」→「野良犬だらけの草原からスタート！」（「何度も言ってます」）

8. **題と最後の行。** 題は、場所と本当に起きたことを、助詞を抜かずに言い切る。1行目は題の札をそのまま読む。
   最後は「みんな」への問いか、入りきらなかった見どころを渡す「アーカイブ見てね」の1行（次の配信に誘うなら時刻まで）
   - あやとの直し: 「ジョージアで滝観に行こうと思ったら大惨事に！」→「滝を観に」（「早口で曖昧な日本語を使うと聞き手はストレス。題も訂正して」）／
     「明日はワンパンピザ作るので配信見にきてね！」→「リベンジにワンパンピザを本日22時から作るので配信見にきてね！」
   - 参考: インド料理の最後「みんなは素手でご飯食べてみたい？」——題の願いを、見る人への問いにして返す

## 4. 書く形

### 長さ

- 1行＝字幕1枚＝約2秒・14字前後（長くても35字）。全部で **350字・22行まで**（声の倍率の上限 1.4 で60秒に入る量。F-019）
- 文末は体言止め・言いさし・関西の文末。です・ます調と「〜でした」は、ふざけるとき以外使わない

### 1行ずつ4欄で書く（全部の行を埋める）

{{table}}

- **元の出来事（配信の時刻）**: その行が言う出来事と、下の材料の字幕の時刻（`[0:05:30]`）。配信に無い出来事を書いた行には【足】、題の答えになる行には【答】。
  言い方を組み直しただけの行には【足】を付けない（【足】は「出来事が配信に無い」の印）
- **見る人に届く文**: 読み上げる字。**このショートを頭から見てきた初見の人が、その行をその行の画と一緒に聞いて、誰が・何を・どうしたかを取れる文**にする。
  題と前の行で言った物は言い直さなくてよい。配信を見ていないと分からない言葉（呼び名・前の会話の続き・その場の相手への呼びかけ）に頼らない。
  言いさし（〜けど・〜たら）で次の行へ渡すのはよい
- **残した本人の言葉**: 字幕から残した擬音・口ぐせ・味の言い方・ツッコミ（例:「ぐっちょぐちょ」「外サク中ドロ」「やんか！」）。無ければ空。
  ここに書かない字幕の言葉は、文の形ごと組み直す
- **選んだ理由**: なぜその出来事を残したか・なぜその言い方にしたか・なぜその画かを、1行に40〜80字で（あやと #1019「なぜそれを選んだか理由付きで」）。
  方針の番号や約束の ID で言ってよい（「方針2: 失うもの（宿にスリッパが無い）を、危なくなる前に置く」）。「字幕にあったから」は理由にならない
- **元の声**（F-051）: 叫び・驚きの声（「うわー」「やばい」、沼にはまった瞬間）のように、その場の声が臨場感を出す所は、AI の声で読まずに配信の本人の声を流してよい。
  その行の「元の出来事」に【元の声 0:10:18〜0:10:21】と流す秒を書き、「見る人に届く文」は叫びの字（それが字幕になる）。
  喋り続けている所・雑音の多い所・視聴者の名前やチャットを読んでいる所は、元の声にしない

書いたら、頭から1行ずつ声に出すつもりで読み、次の2つを見ます。

1. **その行だけで意味が通るか。** 前の会話・その場の呼びかけ・配信の中の呼び名に頼っていないか
2. **前の行から渡れるか。** 前の行を聞いた人が抱いた問い・期待に、この行が応えているか（本人の頭の中でだけつながる行を置かない。F-039）

### 返すもの

1. `script.txt` — 1行1文。【足】【答】の印は行の末尾に
2. `spec.json` — 次の形。**行ごとの中身は必ず `rows` に書く**（`lines` などの別の鍵で書くと、lint と批評役の1枚が止まる）

   ```json
   {"title_card": "<国旗つきの題の札。助詞を直したらその字>", "title_card_seconds": 4.0, "next_stream": "<決まっていれば>",
    "rows": [{"line": "<見る人に届く文>", "why": "<元の出来事と配信の時刻。【足】【答】もここに>",
              "kept": "<残した本人の言葉>", "reason": "<選んだ理由>", "orig_voice": "<元の声を流す秒。AI の声で読む行は空>",
              "visual": "<その行の画。名指す物・動きが写る配信の時刻>", "telop": ""}],
    "promises": {"F-004": {"lines": [3], "note": "<どう直したか／当たらない理由>"}}}
   ```

3. 上の4欄の表と、下の当て表（返事の本文に。あやとに出すときも、この4欄の表をそのまま使う）

## 5. 当て表（全部の ID を埋めないと渡せない）

カード1枚ずつに、**当たる行**（題の札は 0）と**どう直したか**、当たる行が無ければ**当たらない理由**を書きます。「なし」「OK」だけは書かない。
書いたら `python3 tools/shorts/script/lint.py <script.txt>` を通し、**✕ が残っているうちは渡さない**（当て表の欠け・空の note・原稿の外の行の番号は L-ATE が ✕ にする）。
△ の行は、渡すときに1行ずつ「本人の言い方か・正しいか」を添えます。

{{ate}}

## 6. 材料: 配信の字幕（使う区間だけ）

**ここは材料です。字幕の文を、起きた順につなげて行にしない**（方針 1。あやと「安易に配信の文字起こしを繋げてるだけ」）。
ここから拾うのは、出来事と時刻と、残す本人の言葉（擬音・口ぐせ・味の言い方・ツッコミ）だけ。数字・出来事は、ここの時刻で言えるものだけを書きます（X2）。
自動の聞き取りなので、聞き違いと、ほかの声（配信で流した動画など）が混ざります。本人がコメントを読み上げている所は、話を動かす材料にしません（F-048）。
