# 本編集から Gate 2 まで（作り方と、見るところ）

企画が決まってから、あやとに完成動画を見せるまで。1本目（北マケドニアの回 `yk-by7R7iPA`、
2026-10-15〜16、3案とも作った）で通した形。**直すたびに、ここを書き足す**（あとの回が同じところで転ばないように）。

## 1. 流れと道具

| 段 | 何をするか | 道具 | 出来上がり |
| --- | --- | --- | --- |
| 素材 | 絵コンテが指す元動画の時刻を、前後に余白（区間 −2〜+3秒、1点なら −2〜+8秒）を付けて並べ、重なりはまとめて1本の依頼にする | `shorts_ingest` の `clips`（`tools/shorts/ingest/README.md`） | 区間ごとの mp4（元の縦横・fps・音）と `index.json`。手元で復号 |
| 声 | 原稿を1文ずつ。数字・英字・外の言葉は**かなに直して渡し、字幕は原稿のまま** | `tools/shorts/voice/`（EC2 の Chrome で Fish Audio） | 1文1ファイルの wav と `lines.json`（長さ・聞き取り直した字） |
| 編集指示書 | 企画の spec と素材の index と声の長さから組む。場面の差し替えは上書きファイルに理由つきで書く | `tools/shorts/plan/build_edit.py` | `edit_<案>.json`（人が直せる編集データ） |
| 書き出し | BGM を入れた1本（YouTube・TikTok で同じもの。曲はあやとが選ぶ。#909） | `tools/shorts/render/render.py` | mp4 と `plan.json`・音の stem・字なしの版 |
| 機械の検査 | 14項目。顔は「人が見る」で出る。強調の字の言い直しは `text_dup` が、字が顔に被っているのは `text_on_face` が落とす | `tools/shorts/qa/check.py` | 項目ごとの合否と数 |
| **人の目の検査** | 下の 3 を全部。機械は「弱い画」を言い切れず、言葉の重なりも一部しか拾えない | 帯の絵 `tools/shorts/qa/strips.py`（下の 3） | 直しの一覧 → 書き出しに戻す |
| 見せる | あやとだけが開ける場所に置く（推測できない URL でも公開と同じに扱う） | EC2 の Chrome で、あやとの Google ドライブへ | Gate 2 の提出（`gate.py submission --gate video --options …`） |

**字の書体・大きさ・位置・縁・色・動きと BGM の大きさは、参考を測った値から決める**（`references/style_reference.md`。自分の好みで決めない。`docs/island-misses.md` #278）。題の札の**箱（上部・黒い地）だけはあやとの指示**（2026-10-16「背景は黄色から黒に」）で、参考（箱なし）と違うまま残す。箱の中の字は参考の題に寄せる。

並べられるものは最初から並べる: **素材の取得（Actions・約1時間）と声（EC2）は互いに待たない。**
書き出しは、声が来るまで Open JTalk の仮の声で組み、来たら差し替える。

## 2. 決めたこと（理由つき）

| 決めたこと | なぜ |
| --- | --- |
| 字は「上に題の札（黒い箱。1行目の読み上げが終わるコマで消す・最長4秒）」「中央に字幕（白に黒の縁・48px・顔は避ける）」の2つが基本。強調の字（テロップ）は、**その行のナレーションにもタイトルにも無いことを足すときだけ** | 1本目は強調の字の半分がナレーションの言い直しで、0秒目に「25分」が3回並んだ（タイトル・強調・字幕）。数字を目立たせたいときは、字幕の中のその語を黄色にする |
| 足してよい強調の例: 本人の元の声の言葉（「今から揚げんの？」）・言葉の訳（「Pulë = 鶏」）・地図の矢印（「アルバニア → 北マケドニア」） | 画とナレーションだけでは伝わらないもの |
| 字（字幕・大きい字）は画面の縦のまん中が基本。ただし**顔には被せない**（顔に掛かる行だけ、行ごとに1回、顔の下へ。収まらなければ上へ。書き出しの `avoid_faces` と、品質チェックの `text_on_face`） | 自撮りの画が多い。参考のショートは物を写した画が多くまん中で困らないが、こちらは字が目・口元に乗った（p3 の A で7行、B で10行。あやと 2026-10-16） |
| 透かし（PRISM Live）は**塗らずに切り落とす**（元の 720x1280 の y=1192 から下） | 塗ると跡が残る。下の 88px は絵として失っても困らない |
| 顔のぼかしは**顔だけを小さく**。大きな面をぼかさないと隠せない場面は、**使わない** | 1本目はバスの横腹・満員の通路を大きくぼかして、画が壊れて見えた |
| 声は1文ずつ、行ごとに音量を揃えてから混ぜる。仕上げは −14 LUFS・トゥルーピーク −1.5 dBTP 以下 | Fish Audio の声は行ごとに 7 LU ばらつく（−28〜−21 LUFS） |
| 字幕の出だしは、声の頭の無音を切ってから合わせる | Fish Audio の声は頭に間があり、そのままだと字が声より先に出る |

## 3. 人の目の検査（機械の検査が全部通ってから、必ず）

帯の絵は `python3 tools/shorts/qa/strips.py out.mp4 out.work` が1枚にまとめる（はじめの帯・行ごとの1秒刻みの帯・弱い画の見当に赤い枠）。**自分で全部見る**。真ん中の1コマだけの一覧では見落とす（1本目の B は、真ん中のコマでは
メニューが写っていたが、その行の前半2.4秒は何も無いカウンターだった）。

| 見るもの | どう見るか | 落とす例 |
| --- | --- | --- |
| **0秒目がその動画でいちばん強い画か** | 0・0.5・1・2・3・4.5秒の帯 | 回る肉の串が1秒目まで画に入っていない／最初の字が小さい状態から出てくる |
| **同じ言葉が2回以上出ていないか** | 全行の一覧で、タイトル・強調・字幕を並べて読む。`check.py` の `text_dup` が6割以上の言い直しと 0〜3秒の3つ並びを落とすので、残りの言い換え（「予定の時間を過ぎた」と「予定の時間はもう過ぎた」）を読む | 「あと20分」の強調と「あと20分」の字幕 |
| **弱い画が2秒以上続いていないか** | 各行を 0.5〜1秒刻みで。`strips.py` の赤い枠は見当（大きな形が少ない間）で、枠の無い所も見る | 何も無い壁・歩道・暗い車内だけ |
| **小さな字が、スマホで読めるか** | 値段・看板は出来上がりで字の高さ 40px 以上 | メニューを小さな差し込みで出した |
| **ぼかしが画を壊していないか** | ぼかしのある行を全部 | 画面の半分がぼけた塊 |
| **終わりに余韻があるか** | 最後の行の後ろ 0.5〜0.8秒 | 最後の言葉で切れる |
| 顔（機械が「人が見る」に出したもの） | 切り抜きの一覧 | 本人以外の顔がそのまま |
| 透かし | 右下の切り抜き | 少しでも残る |

## 4. 落とし穴（1本目で踏んだもの）

- **Fish Audio**: 1回押すと2つ作られ、片方だけ課金される。課金は**音の長さではなく送った字のバイト数**（63バイト = 63クレジット）。画面の下書きを上書きするので、作業の前に控え、終わったら戻す（あやとの下書きがある）
- **EC2 で文字起こし**: t3.medium では `large-v3-turbo` が載らない。int8 に変換したもの（`Zoont/faster-whisper-large-v3-turbo-int8-ct2`）なら Chrome を閉じて載る。EC2 のディスクは 93% まで埋まった（Chrome の複製 1.5GB・文字起こしの環境 1.3GB）。終わったら片づける
- **素材の取得**: 区間取りは頭がずれるので、配信を1本まるごと取って切る。541秒ぶんで暗号文 255MB・約1時間
- **CI**: `tools/` の下に `/home/<名前>/<下>` の形を書くと `tools/sprites/rootcheck.mjs` が落とす（EC2 の置き場も）。名前の終わりの `r'` は `ts_readers_selftest.py` が生の文字列と読んだ（直した）
- **人の微修正の画面**（`tools/shorts/render/editor/`）は、元の素材をそのまま下見用に出す。**ぼかし前の顔と透かしが写る**ので、ぼかし済みの下見を作るまで本物には使わない
