## 2. 決めたこと（理由つき）

### 例外の無い決め（カットの選び方。あやと 2026-10-21、#959）

> 静止画はやめて欲しい。カクカクじゃないところで良さそうな映像探して。なければカクカクでも良い。
> また、同じカットを3秒以上使わない約束を守って。
> 同じような見た目のカットも連続3秒以上使わないで欲しい。

| 決め | 機械の検査 | 守りかた |
| --- | --- | --- |
| **止め絵を使わない。** 写真・画面の写し・止めたコマ（ゆっくり寄せて動いて見せても同じ） | `still_image`（時間割の印・取り込みの台帳の印・元素材の画素。寄せる前の絵で隣のコマとの差が出る対が 5% 未満なら止め絵） | 画が足りないときは、企画の段で動く素材（アプリを触っている画面の録画など）を頼む（`planning.md` 1.6） |
| **同じカットは 3秒未満。** 時間割で2カットに割っても、同じ素材の続き・止め絵の頭からの使い直しで寄せが続くなら1つのカット | `cut_length`（3.0秒ちょうども落とす） | 長い行は、3秒未満で別の画に切り替える。料理の寄りや景色でも例外にしない |
| **似た見た目のカットを続けて 3秒以上使わない。** 同じ場所の引きと寄り・同じ区間を寄せの倍率だけ変えたものも入る | `similar_run`（隣どうしを使い回しと同じ見分けで比べ、色の分布の線は 0.5。自撮りで話す画どうしは同じ瞬間のときだけ） | 間に見た目の違う画を挟む。線の近く（同じ通りの別の時刻など）は機械が見逃すので、人の目の検査で見る |
| **カクつく映像は、なめらかな映像でその物が写っている所が無いときだけ使う。** そのときも止め絵にはしない | `source_stutter`（カクつく区間を使えば、この検査は落ちたままになる） | 落ちたら、まず同じ物が写る別の区間を `stutter.py` で探す。落ちたまま出してよいのは、探して無かったときだけ。そのときは探した素材の範囲と、使う区間の繰り返しの割合を制作の issue に書く（あやとが「なければカクカクでも良い」と言った範囲の外に出ない） |

v9 はカクつく区間を直すのに、聞かずに止め絵へ替えた（19カット中 10カット）。3秒の決めは企画の手引きに「3秒前後」「料理の寄りや景色は長く見せてよい」とだけあり、
こちらのレビューは1つの画の尺の割合（25%）を数えていて、続けて何秒かを数えていなかった（`docs/island-misses.md` #294）。

### ほかの決め

| 決めたこと | なぜ |
| --- | --- |
| 字は「上に題の札（黒い箱。1行目の読み上げが終わるコマで消す・最長4秒）」「中央に字幕（白に黒の縁・48px・顔は避ける）」の2つが基本。強調の字（テロップ）は、**その行のナレーションにもタイトルにも無いことを足すときだけ** | 1本目は強調の字の半分がナレーションの言い直しで、0秒目に「25分」が3回並んだ（タイトル・強調・字幕）。数字を目立たせたいときは、字幕の中のその語を黄色にする |
| **題の札は、国の名前の前に国旗を付ける**（「🇦🇱アルバニアの…」）。spec の `title_card` に国旗の絵文字を書けば、`build_edit.py` がそのまま指示書の `title.text` へ運び、`render.py` が国旗の絵（`tools/shorts/render/flags/<2字>.png`）を1字ぶん置く。国の2字は ISO 3166-1 alpha-2（コソボは XK）で、絵文字は `flags.py emoji <国の名前か2字>` が出す。絵の無い国は `flags.py add XX=国の名前` で足してコミット・push してから書き出す（無いまま回すと、`render.py` も `remote.py up` も止まる）。国旗の絵はパブリックドメインなので、**説明文にクレジットは要らない** | あやと 2026-10-21「タイトルには国旗を入れて。画像でも絵文字でも綺麗に行く方」。投稿の題には前から国旗の絵文字を付けていたが、動画に焼いた題の札の書体（M PLUS）には絵文字の字形が無く、そのまま書くと豆腐（□□）になる。絵文字の書体・Twemoji・flag-icons と並べて、平らな四角の国旗の絵にした（理由は `tools/shorts/render/flags/README.md`） |
| 足してよい強調の例: 本人の元の声の言葉（「今から揚げんの？」）・言葉の訳（「Pulë = 鶏」）・地図の矢印（「アルバニア → 北マケドニア」） | 画とナレーションだけでは伝わらないもの |

| 字は3段: ふつうの字幕（事実）・**感情の字幕**（spec の行の `mood`）・大きい字（見せ場）。感情の字幕は**感情が動く行だけ**で、**書体は1つ・色は2系統**（張りつめる＝白に濃紺の縁／上がる＝黄に茶の縁）。動きと大きさは感情で変えてよい。大きい字の色は白・黒・黄・赤だけ。**キラキラは付けない** | 白い字幕と大きい字の2段では感情が字に出なかった（あやと「もっと感情に合わせてフォントとか色変えて欲しい」#926）。次に書体5つ・色5つにしたら「バリエーションが多すぎる」「色合いがごちゃごちゃ」「キラキラは男のショートには合わない」「なんの感情もないナレーションは基本の字幕で良い」と言われた（#926、2026-10-16 23:31 UTC。`style_v3.json`） |

| BGM は話している間で声より 10.5dB 前後下（参考の 13.6dB より大きめ） | あやとが2回「BGM もう少し大きく」と言った（#926）。参考に合わせるより、出す本人の好みを取る |
| 透かし（PRISM Live）は**塗らずに切り落とす**（元の 720x1280 の y=1192 から下） | 塗ると跡が残る。下の 88px は絵として失っても困らない |

| 下見はドライブではなく Hosting のプレビューチャンネル（7日で消える）で渡す。URL は issue に貼ってよい | ドライブへは作業箱 → EC2 の転送で3本95MB に約35分かかった。あやと（2026-10-16）「ドライブに置く → Firebase storage か GCS に置いたら？ パブリックバケット作っても良い」「動画のレビューは非公開に無理にする必要ない」。GCS の署名付き URL は Actions のサービスアカウントに Storage の権限が無く（実測）、権限のある Hosting で先に通した。#938 であやとがバケットを作って付与したので、1本ずつの URL でよければ `--place gcs`（37秒）でも渡せる（`tools/shorts/preview/README.md`） |

## 3. 人の目の検査（機械の検査が全部通ってから、必ず）

**あやとの指摘の帳面（`ayato_feedback.md`）の 画・音・題・投稿 の項目も、この表と一緒に1つずつ当てる。** `check:` の付いた項目は `check.py` が、
残りは人が見る（何をどこで見るかは、項目の「当てる場所」）。

帯の絵は `python3 tools/shorts/qa/strips.py out.mp4 out.work` が1枚にまとめる（はじめの帯・行ごとの1秒刻みの帯・弱い画の見当に赤い枠）。**自分で全部見る**。真ん中の1コマだけの一覧では見落とす（1本目の B は、真ん中のコマでは
メニューが写っていたが、その行の前半2.4秒は何も無いカウンターだった）。

| 見るもの | どう見るか | 落とす例 |
| --- | --- | --- |
| **0秒目がその動画でいちばん強い画か** | 企画の段で `tools/shorts/plan/hook.py` を回し（spec・復号した材料・窓の index.json・いまの書き出し）、`hook_<案>.jpg` の「いまの0秒目」と候補3つを並べて見る。候補は色の強さ・暖色の寄り・動き・顔の寄り・山場で測った順で、**その動画の答え（オチ）を先に見せる画か**は人が決める。いまの画より強い候補があれば、1行目の src（overrides の row 0）を替える。書き出したら 0・0.5・1・2・3・4.5秒の帯で、題の札の下にその画が出ているかを見る | 原稿の1行目の画をそのまま置いた（#285）／回る肉の串が1秒目まで画に入っていない／最初の字が小さい状態から出てくる |
| **題の札の国旗が、題の国のものか** | 0秒目の帯で、国旗が国の名前の前にあり、その国の旗か（機械は「国旗が描けたか」までしか見ない。🇲🇰 と 🇲🇪 のような書き違いは人が見る） | 「アルバニアの」の前にモンテネグロの旗／国の名前の後ろに旗が付いた |
| **同じ言葉が2回以上出ていないか** | 全行の一覧で、タイトル・強調・字幕を並べて読む。`check.py` の `text_dup` が6割以上の言い直しと 0〜3秒の3つ並びを落とすので、残りの言い換え（「予定の時間を過ぎた」と「予定の時間はもう過ぎた」）を読む | 「あと20分」の強調と「あと20分」の字幕 |

## 4. 落とし穴（1本目で踏んだもの）

- **Fish Audio の速度**: 画面の「速度」を 1.1 から 1.3 にして同じ3行を作っても、**声は速くならなかった**（詰めた長さの合計 12.32秒 → 12.31秒・6本ずつ、毎秒 5.84 → 5.85拍。2026-10-18、#285）。速度は生成の要求（`POST /task` の本文）に乗らず、下書きの `audio_settings.prosody.speed` に残るだけ。画面で選べるのも 0.7〜1.3 まで。**速さは書き出しの倍率（上限 1.4）で決める**
- **Fish Audio**: 1回押すと2つ作られ、片方だけ課金される。課金は**音の長さではなく送った字のバイト数**（63バイト = 63クレジット）。画面の下書きを上書きするので、作業の前に控え、終わったら戻す（あやとの下書きがある）
- **EC2 で文字起こし**: t3.medium では `large-v3-turbo` が載らない。int8 に変換したもの（`Zoont/faster-whisper-large-v3-turbo-int8-ct2`）なら Chrome を閉じて載る。EC2 のディスクは 93% まで埋まった（Chrome の複製 1.5GB・文字起こしの環境 1.3GB）。終わったら片づける
- **素材の取得**: 区間取りは頭がずれるので、配信を1本まるごと取って切る。541秒ぶんで暗号文 255MB・約1時間
- **CI**: `tools/` の下に `/home/<名前>/<下>` の形を書くと `tools/sprites/rootcheck.mjs` が落とす（EC2 の置き場も）。名前の終わりの `r'` は `ts_readers_selftest.py` が生の文字列と読んだ（直した）
- **人の微修正の画面**（`tools/shorts/render/editor/`）は、元の素材をそのまま下見用に出す。**ぼかし前の顔と透かしが写る**ので、ぼかし済みの下見を作るまで本物には使わない
