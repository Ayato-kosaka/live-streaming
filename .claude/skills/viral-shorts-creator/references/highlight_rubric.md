## 手がかり（重ねて使う。どれか1つで決めない）
| 手がかり | 何が分かる | 注意 |
| --- | --- | --- |
| 字幕・文字起こし | 何が起きたか、本人が何に驚いたか | **自動字幕と whisper の両方を読む。** whisper は固有名詞に強く（鬼滅の刃・スカンデルベグ）、自動字幕は数字と英単語に強い（SIM・23.900ユーロ）。数字は画面か別の発言で裏を取る |
| コンタクトシート（10秒に1コマ） | 音が無くても魅力のある画（景色・料理・人・街並み・日本との違い） | 10秒刻みなので、短い瞬間は zoom（1秒刻み）で確かめる |
| 動き・音量（timeline10 / visual / audio） | 急な展開、大声、笑い、走る | 歩いているだけでも動きは大きい。単独では弱い |
| 配信チャット（chat.txt） | 見ていた人が反応した瞬間 | **出来事の 15〜35秒あと**に付く（2本で12か所を突き合わせた。中央値は約30秒。ティラナの回では +11〜44秒の幅があった）。**チャットの主張（「〜らしい」）は事実ではない**。裏を取る |

## 採点表（各 1〜5。予想であって、結果で判断する）
| 軸 | 5 の目安 | 1 の目安 |
| --- | --- | --- |
| 初見理解 | 1文の説明で状況が分かる | 前の流れや常連の話を知らないと分からない |
| 冒頭の画 | 区間の中に、最初の1〜2秒に置ける「止まる画」がある | 顔のアップと話だけ |
| 意外性 | 日本の常識と違う／予想が裏切られる | 想定どおり |
| 感情 | ドキドキ・笑い・驚き・ほっこりがはっきり動く | 平坦 |
| 画の魅力 | 景色・料理・人・街並みが美しい／珍しい | 暗い・ブレ・何が映っているか分からない |
| 短く成立 | 原因→結末が 20〜60秒に収まる | 結末まで10分以上かかる |
| オチ | 見終わる理由（結末・答え・笑い）がある | 尻切れ |
| 狙いに刺さる | 主の視聴者の疑似旅行・グルメ・文化の発見、またはサブのハプニング | どちらにも当たらない |

## 落とす（または注意して扱う）印
- 常連向け（登録者のお祝い・スパチャのお礼・内輪のあだ名）
- 話だけで画が無い（トークの回想）。ナレーションで補えるかを別に書く
- 第三者（現地の人・子ども）の顔が大きく長く映る。使うならぼかしの要否を書く
- 事実を確かめられない主張（建物の由来・値段など）。確かめた出典か、本人の発言の時刻を付ける
- 右下の配信ソフトの透かし（PRISM Live）は全コマにある。上に固定コメントの帯が出ている回もある（ティラナの回）。どちらも書き出しで隠す前提なので減点しない
- 投げ銭の表示は視聴者さんの名前が出うる。映っていたら使わないか隠す

## 1候補に必ず付けるもの
- 元動画の区間（開始〜終了。H:MM:SS）と、冒頭に置ける画の時刻
- 何が起きたか（確かめた事実だけ）。**前後の文脈（原因と結末）**と、その時刻
- 根拠: 字幕の該当行（時刻つき）・見たコマ（シート番号と時刻）・チャットの反応（時刻と、補正した出来事の時刻）
- 採点表の点と、一言の理由
- 確かめきれていないこと（zoom で見るべき区間）
