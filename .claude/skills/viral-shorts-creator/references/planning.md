# 企画3案の作り方

2026-10-15 に、北マケドニアの回とティラナの回で作った形（`shorts/videos/<videoId>/p1/`）。

## 1. 3案は「見る体験」が違うものにする

題だけ違う3案にしない。素材に合わせて型を選ぶ:

| 型 | 例 |
| --- | --- |
| ハプニング・緊迫 | 出発25分前に、朝ケバブを頼んだら（残り時間が減る → 最後の1席） |
| 物語 | 日の入りに間に合え！ 急いだら、早すぎた |
| グルメ | 国を出る前に、残りの現金590円で朝ごはん |
| 日本との違い | 路線バスの運賃は「人」に払う |
| 発見・文化 | この国、英雄の顔をビルにした |
| クイズ・歴史 | 街なかのキノコ、何だと思う？ |

同じ場面を2案で使ってもよいが、**山とオチが違うこと。**

## 2. 1案に必ず入れるもの

| 項目 | 中身 |
| --- | --- |
| 概要 | 仮タイトル・狙い・狙う視聴者・尺・感情の流れ・伸びると考えた理由（**数字の根拠つき**）・今回確かめる仮説（`playbook.md` の番号と物差し） |
| 伝えたいこと | 1行で（`script_writing.md` 0.5）。全部の行がここへ向かっているかを見る |
| 見る人とそろえる前提 | この企画の驚きが、見る人の常識（日本の常識）のどれと食い違うか。食い違うなら、原稿のどの行で先にそろえるか（例: 日本ではケバブ＝ラップ → ここはパンをプレスしたパニーニ風。`script_writing.md` 0.7）。食い違いの無い企画・行には書かない（違いを毎回入れる、ではない） |
| 0秒目の画 | `tools/shorts/plan/hook.py` で素材から測った候補3つと、選んだ1つ（元動画の時刻）・選んだ理由。その動画の答え（オチ）を先に見せる画にする（`production.md` 3） |
| 原稿 | ナレーションの全文。1行1文 |
| 尺の確認 | `tools/shorts/plan/readtime.py` で**読ませて測る**。想定（1.15倍）と遅め（1.0倍）の両方が60秒未満 |
| 絵コンテ | 動画内の時間・元動画の時間・映像・ナレーション・テロップ・演出の表と、静止画を並べた絵（`storyboard.py`） |
| 自己評価 | 冒頭の引き・初見の分かりやすさ・意外性・画の魅力・物語・テンポ・見終わった満足・狙いとの合い（各1〜5）と、低い点の理由 |
| 確かめた事実 | ナレーションの1文ずつに、元動画の時刻か外の出典 |
| 気をつけること | ぼかす場面・言わないこと |

3案の比べ表と、推薦する1案とその理由を頭に置く。**自己採点は予想であって、結果で判断する**と書く。

## 3. 冒頭と2つ目の山

- **0秒目に、その回でいちばんの画と、一行で言い切った題。** 題の札は0秒目から出す（H2・H4）。
  画は原稿の1行目の画のまま決めない。`tools/shorts/plan/hook.py` で素材（取り込んだ窓と、その話の範囲のコンタクトシート）から色の強さ・暖色の寄り・動き・顔の寄り・山場かどうかで候補3つを並べ、**その動画の答え（オチ）を先に見せる画**を人が選ぶ。選んだ画は1行目の `src`（と overrides の row 0 の `cuts`）に置き、題の札の下に出す
- **4〜8秒に2つ目の山**（意外な数字・障害・決める一言）。あやとの過去ショートはここで離れていた（H1）。
  作ったあとで、原稿の2文目が何秒から始まるかを表で見る。1文目が長くて山が8秒を過ぎるなら、文を割るか順番を入れ替える
  （北マケドニアの C案は1文目が7秒あったので、「1A……これ、違う？」を2文目に上げた）
- 常連向けの情報（何日目・区間・シリーズ名・配信の題）を頭に置かない

## 4. ナレーション（原稿）の決まり

**書き方は `script_writing.md` に従う。** 要点だけ:

- **あやとが自分の言葉で喋る一人称の台本**を、AI の声が読む（西園寺さんと同じ形）。外の語り手が「あやとは〜」と説明しない。
  言い回しは、まず配信の文字起こしからあやとの言葉を拾う（関西弁）
- 事実1行 → 反応1行を2〜3秒ごと。最初の反応は5秒まで、見続ける枠は10秒まで。最後は「みんな」への問いで切る
- 値段は円も添える。数字は感情か比較と組で（「295レク、日本円で590円」→「微妙すぎる額やん」）
- **盛らない。** 確かめられたことだけを言う
  - 「全財産590円」→ 本人が持っていたのは**残りの現金**（カードはある）。「残りの現金590円」と言う
  - 本人の思い違いは、思い違いのまま本人の言葉で言う（ティラナの「あと10分」は実際は約23分あった →「俺の計算では、あと10分」）
  - 数が資料で割れるものは「〜とも」（シェルターの数は17万〜75万 →「数十万とも」）
- 言わないこと: 国や人をひとまとめにする笑い・相手の国を笑う冗談・確かめていない「世界初」・他人の作品の名前（漫画のキャラクターなど）・
  視聴者さんの名前（配信の文字起こしに出てくる）

## 5. 絵コンテの決まり

- 1行は3秒前後。4秒を超える行は、元動画の時刻を2つ以上書いて画を切り替える（ただし料理の寄りや景色は長く見せてよい）
- 静止画は zoom（1秒刻み）から取る。**第三者の顔が映るコマには `blur` を付ける**（絵コンテは issue に貼るので、その時点で公開になる）
- 配信の透かし（PRISM Live）・固定コメントの帯・投げ銭の表示は、書き出しで隠す前提で「気をつけること」に書く
- 本人の短い一言を元の音で残す候補は、演出の欄に「残す候補」と書く（原則はミュート）
- **テロップの「中央」欄には、その行のナレーションにもタイトルにも無いことだけを書く**（本人の元の声の言葉・訳・地図の矢印など）。
  数字や値段を目立たせたいだけなら「字幕で強調: 25分」と書く（書き出しが字幕の中のその語を黄色にする）。
  1本目は中央欄の半分がナレーションの言い直しで、画面に同じ言葉が2〜3回並んだ（`production.md` 2）
- **静止画は真ん中の1コマで選ばない。** その行の長さぶんを1秒刻みで見て、行のあいだずっと強い画が続く区間を選ぶ。
  何も無い壁・歩道・暗い車内が2秒以上続く区間は使わない。値段や看板を見せる行は、字が画面いっぱいに近く写るコマを選ぶ
- 第三者の顔が大きく写る場面は、ぼかしで済ませる前に別の画を探す（大きくぼかすと画が壊れて見える）

## 6. テロップの読み方（2026-10-15 の約束）

依頼は「タイトルは上部配置で背景あり、セリフは中央配置で文字枠あり」。
**「文字枠」は縁取り（白字に黒の縁）と読んだ**（参考スクショ2枚目の形）。箱のことなら、企画を見せたときに直してもらう。
