# 批評役への頼む文（雛形）

`tools/shorts/script/brief.py critic <script.txt> --ref <参考> --video <配信の videoId> --about "…"` が、下の線より後ろの `{{…}}` を埋めて1枚にする。
回すのは `tools/shorts/script/critic.py`（`claude -p` に、この1枚だけを渡す。道具なし・ファイルも読ませない）。
返ってきた JSON の合否は `tools/shorts/script/critic_gate.py` が数える。**批評役の「通る／通らない」の一言では決めない。**

## なぜこの形か

- **作文者と同じ約束のカードで見る**（2026-10-23 #1019、帳面 F-050）。前は帳面を「題＋直しの最初の1組」に縮め、lint が見る項目は名前だけだった。
  批評役が当てたかどうかも分からなかった。いまはカードを全文で渡し、**当てた ID を全部 `checked` に並べさせる**（欠けたら gate が ✕）
- **「人の話の印があるか」をやめた**（F-048）。前は (i) で「人に言われた話に印（〜って・コメントで）があるか」を当て、印の無い伝聞を ✕ にしていた。
  批評役は「コメントで」を**要求する**作りで、滝の回 p1 の8・9行目はそれで通り、1人目の批評役が「取消の印が無い」で落としたので作文者が
  「思てたのに」を足して2人目を通した（関所が逆の向きに押した）。いまの当たりは「**画に居ない人（視聴者のコメントなど）の言葉を持ち出したか**」
- **1行ずつ「その行だけ聞いて意味が通るか」を当てる**（F-039 の2回目・F-050）。字幕と8字以上一致する行は、通った原稿にも落ちた原稿にも同じくらいあった
  （滝の回 p1 8/17・フォカッチャの承認版 9/19）。字の一致では分からず、分かれ目は「その行だけで意味が通るか」だった
- 返すのは決まった型の短い JSON。行ごとの「つなぎ」と「その行だけで通るか」を全部の行に1字ずつ付けさせるので、数えるのは gate（批評役の言いかたの揺れが合否に入らない）
- 1人 約14〜19万トークン・6〜12分を使っていた頃（2026-10-21）から、読むものを1枚に寄せている（#1011、帳面 F-044）

## 雛形を直すとき

- **この雛形に、対照の原稿（`tools/shorts/script/fixtures/` と、城塞 p1・地下鉄 p1・銅像 p2・フォカッチャ・滝の回 p1）の行を例として書かない。** 書くと、
  対照（`script_writing.md` 7.7）が答えを見て通る・落ちるようになり、雛形の良し悪しを測れなくなる。例は参考（西園寺さんほか）から取る。
  `brief_selftest.py` の `c_leak` が、対照の行を8字以上そのまま引いていないかを見る
- 直したら、対照を回し直す（滝の回 p1 が落ち、フォカッチャの承認版が通る。銅像 p2 が落ち、城塞 p1 と地下鉄 p1 が通る）。外れたら雛形を戻す

## 5. 採点のしかた

### (j) その行だけ聞いて、意味が通るか（全部の行に1字ずつ）

頭の行から順に、**このショートを頭から見てきて、その行を、その行の画と一緒に聞いた初見の人**のつもりで読み、`alone` に1行ずつ `{"line": 行, "ok": true か false, "why": ""}` を入れます。
**1行目から{{n}}行目まで、全部の行を1件ずつ**（題の札は入れない）。通らない行は `ok` を false にし、`why` に理由を40字まで。

通らない（`ok` が false）のは、次のどれかに当たる行です。

1. **誰が・何を・どうしたが取れない。** 主語・目的語・助詞・理由が抜けていて、画からも、題と前の行で見る人がもう知っていることからも埋まらない
   （主語が画に写っている・題や前の行で出た物を指している、なら言わなくてよい。グランクラスの回は題「グランクラス乗ってみたい！」のすぐあとを
   「お値段なんと」で始め、何の値段かを言い直さない）
2. **宛先が、見る人ではない。** その場の誰か（配信の視聴者・動物・同行者・その場の自分）に向けた呼びかけ・相づち・指示のままで、あとから聞く人には意味が通らない・逆に聞こえる
3. **配信の中だけの言葉に頼っている。** 配信の中の呼び名・配信の前の会話の続き・言い差しの断片で、配信を見ていない人には何の話か分からない
   （見るのは「配信を見ていないと分からないか」。このショートの前の行で言ったことに頼るのは、つながりで、当たらない）

通らないにしないもの: 言いさし（〜けど・〜たら……）で次の行へ渡し、次の行と合わせれば通る行（次の行まで読んで決める）／画が見せている動きに付けた擬音・掛け声（画の列で確かめる）／
最後の「みんな」への問いと「アーカイブ見てね」の1行。

参考の伸びたショートは、その場の実況に聞こえる行がほとんど無く（スイス一周は36行中2行、裁判傍聴は27行中0行）、その場の叫びも「光ったぁ」のような4〜13字を、話をつなぐ行のあいだに挟むだけです。

### (k) 画に居ない人の言葉を持ち出していないか

視聴者のコメント・チャット・常連・フォロワーなど、**旅の場に居ない人の言葉や書き込みで話を動かす行**を `outsider` に挙げます（`who` に誰の言葉か）。
地元の人・宿の人・店の人・案内役のように、旅の場に居て見る人にも分かる人の言葉は当たりません（その人を紹介しているかは (e) で見る）。
参考では、四国の回の「フォロワーさん曰く」1か所だけがこれに当たり、ほかの6本には1つも無い。

### (i) 行と行のつなぎ（全部の行に1字ずつ）

頭の行から順に、その行を聞いた直後に見る人が持っているもの（知ったこと・抱いている問い・期待）を思い浮かべ、
**次の行が、前の行までの頭の中の何に応えたか**を、次の1字で `tsunagi` に付けます。

- **題**: 1行目
- **答**: 開けた問い・溜め（〜？・なんと・〜たら・思てたら で切った行）に答える
- **反**: 前の行の事実に、見る人が思ったことを本人が言う（驚き・ツッコミ・自分を落とす・物差し）
- **足**: 同じ物・同じ場面に事実を1つ足す
- **前**: あとの行で使う前提・前ふり・枠を先に置く
- **転**: 場面・話題を移す。頭に印（次！・て訳で・ほんで・てか・いざ）を置くか、新しい場所・物をその行で名指す
- **外**: 前の行までの予想・気持ちを、印（思てたら・と思いきや・しかーし・でも・けど）付きでひっくり返す
- **跳**: 上のどれでもない。前の行の頭から、この行へ渡れない（本人の頭の中でだけつながる）
- **締**: 最後の「みんな」への問い・「アーカイブ見てね」の1行

参考の伸びたショート10本・308行に、**跳は0行**でした。そのうえで、当てはまる行だけ挙げます。

1. **問い**（`questions`）: 問い・溜めで切った行ごとに、答えた行（`answered_by`。答えないなら 0）と、答えより前に別の話題・場面へ移ったか（`moved`）。
   答えに向かう行（障害が出る・それに驚く）を挟むのは移ったに数えない
2. **向きの変わり目**（`turns`）: 前の行までに本人が**言い切ったこと**（事実・判定・予想・計画）を「違った」と打ち消す行は **取消**。
   外の出来事で良し悪しが入れ替わるだけなら **動**。見分けかたは、前の行の言葉とこの行の言葉が**両方とも本当で話が通るか**（通るなら動）。
   気持ちの返し（「寒すぎる！」→「わあキレイ」）・？を付けた予想の答え・決めたことが売り切れでできなかった、は取消ではない。
   取消には、印（`mark`。思てたら・でも…。無ければ ""）・打ち消す理由（根拠の事実）が声にあるか（`reason`。この行か、その手前の同じ向きに進む行）・
   打ち消す言い切りが何行ぶんか（`erases`）・すぐあとで同じ話題の向きをもう一度変えるか（`back`。謝って引っ込める・言い直す・元に戻す）を付ける
3. **前に声の無い数**（`numbers`）: あとで拾う数・前提（「2回目」の1回目・「元取れる」の値段）を使う行と、それより前の行の声で言ったか（`said_before`）。
   挙げるのは、前の数を数え続ける・足し引きする・比べる行だけ。その行で初めて言って出す数（時刻・日付・値段・人数）と、見る人の常識は挙げない

### (h) 約束のカードを当てる — 読み違えやすい線引き

- **F-037（答えのあと）**: 当たるのは、答えのあとの**気持ちの言い直し・もう一段の落ち・同じ話の重ね**。締めの前の**注意・実用の一言**
  （危なかった・こうすると良い・気をつけて）は、参考の終わりの拍（グランクラスの「食事無し列車があるから気をつけて！」→ 問い）と同じで、F-037 ではない
- **F-025（結末に別の筋）**: 最後の「アーカイブ見てね」の1行で、入りきらなかった見どころを渡すのは F-032 の決まりどおりで、別の筋ではない
- **F-047（配信の言葉で書く・足さない）**: 下の「配信の字幕」と原稿を1行ずつ並べて当てる。当たるのは次の5つで、why の頭に番号を書く（「2: …」）。
  1. **配信に無い出来事**: 【足】の無い行なのに、字幕のその場面に、**その出来事が無い**。同じ出来事を見る人に向けて組み直した行は当たらない。
     離れた2つの場面の出来事を1行につないで、無かったつながりを作った行は当たる
  2. **要らないつなぎ・決め台詞**: 中身が意気込みか問いかけだけの1行で、次の行がその答えになる動き・作戦を言うもの。
     キメの一言で、配信のその場の相談・チャットを知らないと意味が通らないもの。**字幕にあっても当たる**。
     当たらないのは、見る人が知りたい結果（どうなった・どんな味）を1行だけ溜めて次の行で出す行と、行の終わりを開けて次の行へ渡す言いさし
  3. **要らない飾り**: 動きに付けたたとえ（〜みたいに＋動き）・持ち主・大きさの言葉で、消しても話が通じるもの。字幕と食い違う飾りは、事実の誤りでもある。
     味・見た目・中身を言う言葉（食感・種類・産地・何に似ているか）は飾りではない
  4. **言い換えた説明**: その場面で本人が言った擬音・対比・味の言い方が字幕にあるのに、どの物にも言える平たい形容（色・重さ・大きさ）を並べた説明に替えた行
  5. **画とずれた動きの行**: 掛け声・擬音で動きを言う行で、その行の画（表の「画」）がその動きを見せていない
  - 1行目が題の札の字か・最後の誘いの時刻は、lint が見た。字幕が渡されていないときは、1 と 4 は当てない
- **F-048（内輪）・F-039（なぞる）**: (k) と (j) で当てた行は、`ledger` にも同じ行で挙げてよい（合否は (j)(k) が数える）
- **F-008（「？」）**: 当たるのは、前置きの無い人・物・呼び名・数が出る行。題や前の行で出た物を、その行で言い直していないだけでは当たらない（(j) の 1 と同じ線）
- カードに無い好みは `ledger` に入れない（点か `leave` に書く）

### 点 (a)〜(f)（1〜5。4 で「参考の同じ拍に負けない」）

| | 見るもの | 5 | 1 |
| --- | --- | --- | --- |
| a | 0〜2秒の引き | 札と画だけで、何が起きるかと続きを見たい気持ちが立つ | 何の動画か分からない |
| b | テンポ | 2〜3秒ごとに何か起きる。説明の行が2つ続かない | 説明や、同じことの言い換えが続く |
| c | ツッコミ | 参考の同じ拍と並べて、負けない短さと切れ。自分か人の言動に刺さる | 説明や事実で返している |
| d | 上がって、回収する | 失うもの・前ふりを先に置き、後の山ほど大きい。前に置いた振りを後で拾う | 同じ高さが続く・振りが拾われない |
| e | 「？」が無い | 出てくる人・場所・物が、使う前に紹介されているか、誰でも知っている | 前置きの無い人・物・呼び名が出る |
| f | 終わり | 題の気持ちで着地し、問いにコメントしたくなる | 題と違う気持ちで終わる・答えにくい問い |

**3 以下を付けるのは、参考の同じ拍と並べて具体的に負けている所を1行で言えるときだけ。** 好みで下げない。

### (g) 離れる行・直し案

- `leave`: 初めて見る人が「ここでスワイプする」行を、理由と一緒に全部。無ければ空
- `fixes`: 落とす理由のある行にだけ、1行に1つ、40字まで。**直し案もカードと (i)(j)(k) に当ててから出す。** 答えのあとに行を足す案は出さない（F-037）。
  本人が言っていない出来事には `"ashi": true`

## 6. 返す形（JSON だけ。前置き・後書き・コードの囲みなし）

```
{"scores":{"a":4,"b":4,"c":4,"d":4,"e":4,"f":4},
 "score_why":{"a":"40字まで（3以下なら、参考のどの拍に負けたか）","b":"","c":"","d":"","e":"","f":""},
 "checked":["F-004","F-005", …当てた ID を全部],
 "alone":[{"line":1,"ok":true,"why":""},{"line":2,"ok":false,"why":"40字まで"}, …1行目から最後の行まで全部],
 "outsider":[{"line":8,"who":"視聴者のコメント"}],
 "tsunagi":["題","答","反", …全部の行ぶん。数は表の行数と同じ],
 "questions":[{"line":2,"answered_by":5,"moved":false}],
 "turns":[{"line":7,"kind":"取消","mark":"でも","reason":true,"erases":[6],"back":false}],
 "numbers":[{"line":12,"said_before":true}],
 "ledger":[{"id":"F-037","line":18,"why":"40字まで"}],
 "leave":[{"line":11,"why":"40字まで"}],
 "fixes":[{"line":11,"text":"40字まで","ashi":false}],
 "verdict":"通る"}
```

- `why`・`text`・`who` はどれも40字まで。長い説明を書かない
- `verdict` はあなたの一言（「通る」「通らない」）。合否は、上の数から機械が数える

## 8. 配信の字幕（原稿が使った場面）

{{source}}

- 自動の聞き取り。聞き違いと、ほかの声（配信で流した動画など）が混ざる。言葉が1〜2字違うだけなら同じ言葉に数える
