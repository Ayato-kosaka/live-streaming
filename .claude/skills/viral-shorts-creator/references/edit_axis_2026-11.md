## 0. 先に結論

1. **回の型は5つ。** その回の「山」（題の答え）が何かで決める。**食べ物の反応**（味の判定）・**やってみた・体験**（やった結果）・
   **トラブル・やらかし**（その最中と結末）・**その国の驚き**（日本と違う事実）・**お金・値段**（いくら）。
   **温泉は「やってみた・体験」**（答えは「飲んでみたら激まず」＝やった結果。判定の字だけ食べ物の見た目を借りる）、
   **ボザは「食べ物の反応」**（答えは「うまい・甘酒の小麦版」）
2. **型で大きく変わるのは、字を出し続けるか・大きい字の量・カットの長さ・題を言う札の形。** 書体や縁の色は型より作り手で決まる
   （同じ作り手は型が違っても同じ見た目。西園寺さんの体験2本と食べ物2本は同じ形）【事実】
   - **体験**（2本）: 字が出ている秒 92〜97%・大きい字を場面ごとに替える（数・逆接・切り替え・ツッコミ）・カット 10秒に5.2〜5.5回
   - **食べ物**（西園寺さんの2本を除く6本）: 字は小さいか少ない。焼き込みの字幕が無い（11%）・1語ずつの小さい字・擬音だけ、が3本。
     跳ねた2本（路上ジュース 479倍・屋台 31倍）は、**題を言う札を0秒目から動かさずに出す**（路上ジュースはカットと同じコマで2枚目に
     差し替え、屋台は3秒以上同じ札）。札の要の語に色（赤・黄緑）
   - **トラブル**（4本・全部跳ねた回）: 字が出ている秒が少ない（36〜77%）・**カットが長い**（10秒に0〜1.4回・1カットの中央値 2.9〜35秒）・
     **動かない帯**（上の題の帯・下のシリーズの帯・黒地の枠）が4本中3本・相手の言葉を色で分ける（2本）
   - **その国の驚き**（3本）: 字が出ている秒 88〜100%・**区切りの札**（番号の見出し・「期待／現実」の札）が3本とも・語ごとの色（2本: 題の語・1語ずつの字幕）
3. **跳ねた回とふつうの回で、字・音・カットの作りはそろっている**（C の15組。同じチャンネルは同じ作り）。だから軸は
   「その型の跳ねた回が使っている作り」で決めた。**編集で跳ねさせるのではなく、題材と構成で跳ねる回を、その型に合う編集が邪魔しない**
   ようにする【推測】
4. **音は、参考の効果音を測れたのが前の研究の1本（体験）だけ。** 大きい字のコマに 0.3〜0.5秒の効果音（シュッ・キラキラ）を声と同じくらいで
   鳴らし、BGM は声で上下させず差 13.6dB（`style_reference.md`）。1秒ごとの荒い音では、西園寺さんの3本（体験2・食べ物1）は声の無い秒も
   声と同じ大きさで BGM が続き（差 0.2〜1.2dB）、トラブルの2本（lVrV・xB83）は声の無い秒もその場の音が同じ大きさで続く（差 0.1dB）【事実】。
   参考35本の効果音は、**取り込みが2回とも YouTube に断られて測れていない**（8章）。**効果音の決めは仮**（音は1本で見た）
5. **こちらの作りは、いま全部の回が体験の型**（西園寺さんの型が様式 style_p3/v3 の元）。カットは10秒に5.7〜6.6回で、参考13本の中央値（3.9回）より速く、
   効果音は10秒に1.2〜2.6回で、温泉の12個のうち7個はカット（風切り音）と写真の札（ポン）に鳴っている【事実】。
   食べ物の回は、大きい字を味の判定と数に絞り、効果音を判定のコマに絞る（ボザで F-087 の 12→5 と同じ向き）
6. **様式の組を5つ置いた**（`tools/shorts/render/presets/{food,try,trouble,surprise,money}.json`）。書き出しがそのまま読む様式
   （大きい字の見た目と順・感情の字・字幕の大きさ・BGM の下げ幅）と、書き出しが読まない置きかたの決め（`_axis`。大きくする言葉・
   効果音の名前と鳴らす所・BGM・カット・色）。題の札は全部の型であやとが選んだ形のまま
7. **いまの道具で作れない物は7つ**（6章）。効果音を行の種類から置く道具・題の語ごとの色・1語ずつ出す字幕・擬音を物の近くに置く・
   上下2本の動かない帯・BGM を溜めで止める（参考には無かった仮説）・黒地の枠

**取れなかった理由（音）:** 取り込み（`shorts_ingest.yml`）に元の音の束を渡す欄（`audio: true`、d76644a6）を足して35本を頼んだが、
1回目（16:32 UTC・run 45216402792）は35本とも全部の口で「Video unavailable」（取れた 0/35）、
2回目（17:27〜19:36 UTC・run 45226750147）は15本目まで全部の口で「Failed to extract any player response」（1本 約520秒）で、
どちらも取り消した。毎晩のチャットの取り込みと同じ Cookie なので、それが通るのを見るまで頼まない（main の決め）。
代わりの道の EC2 の Chrome は、ほかの担当の絵の仕事で load 10〜18 のあと、19:37 UTC から SSM が届かなくなった。
EC2 で再生しながら音を録る道具（`live.py`。使い捨て）は、試しの1本で、再生の速さが 1.5倍に残っていた・読み込みで止まった所の音が
抜ける、を直したところで止まった（8章）。

### 1.2 物差し

| 何 | どう数えたか |
| --- | --- |
| 字の帯 | 1秒1コマ（取り込みのシートの 270×480）で、明るい塗り（白・黄・桃）のすぐ隣に暗い縁か影がある画素が横に詰まった所を帯にした（`telop_scan.py`）。帯の縦の位置（画面の高さの割合）・字の高さ（1920 の縦に直した px。2行の字幕は2行ぶん）・幅（画面の幅の割合）・塗りの色 |
| 動かない帯 | 同じ縦の位置・同じ高さの帯が6割以上のコマにあるもの（題の帯・シリーズの帯・黒地の枠）。字が出ている秒は、これを除いて数えた |
| 大きくした言葉 | 人の目。1本ごとに10コマ（0・1・2秒、大きい字の秒、字のある真ん中の秒、最後）を見て、大きい字の語と種類（数・味・逆接・切り替え・ツッコミ・結末）を付けた |
| 書体・縁 | 人の目（丸ゴシック・角ゴシック・明朝・手書き風）。字の形を測る道具（`font_match.py`）は回していない |
| 出しかた | 頭3秒の 0.1秒刻み（4本）と前の研究（HPJrXDpkfuo を 30fps で測った） |
| カット | 取り込みの `scenes.csv`（30fps の色の差の跳ね） |
| 荒い音 | `audio.csv`（1秒の RMS）。whisper の語がある秒を「声の秒」、無い秒を「声の無い秒」にして、それぞれの中央値 |
| 効果音 | こちらは指示書の `sfx[]`（コマと種類と大きさが分かっている）。参考は前の研究の所見だけ |

### 1.3 注意（数を読む前に）

- **型ごとに2〜6本しかない。** 「この型はこう」は傾向で、跳ねるかを決める物ではない（C の結論6: 作りは差にならない）
- **西園寺さんの回が4本**（体験2・食べ物2）。体験と食べ物の見た目の差に、作り手の差が混ざる。食べ物の型は西園寺さん以外の6本で書いた
- 11-18 の参考7本は、跳ねた回かを数えていない（再生数だけ。英語の回が4本）
- 字の帯の検出は外れがある（画の中の看板を字と取る・白地の白い字を取り落とす・2行の字幕を1つの帯にする）。数は目安で、見た目は人の目で確かめた
- 字の大きさの px は帯の高さ（縁と2行を含む）で、書体の大きさそのものではない。型どうしの比べにだけ使う
- 効果音の数・種類・鳴らす所は、**参考については測れていない**。4章の効果音の欄は、前の研究の1本・こちらの指示書・型の山の置き場所からの【推測】

### 4.1 型をまたいで共通（どの型でもする）

## 8. 測れなかったこと・次に測ること

- **参考の効果音とBGM**（予定の35本）。頼む形はできている（取り込みの reference に `audio: true`。`shorts/requests/teko-F-edit-axis-20261123.json`）。
  毎晩のチャットの取り込みが通ったのを見てから、1回8本まで・頼み直し1回まで（main の決め）。測るのは `tools/shorts/style/sfx_scan.py`
  （効果音の候補・同じ音の繰り返し・BGM の落ち・カットが拍に乗るか）と `bgm_gap.py measure`（声と BGM の差）。
  効果音の数えかたは、効果音の位置と種類が指示書で分かっているヨーグルトの回（FgLkHZofCT8）で先に当てる
- 効果音の候補の見つけかたは、合成の音（声＋クシコス・ポスト＋ポケットサウンドの5つ）で試しただけで、声の音節とオーケストラの音の頭を
  効果音と取り違える（候補 27 のうち本物 5）。**同じ音の繰り返し**（効果音は同じ波形なので何度でも同じ形になる）で束ねると当たりやすいが、
  BGM の太鼓も同じ形で繰り返すので、最後は人が音の絵で見る
- お金の型の字（0本）・トラブルとお金の頭3秒の出しかた（0本）
- 同じチャンネルの組（跳ねた回とふつうの回）で字と音を並べること（C の15組は字幕と構成だけ）
- 書体の名前（`font_match.py` は回していない）
- 再生しながら音を録る道（EC2 の Chrome。`live.py`・使い捨て）: プロファイルの再生の速さが 1.5倍に残っていた（1倍に戻す）・
  読み込みで止まった所の音が抜ける（先に読ませてから頭へ戻して録る・止まった所を時刻で抜く）を直したが、EC2 の SSM が届かなくなって
  通しては確かめていない
