# 配信から「実際に行った」を抜く（guide-facts）

行った街のガイドは、**行った日・払った額・本人の一言・その場面の時刻つきリンク**で答える（#1196・#1203）。
その材料を、配信1本につき1ファイルで作る。**読み手は、面を作る担当と道具**（視聴者さん向けの文章ではない）。

**抜くのは道具 `python/guide_extract.py`**（`claude -p` に1本ぶんの1枚だけを渡す）、**確かめるのは `python/guide_facts.py`**。
担当（Agent）に1本ずつ配るのは、道具で回せないときの逃げ道（§4）。

## 0. 置き場

```
streams/2026/10/
  2026-10-24_2123_eHBAnQF56-E.transcript.txt   # 材料（手で直さない）
  2026-10-24_2123_eHBAnQF56-E.chat.txt         # 材料（手で直さない）
  2026-10-24_2123_eHBAnQF56-E.md               # 議事録（地図として使う。先に要る）
  2026-10-24_2123_eHBAnQF56-E.facts.json       # ← これを書く
python/data/guide/cities.json                  # 寄せる表（国・街・通貨の言いかた・場所の名前・遠出の札）
```

**街ごとの下書きは git に置かない。** `city` が `.facts.json` から毎回組んで、標準出力か `-o` に出す
（置くと、元を直した日から古くなる。#1203 で決めた）。

## 1. 手順

1. **まだの配信を出す。** `python3 python/guide_facts.py pending --country north-macedonia`
   （議事録がまだの回は出てこない。議事録が先——`/stream-notes`）
2. **道具で抜く。** 控えはスクラッチパッドに置く（渡した1枚・返事・途中の facts。git に入れない）
   ```bash
   python3 python/guide_extract.py --pending --country north-macedonia --out <scratch>/guide --runs <scratch>/guide/runs.jsonl --jobs 3
   python3 python/guide_extract.py <stem> [<stem> ...] --out <scratch>/guide      # 名指し
   python3 python/guide_extract.py <stem> --prompt-only --out <scratch>/guide     # 1枚を組むだけ（呼ばない）。伏せ残しもここで分かる
   ```
   道具がすること: 長い回は流れだけを渡して字幕を読む窓を選ばせる → 窓の字幕と、その行に付いたチャットの本文と、流れ・見出し・
   寄せる表・別の回の完成形（6項目）で1枚を組む → **視聴者さんの素性を伏せ、別の見かたでもう一度探して、残っていれば呼ばない** →
   返事を check に掛け、NG の行だけを添えて同じ1枚で1回だけ直させる → 2回目も落ちた項目は落とす → 通ったものだけを
   `<stem>.facts.json` に置く（**0件の回は置かない**）。1本1行で、項目の数・1回目の NG・落とした数（札ごと）・トークン・秒が出る。
   並べるのは3本まで（`--jobs` は3で頭打ち）。もう在る `.facts.json` は作り直さない（`--force` で作り直す）
3. **確かめる。** `python3 python/guide_facts.py check --country north-macedonia`（1本なら stem を渡す）。
   終了 0=通った / 1=NG / **2=見るものが無い**（項目0件・材料が読めない）。道具が置いたものは通っているはずなので、
   ここは「全部まとめて通るか」と、表に足す前後で変わらないかを見る。
   NG の札（`number` `quote` `readaloud` `chatfirst` `identity` `music` `split` …）の意味は `python/guide_facts.py` の頭の表。
   **道具では見きれないものを、本文（`text`）を目で通して落とす**: 名前の無い第三者の話（宿のオーナーの事情・
   同宿の人とのもめごと）と、宿・店・施設の悪い評判（汚れへの文句・口コミの点数）。2026-11 の18本で6件落とした
   （1枚の決まりにも足したので、次からは減るはず）。落とすときは項目を消して、check をもう一度回す
4. **寄せる表に足す。** check（と道具）が「寄せる表に無い場所の名前」と数えたものを見て、同じ場所の別の書きかたなら
   既にある名前の `places` の欄に、新しい場所なら新しい名前として `cities.json` の `places` に足す
   （道具には触らせない。表は回をまたいで効くので、こちらが見て決める）。
   道具が「札の無い遠出」と出したもの（日帰りで行った先）は、同じ表のその街の `trips` に札を足して、その回を `--force` で抜き直す
5. **束ねて読む。** `python3 python/guide_facts.py city --country north-macedonia --city skopje`
   （遠出だけなら `--trip matka-canyon`。ファイルに欲しければ `-o`。check を通っていない材料が1本でも在れば組まない）。
   出るのは2つの山——**「そのまま出せる行」**と、**「確かめが要る行」**（`verify` の付いた項目と、チャットが出どころの項目。
   このままでは面に出さない）。数は頭に出る。街の中の話と、遠出ごとの話は別に束ねてある
6. `.facts.json` と寄せる表をコミットして push（「なぜ」を書く。何本足したか）。**下書きはコミットしない**

```json

 "items": [
  {
   "kind": "price",
   "text": "バスは片道50。本人の計算では150円で、往復で100。",

   "what": "マトカ渓谷へのバス（片道・往復）",
   "amounts": [{"value": 50, "unit": null, "as": "said"}, {"value": 150, "unit": "円", "as": "said"}],

```

**頭の7欄は `new` が機械で埋める**（stem・議事録の `- 場所:`・寄せる表から）。手で書かない。

| 欄 | 中身 |
| --- | --- |
| `kind` | `move` どう行く・どう動く／`price` いくらかかる／`place` どこへ行った／`food` 食べたもの／`stay` 泊まる／`fact` そのほかの事実／`caution` 気をつけること（失敗談）／`quote` 本人の言い回し（`about` に、どの問いの話かを上の7つから） |
| `text` | 短い事実の1文。こちらの言葉でよいが、**言っていないことを足さない** |
| `t` | その場面の秒。時刻つきリンクはここから機械で組む（`&t=<t>s`）。根拠の行の中に置く |
| `src.lines` | 根拠にした文字起こしの行の時刻（30秒きざみの `h:mm:ss`）。頭から尻まで5分以内 |
| `src.notes` | 議事録のどの見出しか。`new` が出す見出しを**そのまま写す** |
| `what` `amounts` | 額が在るとき。`as` は `said`（配信で言ったまま）か `converted`（こちらの換算。`from` と `rate` が要る）。`unit` は言ったままの単位、**言っていなければ `null`** |
| `other_amounts` | 根拠の行の近く（前後1行）に在るが、この項目の品ではない額（`{value, unit, what}`） |
| `verify` | 「確かめが要る」の印。**何を確かめるか**を字で書く。**付いたままの項目は面に出さない**（`city` が後ろの山に回す）。動画か外の出どころで確かめたら、額を直して印を外す |
| `via` | `"chat"` だけ。**チャットが先に言い、本人はその場で認めただけの話**（「クラクションないし」→「ないよ」）。面には出さない。`quote` は付けられない |
| `measured` | 配信の時刻の差で**測った値**（`{what, from, to}`。`from` と `to` は字幕の行の時刻）。乗った行と降りた行のように、**始まりと終わりの両方が字幕ではっきりしているときだけ**。言った数字（本文）とは別の欄 |
| `trip` | 日帰りの遠出の札（寄せる表のその街の `trips` に在るもの。`new` が一覧を出す）。街はそのまま（泊まっている街） |
| `place` | `name` は読める正の名前、`heard` はその配信の字幕での形（崩れたまま。無ければ `[]`） |
| `quote` | 本人の言い回し。**字幕に在る字のまま** |

## 3. 抜くときの決まり

- **正は文字起こし。** 議事録は地図（どの時刻に何が在るか）で、機械が書いたもの。**議事録に在って字幕で確かめられないものは抜かない**
- **本文の算用数字は、全部「配信で言った数字」として確かめられる**（根拠の行の前後 ±90秒）。
  言っていない数（「1泊」と言っていないのに書く 1、こちらが数えた「3つ」）は書かない。**換算した額は本文に書かない**（`amounts` にだけ）
- **1項目に、同じ単位の額は1つ。** 2つ言っているなら、割れている（→ 両方挙げて `verify`）か、別の品（→ `other_amounts` か別の項目）
- **言い回しは字幕の字のまま。** 直してよいのは2つだけ——明らかな誤字のすぐあとに `[正しい字]` を**足す**
  （字幕の字は消さない。「吉の屋[吉野家]より早い」）、途中を飛ばすときは `…`。崩れがひどい所は、言い回しにしない
- **チャットが出どころの話は、本人の話として抜かない。** 本人はチャットを声に出して読むので、字幕では本人の発話に見える。
  `read --chat` で同じ時刻のチャットを並べて見る。分けかたは3つ——
  (1) チャットが言っただけ（「手前で折り返すことがあるらしい」）→ **抜かない**
  (2) チャットが先に言い、本人がその場で認めた（「クラクションないし」→「ないよ」）→ 抜くなら **`via: "chat"`**。
  一言（`quote`）にはしない。面には出ない
  (3) 本人が自分の言葉で、自分の体験として言った（「この日は手前で降ろされた」）→ ふつうに抜く
- **所要時間は、言った数字と、測った値を分ける。** 「バスで1時間」は本文に。乗った行と降りた行が字幕ではっきりしていれば、
  `measured` に両方の行を書く（道具が差を出す）。途中で寄り道した・どこで終わったか分からない、は測らない
- **視聴者さんのことは1字も書かない。** 名前・呼びかけ・チャットの文・投げ銭。本人（配信者）の発話と体験だけ
- **第三者（宿の人・同宿の人・店の人・通りがかりの人）は、名前を書かない。** その人が特定できる話
  （どこの誰が何をした）と、特定できる店への悪い評判は抜かない
- **歌詞の印の付いた行（`[音楽]`）は根拠にしない**
- 屋内の回（料理・雑談・アプリ作り）は、街の事実がほぼ無い。**食材の値段・宿の様子**だけ抜いて、無理に増やさない

## 4. 道具で回せないとき（逃げ道）

`claude -p` が使えない箱・道具が同じ回を何度も0件にする・伏せ残しで止まって直しようがない、のときだけ、
1本につき1人の担当（Agent）に配る。担当は Agent の前置き（約6.9万トークン）を読むので、**道具の約10倍高い**。

```
配信1本から「実際に行った」を抜いて、<stem>.facts.json を書いてください。日本語。
形と決まりは /home/user/live-streaming/.claude/skills/guide-facts/SKILL.md の §2・§3（先に読む）。
1. python3 python/guide_facts.py new <stem>  … 頭を埋めた空のファイルと、議事録の見出し
2. 議事録の「## 流れ」から外の場面の時刻を拾い、その前後だけを read <stem> <始> <終> --chat で読む（丸ごと読まない）
3. check <stem> が終了 0 になるまで直す。直せないものは落とす（verify で黙らせない）
触ってよいのは <stem>.facts.json だけ。コミットしない。返すのは10行以内（種類ごとの数・落とした数と理由・
表に足してほしい場所と遠出）。視聴者さんの名前とチャットの文は、報告にも書かない。
```

字幕が無い回（`manifest.tsv` が `none`）と、議事録がまだの回は抜かない（議事録が先）。

## 5. 道具のモデルの決めかた（2026-11-13、完成形3本と同じ回で比べた）

同じ1枚（窓の選びかたも同じ）で、`--no-write` で3本を抜いて比べた。数は3本の合計か、3本ぶんを並べたもの。

| | 完成形（Agent） | Haiku | **Sonnet（既定）** | Opus |
| --- | ---: | ---: | ---: | ---: |
| 項目（到着の日／旧市街と食堂／マトカ渓谷） | 27／15／21 | 43／27／21 | 21／21／17 | 45／27／37 |
| 1回目の NG（3本の合計） | — | 4 | 4 | 9 |
| 直させたあとの NG → 落とした | — | 1 → 1（chatfirst） | 0 → 0 | 0 → 0 |
| 確かめが要る・チャットが出どころ | 8・2 | 7・2 | 6・0 | 7・5 |
| 1本あたりのトークン（出力） | 測っていない（前置き約6.9万を毎回＋往復10回前後） | 約9.9万（5万） | 約6.0万（1.2万） | 約5.4万（1.4万） |
| 1本あたりの秒（API） | — | 約210 | 約80 | 約120 |
| 1本あたりの額（`claude -p` の出す値） | — | 約0.03ドル | 約0.28ドル | 約0.59ドル |

そのまま Sonnet で残りの18本を抜いた（2026-11-13）: **18本とも置けた・項目288件・道具が落とした2件**（identity 1・split 1）・
1回目に NG が出たのは12本（直させて10本が0に）。**1本あたり 約5.8万トークン（中央値 6.8万・最大 10.9万）・約60秒・約0.27ドル**、
呼んだのは46回（窓を選ばせる16・抜く18・直す12）。3本ずつ並べて、18本で約8分。

**Sonnet にした。** 落とした項目が0で、項目の密度が完成形に近い。Haiku は額こそ安いが、出力（考えた分）が4倍・時間が3倍で、
種類の付けかたが粗い（「川の匂いで水も飲めそう」を caution に）うえ、直しても1件落ちた。Opus はいちばん丁寧
（チャットが出どころの見分け・測った値まで拾う）だが、額が2倍。**チャットが出どころの話を見分けるのは Sonnet が弱い**
（3本で0件。完成形は2件）ので、面に出す前の目通しで、本文がチャットの言ったことでないかを見る。

## 6. 1本あたりの手間と、つまずく所（2026-11 の試作3本の実測。Agent で抜いたとき）

| | 到着の日（1:16） | 旧市街と食堂（1:46） | マトカ渓谷（3:47） |
| --- | ---: | ---: | ---: |
| 字幕の字数 | 1.5万 | 1.7万 | 3.2万 |
| 読んだ字幕（窓の合計） | 約9千字（6割） | 約6.5千字（4割） | 約8.5千字（3割） |
| `read` の回数 | 6 | 6 | 8 |
| 項目 | 27 | 15 | 21 |
| うち、面に出さない山（verify・via） | 2・2 | 3・0 | 3・0 |
| 測った値（measured） | 0 | 2 | 1 |
| check を回した回数 | 5 | 3 | 3 |

議事録の「流れ」（3〜4千字）を足して、**1本あたり読む字は1〜1.3万字、往復は10回前後**。

つまずいた所（どれも実際に起きた）:

- **議事録の数字と言い回しが、字幕に無い。** 「1泊19ユーロ」→ 字幕は `eur` と `price 19` が別の行で「1泊」は言っていない。
  「片道50デナール」→ 字幕は「50」だけで、単位はチャットの字。「サウナの後に入る水風呂みたい」→ 字幕は「サウナの後に入る。冷たいな」
- **議事録に、チャットが出どころの事実が混ざっている**（市内の運賃・店の支払いかた・水面の棒の正体）。3本で6件、抜かなかった
- **読み上げを、本人の一言として2件入れかけた**（道具が `readaloud` で落とした。うち1件は、字幕が「やばい」・
  チャットが「ヤバい」で、はじめの比べかたをすり抜けていた）。言い回しは必ず `--chat` で見る。
  本文のほうは道具では見きれない——**チャットが先に言ったこと（「ゴミが増えた」「真っ暗」）を、本人の観察として書かない**
- **チャットが出どころの数字を、本人の数字として1件書いていた**（料理が来るまでの「1分」。本人はチャットを読んだだけ）。
  数字は道具が `chatfirst` で見る（本人が言う前に、同じ数字＋あとの1字がチャットに在る）。本人が先に言った行を根拠にする
- **値段はほぼ全部「円」で喋る。** 本人がその場で値札を円に直している（北マケドニアは「3倍」）。現地通貨の単位はほとんど言わない。
  「600」が円かデナールか字幕から決められないときは `unit: null` か、言ったまま「円」にして `verify`
- **場所の名前は字幕にほとんど無い。** 「マトカ」は題名にだけ在り、本文は「ま渓谷」「警谷」。`heard` は本文に在る形を書く
- **字幕には周りの人の声も入る**（外国語の行）。本人の発話ではないので抜かない
- **お祈りの放送が曲として伏せられている**ことがある。その前後の話は根拠にできない
- **所要時間は、言った数字より配信の時刻の差のほうが確か。** 本人は「バスで1時間」と言い、乗った 0:11 → 降りた 1:00 で測ると49分。
  料理が来るまでの「1分」（チャットの数字）は、注文した行と来た行で測ると1.5分だった。`measured` に入れる
- **測れる移動は少ない。** 3本で測れたのは3つだけ。歩きは寄り道（スーパー・カフェ）が挟まって、始まりと終わりが決まらない
