# 国旗の絵（題の札の「🇦🇱アルバニアの…」）

書き出し（`render.py` → `textlook.py`）が、字の中の国旗の絵文字（🇦🇱）の場所に置く絵。
書体（M PLUS）に絵文字の字形が無いので、字としては描けない（豆腐 □□ になる）。

- `<小文字の2字>.png` — 国旗1枚。高さ 256px・元の縦横比のまま（スイスは正方形、ネパールは旗の形のまま）
- `SOURCES.json` — 1枚ずつの出どころ（SVG の URL と sha256）・焼いた PNG の sha256・焼いた道具・国の名前
- `LICENSE-region-flags.txt` — 出どころの許諾の写し

足す・確かめるのは `../flags.py`（使い方は頭のコメント）。**PNG を手で描き直さない**——`flags.py check` が
控えの sha256 と比べて落とす。

## 出どころと許諾

[region-flags](https://github.com/fonttools/region-flags) の SVG を、noto-emoji のタグ `v2.047` に入っている写し
（`third_party/region-flags/svg/`）から取る。Noto Color Emoji の国旗の元になっている絵と同じもの。

**パブリックドメイン（または著作権の対象外）。クレジットは要らない。** Wikipedia から落として、
パブリックドメインか、国の法律で著作権の対象外（国の旗などの公の印）と確かめたもの、と許諾に書いてある。
アルメニア（AM）・アゼルバイジャン（AZ）・モルドバ（MD）・セルビア（RS）は後者
（`{{PD-AM-exempt}}` などの国ごとの決まりで対象外）として、許諾の中に名指しで挙がっている。

ほかの候補を見比べて、これにした（2026-10-21、ホステルの回の題の札を 1080x1920 で並べた）:

| 候補 | 許諾 | 見え方 | 取らなかった理由 |
| --- | --- | --- | --- |
| **region-flags（これ）** | パブリックドメイン | 平らな四角。角を丸め、内側に細い白い縁 | — |
| Twemoji | CC BY 4.0 | 平らな四角（角が大きく丸い）。region-flags とほぼ同じ | 投稿のたびに説明文へクレジットが要る（書き忘れたら許諾違反）。見た目の差が無いのに手間だけ増える |
| Noto Color Emoji（書体） | OFL | はためく旗・光沢 | Pillow で描けるのは大きさ 109 の絵（旗は 126x94px）だけで、それより大きく置くとぼける（【大】の字の 184px なら 151px の旗）。はためく形は上下にすき間ができ、箱の上で字の列から浮く。書体（10.6MB）をランナーに落とす手間も増える |
| Noto の COLRv1（書体） | OFL | 同上（ベクター） | Pillow 12.3 が何も描かない（空の絵が返る） |
| flag-icons | MIT | 4:3 にそろえた四角 | 赤が #FF0000 の原色で、題の札の黄・赤の縁とぶつかる。縦横比を国の決まりから変えている |

## 国の2字の決めかた

ISO 3166-1 alpha-2（`AL` アルバニア・`MK` 北マケドニア・`GB` イギリス）。ISO に無いコソボは、
国際的に使われている `XK`。絵文字は2字を地域指示子に置き換えたもの（`flags.py emoji AL` → 🇦🇱）で、
YouTube・TikTok の投稿の題に書く国旗と同じ字になる。いま入っている国は `flags.py list`。
