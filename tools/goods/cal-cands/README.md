# カレンダーの絵の候補（選ばなかったものも含む）

月ごとに ChatGPT で3枚ずつ作った候補（7月は2テーマ × 3枚）。カレンダーに刷るのは
`../cal-src/` に置いた1枚だけで、ここは**差し替えるときの手元**。

- `<MM>-<a〜f>.webp` … 候補そのもの（1254px の正方形）。MM は暦の月（2025年11月の思い出 → `11`）
- `<MM>-sheet.jpg` … その月の候補を横に並べた見比べ用（7月は上の段が a〜c＝イワシ祭り、下の段が d〜f＝ルーレット）

差し替えかた:

```bash
python3 -c "from PIL import Image; Image.open('tools/goods/cal-cands/12-a.webp').save('tools/goods/cal-src/12-a.png')"
python3 tools/goods/calbake.py
```

差し替えた月が1月なら、`/goods` の SUZURI の升目に出している写真（1月のページ）も
撮り直しになる（`site/content/goods.ts` の `SHOP_GOODS` のカレンダーの `alt` と、
`tools/goods/shopgoods.py` / `shopshot.py`）。月ごとの絵を面に並べていた表
（`CAL_MONTHS`）は、SUZURI に出した 2026-10-15 に欄ごと畳んだので、もう無い。

## `hidden/` — 8位以降の住人を景色に溶かした版（2026-10-14、採用した）

各月の上位7人に加えて、**同じ締めで数えた8位以降の住人**（図鑑に絵のある人・上位と重ならない人）を、
「ウォーリーをさがせ」の大きさで景色の中に足したもの。

- `<MM>-a.png` … 元絵（一言なし）。`../cal-src/<MM>-a.png` に置き換えれば `calbake.py` でそのまま焼ける
- `<MM>-a.webp` … 一言を重ねた確認用の正方形
- `compare-<MM>.webp` … 左が今の元絵、右が足したもの

ChatGPT は絵ぜんぶを描き直してくるので、**返ってきた絵は使わず、足された住人の画素だけを今の元絵へ移した**
（位置を合わせ、差の出たところだけを切って重ね、大きすぎる子は足もとを据えたまま縮めた）。
住人の外の画素は元絵と同じ。足す人がいない月（3・11・12月）は元絵のまま。

**採用した（2026-10-14、あやとが #890 で全部 OK）。** 1・2・4〜10月の `<MM>-a.png` を `../cal-src/` に置き換えて
焼き直し、SUZURI の卓上カレンダー（2027年版）もこの12枚で作った。3・11・12月は前の元絵のまま。
ここの `<MM>-a.png` はいまの `../cal-src/` と同じ画素。足す前の元絵は git の履歴にある。
