# `crawl.mjs` の対照（わざと壊してある面）

**`crawl.mjs` が数字を出す前に、必ずここを1周する。**
1つでも見落としたら、本物の面の数字を1つも出さずに終了コード2で落ちる。

「違反0件」は、**見ていないから0件**かもしれない（`docs/island-standards.md` §15）。
ここの面は、拾ってほしい壊れ方を1枚に1つずつ植えてある。

| 面 | 何が植えてあるか | 拾ってほしいか |
| --- | --- | --- |
| `ok.html` | どこも壊していない（畳みの中の遅れ読みの絵も含む） | **拾ってはいけない** |
| `deadimg.html` | `<img>` の src が配られていない | 絵 |
| `deadsrcset.html` | 1x は在るが **2x が無い**（`#122` の形） | 絵 |
| `deadbg.html` | CSS の背景画像が配られていない | 絵 |
| `deadsvg.html` | SVG の `<image>` が配られていない | 絵 |
| `noh1.html` | h1 が無い | h1 |
| `jserr.html` | 読み込みで例外が飛ぶ | JS |
| `wide.html` | 画面より広い箱がある | 横あふれ |
| `deadlink.html` | 島の中に無い先へのリンク | リンク切れ |
| `stub.html` | 外に出られない宛先の絵（差し替わる） | **拾ってはいけない。「見ていない」に数える** |

面を足したら `crawl.mjs` の `FIXTURES` にも足す。**書いていない面は見に行かない。**
