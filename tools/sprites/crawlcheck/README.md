# `crawl.mjs` の対照（わざと壊してある面）

**`crawl.mjs` が数字を出す前に、必ずここを1周する。**
1つでも見落としたら、本物の面の数字を1つも出さずに終了コード2で落ちる。

「違反0件」は、**見ていないから0件**かもしれない（`docs/island-standards.md` §15）。
ここの面は、拾ってほしい壊れ方を1枚に1つずつ植えてある。

| 面 | 何が植えてあるか | 拾ってほしいか |
| --- | --- | --- |
| `ok.html` | どこも壊していない（畳みの中の遅れ読みの絵も含む） | **拾ってはいけない** |
| `deadimg.html` | `<img>` の src が配られていない | 絵 |
| `deadsrcset.html` | 1x は在るが **2x が無い**（`#122` の形） | 絵 |
| `deadbg.html` | CSS の背景画像が配られていない | 絵 |
| `deadsvg.html` | SVG の `<image>` が配られていない | 絵 |
| `noh1.html` | h1 が無い | h1 |
| `jserr.html` | 読み込みで例外が飛ぶ | JS |
| `wide.html` | 画面より広い箱がある | 横あふれ |
| `deadlink.html` | 島の中に無い先へのリンク | リンク切れ |
| `publiclink.html` | **`public/` の側に在る面**へのリンク（書き出したものには無い） | **拾ってはいけない** |
| `deadpublic.html` | `public/` に在りそうで**無い**先へのリンク | リンク切れ |
| `filelink.html` | **落とせるファイル**へのリンク（面ではないが、配り先に在る） | **拾ってはいけない** |
| `deadfile.html` | 落とせそうで**無い**ファイルへのリンク | リンク切れ |
| `stub.html` | 外に出られない宛先の絵（差し替わる） | **拾ってはいけない。「見ていない」に数える** |

`pub/` は**`public/` の代役**。`publiclink.html` の行き先（`pub/nordic/review.html`）が
ここに在る。本物の `public/` を対照に渡さないのは、**本物のファイルが消えたときに
落ちるのが「リンク切れ」ではなく「対照が壊れた」になってしまう**から。
本物の `public/` は、本番の面を歩くときに渡す（`crawl.mjs` の `pubDir`）。

**落とせるファイルの代役は、この置き場そのもの**（`pix.png`）。`filelink.html` が
そこを指している。行き先は面（`.html`）だけではない——`/goods` の「おとす」は
`/goods/ayato-sticker.jpg` を渡していて、押せば 200 で落ちる。面だけを数えて
いたころは、それが毎回「島の中に無い先」として挙がっていた（2026-10-08）。
本番の側は書き出したもの（`crawl.mjs` の `fileDir`）を歩く。

面を足したら `crawl.mjs` の `FIXTURES` にも足す。**書いていない面は見に行かない。**
